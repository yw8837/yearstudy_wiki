# AI 산업 활용 사례

**정의**: 생성형 AI·AI Agent가 제조·금융·IT 등 실제 산업에서 쓰이는 사례 모음. 세 사례 모두 "도입 배경 → 활용 전략 → 성과(수치)"의 같은 골격을 따른다.

---

## 산업별 사례

### 제조 — LG전자 (가전·전자 / 스마트팩토리)

생성형 AI + 디지털 트윈 + 데이터 분석을 묶어 스마트팩토리를 운영, 공장의 효율·품질·에너지를 동시에 개선한 사례.

- **도입 배경**
  - 공정 복잡도 증가 — 다품종·복잡 공정으로 관리 난이도 상승
  - 설비·품질 관리 한계 — 이상 원인 분석·대응이 사람 경험에 의존
  - 생산성·비용 개선 요구 — 글로벌 경쟁 심화
- **활용 전략**
  - AI 기반 공정·설비 관리 — 센서 데이터 분석 + 생성형 AI로 이상 원인 분석·대응
  - 디지털 트윈 공장 운영 — 가상 공장에서 병목·불량·설비 문제를 사전 예측·최적화
  - 생성형 AI 업무 지원 — 음성·텍스트 기반 설비 상태 조회·작업 이력 검색
- **성과**: 생산성 **17% 증가** / 에너지 효율 **30% 향상** / 불량 품질 비용 **70% 감소**

### 금융 — 모건 스탠리 (투자은행·자산관리)

내부 문서·지식을 검색·요약해 주는 Assistant로 어드바이저(자문) 업무 생산성을 끌어올린 사례.

- **도입 배경**
  - 문서·지식 과다 — 필요 정보를 빠르게 찾기 어려움
  - 검색 품질이 사람 역량에 좌우됨
  - 반복 정리 업무 누적
- **적용 방식**: 내부 지식 검색 지원 / 요약·응답 초안 생성 / 업무 흐름 내 활용 확산
- **성과**: 어드바이저 도입률(Advisor adoption) **20% → 80%** / 문서 접근률 개선 **98%+** / 문서 검색 시간 감소

### IT·개발 — 채널코퍼레이션 (소프트웨어 개발 / AI Agent)

[[AIAgent]] 기반 개발 시스템을 구축해 개발 업무(앱 설치·결제·웹훅·OAuth·MCP 등 핵심 시스템)를 자동화한 사례.

- **도입 배경**
  - 개발 생산성 한계 — 대규모 코드베이스 수정·리팩토링·PR이 어려움
  - 복잡한 코드 변경 관리 — 여러 레포·다수 파일, 테스트 반복
  - 개발 피드백 루프 지연 — CI·코드리뷰가 길어짐
- **활용 전략**
  - Agent 기반 개발 — 구현·리팩토링·PR은 에이전트가, 개발자는 설계·판단에 집중
  - CI 피드백 루프 자동화
  - 다중 Agent 병렬 개발 — `worktree`로 여러 작업을 병렬 진행
- **성과**: 약 **97만 줄** 코드 수정 / **560개 이상** PR 자동 머지 / CI 실행 시간 **80% 감소**
- 실사용 코딩 에이전트 도구는 [[Cursor]] 참조.

| 산업 | 기업 | 핵심 | 성과 |
|:---|:---|:---|:---|
| 제조 | LG전자 | 생성형 AI + 디지털 트윈 + 공정 관리 | 생산성 17%↑ / 에너지 30%↑ / 불량비용 70%↓ |
| 금융 | 모건 스탠리 | 내부 지식 검색·요약 Assistant | 어드바이저 도입 20→80% / 문서 접근률 98%+ |
| IT·개발 | 채널코퍼레이션 | AI Agent 기반 개발·CI 자동화 | 97만 줄 수정 / 560+ PR 자동 머지 / CI 80%↓ |

## 자주 헷갈리는 것

**"수치가 곧 ROI"**: 위 수치는 각 사 발표 기준의 효과 지표다. 산업·조건이 다르면 그대로 재현되지 않으니 맥락과 함께 읽을 것.
