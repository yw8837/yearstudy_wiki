# 통계 자료의 요약 정리

기술통계(자료의 요약) 6/19 요약. **논리적(수치) 요약 + 시각화 요약**을 한눈에. 실측값은 seaborn `tips`(244건).

> 강의 출처: [[0619-통계자료요약]] · 상세: [[평균]] · [[중앙값]] · [[분산]] · [[IQR]] · [[상관계수]] · [[상자그림]]

---

## 1. 자료의 형태 → [[자료의형태]]

```python
# tips 컬럼 분류 예
연속형: total_bill, tip      # 수치 측정 가능·연속
이산형: size (1~6명)         # 셀 수 있는 수치
명목형: sex, smoker, time    # 순서 없는 범주
순위형: day (Thur<Fri<Sat<Sun)  # 순서 있는 범주
```

- **수치형(양적)** = 연속/이산, **범주형(질적)** = 명목/순위. 이 분류가 이후 모든 요약 기법을 결정.
- **함정:** 숫자로 코딩해도(남=1·여=0) 범주형 / 나이를 구간화하면 범주형. 측정 가능 여부로 판단.

---

## 2. 범주형 요약 → [[도수분포표]] · [[교차표]]

```python
s.value_counts()                       # 도수(개수)
s.value_counts(normalize=True)         # 상대도수(비율)
pd.crosstab(index=요일, columns="count")     # 한 범주 도수표
pd.crosstab(index=요일, columns=흡연)        # 두 범주 교차표
```

- **원형(Pie)** = 비율 파악 쉬움·크기 비교 어려움 / **막대(Bar)** = 크기 비교 쉬움·비율 어려움.

---

## 3. 수치형 요약 (연속형 분포) → [[히스토그램]] · [[도수다각형]]

- **5기법:** [[점도표]]·도수분포표·[[히스토그램]]·[[도수다각형]]·[[줄기잎그림]].
- **[[히스토그램]]**(`plt.hist`): 계급=X·빈도=Y, 분포 형태 파악. **[[도수다각형]]**: 계급 중앙 점을 직선 연결 → **여러 그룹 비교에 적합**(꺾은선 겹침).
- **도수분포표 순서:** 범위 → 계급폭 → 경계점 → 도수 → 상대도수. 계급수는 [[Sturges공식]] $k=1+\log_2 n$.
- ⚠ **[[점도표]]·[[줄기잎그림]]은 PDF 이론에만**, 노트북 코드 없음.

---

## 4. 중심위치 측도 → [[평균]] · [[중앙값]] · [[최빈값]]

```python
np.mean(x)      # 평균 — 극단값에 민감
np.median(x)    # 중앙값 — 극단값에 강건
stats.mode(x)   # 최빈값 — 이산/범주·단봉형
```

- **tips:** 평균 **19.79** > 중앙값 **17.80** > 최빈값 13.42.
- 단봉 대칭 → 평균=중앙값=최빈값 / 다봉 → 평균=중앙값≠최빈값 / 비대칭 → 모두 다름.

### ⚠ 치우친 분포 — 기준 따라 반대 (단정 금지) → [[치우친분포]]

| 기준 | 왼쪽 치우침 | 오른쪽 치우침 | 출처 |
|:--|:--|:--|:--|
| 봉우리(한국교재) | 평균>중앙값 | 평균<중앙값 | PDF p19·노트북 마크다운 |
| 꼬리(영어 skew) | 평균<중앙값 | 평균>중앙값 | 노트북 코드 주석 |

- 같은 tips 데이터를 노트북 코드는 `right-skewed`(꼬리), 슬라이드는 "왼쪽 치우침"(봉우리)로 라벨. **"어느 기준인지 먼저 말하기".**

## 5. 산포(퍼진 정도) 측도 → [[분산]] · [[표준편차]] · [[IQR]] · [[변동계수]]

```python
np.var(x, ddof=1)    # 분산 79.25  (표본=n-1, PDF 이론은 모분산 n)
np.std(x, ddof=1)    # 표준편차 8.90 (원 단위 동일)
x.max()-x.min()      # 범위 47.74
Q3-Q1                # IQR 10.78 (Q1 13.35·Q3 24.13) — 극단값 무관
s/mean*100           # 변동계수 45.0% — 단위 없음, 이종변수 비교
np.percentile(x, [10,25,50,75,90])   # P10~P90
```

- **선택:** 전체 반영 → 표준편차 / 극단값 무시 → IQR / 단순 → 범위 / 단위 다른 변수 비교 → 변동계수.

## 6. 도수분포표 요약 + [[상자그림]]

- **midpoint 가정:** 원자료 없이 그룹 도수표만 있으면 계급 중간값으로 계산 → **정보 손실**(tips 그룹 평균 19.66 vs 원자료 19.79). 원자료 우선.
- **[[상자그림]]**(`plt.boxplot`): 5수치 요약(최소·Q1·Q2·Q3·최대), 수염=Q1-1.5IQR~Q3+1.5IQR, 바깥=이상값. **단봉형에만 적절 → 히스토그램으로 형태 먼저 확인**.

## 7. 두 변수 요약 → [[공분산]] · [[상관계수]] · [[분할표]]

```python
pd.crosstab(요일, 식사시간)              # 범주형×범주형 = 분할표
plt.scatter(x, y)                        # 연속형×연속형 = 산점도 (상관 전 필수)
df.cov()                                 # 공분산 8.3235 — 단위 있음·해석 어려움
df.corr()                                # 상관계수 r=0.6757 — [-1,1]·단위 없음
```

- **r:** >0 비례·<0 반비례·±1 직선·≈0 선형관계 없음. **직선 관계만** 측정(곡선은 r≈0), 이상값에 민감.
- **★[[상관과인과|상관 ≠ 인과]]:** 상어 물림↑↔아이스크림↑ — 공통원인 "여름"(허위 상관). 상관 높아도 산점도·인과 검증 필요.
