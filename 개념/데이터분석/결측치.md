# 결측치 (Missing Value)

**정의**: 데이터에서 **비어 있는 값**(NaN·NULL). 어떻게 처리하느냐가 분석·모델 결과에 영향을 준다.

---

## 왜 필요한가

현실 데이터엔 결측이 흔하다(미응답·수집 실패). 그대로 두면 평균·모델 학습이 깨지므로 **삭제하거나 채워야** 한다. 단 처리 방법에 따라 결과가 달라져 신중해야 한다.

---

## 어떻게 작동하나

표준 처리 전략:

| 전략 | 방법 |
|:---|:---|
| **삭제** | 결측 행/열 제거(Complete Case·listwise·pairwise) |
| **단순대치** | 평균·중앙값·최빈값으로 채움 |
| **회귀/예측 대치** | 다른 변수로 결측값 예측 |
| **다중대치** | 여러 값으로 채워 불확실성 반영(MICE) |
| **KNN 대치** | 비슷한 행의 값으로 채움 |

```python
import numpy as np
ok = ~np.any(np.isnan(X), axis=1)   # 결측 행 마스크
cleaned = X[ok]                      # 삭제 (NumPy)
```

---

## 실제 예시
