# 피라미드 원칙 (Pyramid Principle)

**정의**: **결론(핵심 메시지)을 피라미드 최상단에 두고 탑다운으로 전개** 하는 논리 구조. 바바라 민토 『논리의 기술』의 핵심. 결론 → 근거 → 세부 순으로 내려간다.

---

## 왜 필요한가

강사 강조: **보고/발표는 현황 설명이 아니라 의사결정을 구하는 행위** 다. 상대는 바쁘고 내용을 모르므로 **결론부터** 말해야 한다. 컨설팅·기획·전략 문서는 물론 정부 부서까지 표준으로 쓰는 방식.

```
            [ 결론 / 핵심 메시지 ]        ← 맨 위에 먼저
           /        |        \
     [근거1]     [근거2]     [근거3]      ← 결론을 떠받침 (MECE)
      / \         / \         / \
   세부 세부   세부 세부   세부 세부       ← 각 근거의 디테일
```

---

## 어떻게 쓰나

1. **결론을 한 문장으로** 꼭대기에 둔다. (SCQA의 A가 여기 온다 → [[SCQA]])
2. 그 결론을 떠받치는 **근거 3개 내외** 를 두 번째 층에.
3. 근거들은 **서로 중복 없이, 모두 결론을 향하게** → [[MECE]].
4. 각 근거 아래에 세부 데이터·예시.

---

## 자주 헷갈리는 것

**"배경부터 차근차근 설명해야 친절하다"**: 바쁜 의사결정자에겐 역효과. 결론을 먼저 주고, 궁금해하면 근거로 내려간다.

**"피라미드 = 목차 만들기"**: 단순 목차가 아니라 **각 층이 위층을 논리적으로 뒷받침** 해야 한다. 받치지 못하는 근거는 빼야 한다.
