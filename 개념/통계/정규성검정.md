# 정규성 검정 (Normality Test)

**정의**: 데이터가 [[정규분포]]를 따르는지 판정하는 검정. `H₀: 정규분포를 따른다` → `p<0.05`면 정규분포가 아님.

---

## 왜 필요한가

[[t검정]]·[[분산분석|ANOVA]]·[[회귀분석]]은 정규성을 가정한다. 위반하면 [[비모수검정]]으로 바꿔야 하므로 사전 확인이 필요하다.

---

## 어떻게 작동하나

```python
from scipy import stats
stats.shapiro(x)                       # Shapiro-Wilk (소표본에 강함)
from statsmodels.stats.diagnostic import normal_ad
normal_ad(x)                           # Anderson-Darling (꼬리 민감, 극단값 탐지)
# Kolmogorov-Smirnov(모수 추정 시 Lilliefors)도 사용
```

| 검정 | 특징 |
|:--|:--|
| Shapiro-Wilk | 소표본에 강력, 일반적 1순위 |
| Anderson-Darling | 꼬리(tail) 민감 → 극단값 탐지 유리 |
| Kolmogorov-Smirnov | 분포 전체 비교 |

---

## 자주 헷갈리는 것

**H₀이 "정규분포다".** 그래서 `p≥0.05`면 정규성을 기각 못함(정규로 봄), `p<0.05`면 정규성 기각(비정규). 다른 검정과 H₀ 방향이 반대라 헷갈리기 쉽다.

---

## 더 알면 좋은 것

📌 N≥30이면 [[중심극한정리|CLT]]로 정규성을 가정하고 검정을 생략하기도 한다. Q-Q plot으로 시각적 확인도 병행.
