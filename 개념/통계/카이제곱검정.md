# 카이제곱 검정 (Chi-Square Test)

**정의**: **범주형 자료**의 도수를 χ² 분포로 검정. 적합도 검정(관측이 이론분포를 따르나) + 독립성 검정(두 범주형이 독립인가) 2종.

---

## 왜 필요한가

평균이 아니라 "빈도·비율·연관성"을 다뤄야 할 때 쓴다. 예) 전형 유형과 합격 여부에 연관이 있나.

---

## 어떻게 작동하나

```python
from scipy import stats
import pandas as pd
# 적합도: 관측 vs 기대분포
f, p = stats.chisquare(observed, f_exp=expected)
# 독립성: 두 범주형 (교차표 입력), df=(r-1)(c-1)
ct = pd.crosstab(df['A'], df['B'])
chi2, p, dof, expected = stats.chi2_contingency(ct)
```

- 적합도 `H₀: 이론분포를 따른다` / 독립성 `H₀: 두 변수는 독립이다`.

---

## 자주 헷갈리는 것

**기대도수 ≥ 5 조건.** 셀의 기대도수가 5 미만이면 카이제곱 근사가 부정확 → Fisher의 정확검정을 쓴다. 입력은 [[분할표]](crosstab)다.
