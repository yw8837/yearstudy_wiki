# IQR (사분위 범위)

**정의**: 제3사분위수에서 제1사분위수를 뺀 값. **IQR = Q3 - Q1**. 자료 **가운데 50%가 퍼진 정도**를 나타내는 산포 측도.

---

## 왜 필요한가

[[표준편차]]·[[범위]]는 극단값에 흔들리지만, IQR은 양 끝 25%씩을 잘라낸 가운데 50%만 보므로 **극단값에 강건**하다.

---

## 어떻게 작동하나

```python
import numpy as np
Q1, Q3 = np.percentile(x, [25, 75])
IQR = Q3 - Q1          # 10.78 (tips: 24.13 - 13.35)
# 이상값 경계
lower = Q1 - 1.5*IQR
upper = Q3 + 1.5*IQR
```

- **이상값 규칙:** Q1-1.5×IQR보다 작거나 Q3+1.5×IQR보다 크면 이상값(outlier). [[상자그림]]의 수염이 이 경계다.

---

## 자주 헷갈리는 것

**IQR ≠ [[범위]].** 범위는 max-min(전체), IQR은 Q3-Q1(가운데 50%). 이상값에 강건한 건 IQR이다.

---

## 더 알면 좋은 것

📌 IQR의 1.5배 규칙이 [[상자그림]] 이상값 탐지의 표준. 분포가 단봉형일 때 잘 동작하므로, 먼저 [[히스토그램]]으로 형태를 확인하는 게 좋다.
