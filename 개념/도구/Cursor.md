# Cursor (코딩 에이전트)

**정의**: 채팅형 **코딩 보조 도구**. VS Code와 비슷한 형태로, 채팅창에 프롬프트(질문)를 입력하면 **코드 생성·수정·디버깅을 자동 수행** 한다. [[AIAgent]]의 대표적 실사용 사례.

---

## 무엇을 하나

- 채팅창에 요청 → 코드를 **생성·수정** 하고, 에러가 나면 **스스로 실행·수정을 반복.**
- 여러 모델(**Claude / Gemini / ChatGPT** 등)을 **선택적으로 사용** 가능한 것이 강점.

```
사용자 프롬프트 → Cursor가 코드 작성/수정 → 실행 → 에러 시 자동 수정 반복 → 동작
```

---

## 강사 권장 사용법

- **지금은 사용 불필요.** 기초를 직접 손으로 익히는 시기.
- **파이널 프로젝트 기간** 에 **한 달 정도만 유료 결제** 해 활용하는 것을 권장.
- (Cursor 외 유사 도구도 있다고 언급 — 정확한 명칭은 `[원문 확인 필요]`.)

---

## 자주 헷갈리는 것

**"Cursor가 다 짜주니 공부 안 해도 된다"**: 코드를 읽고 검증하는 힘이 없으면 에이전트 출력도 못 믿는다. 기초는 직접 익혀야 한다 → [[HumanInTheLoop]].
