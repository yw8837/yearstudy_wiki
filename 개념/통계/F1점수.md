# F1 점수 (F1-Score)

**정의**: [[정밀도]]와 [[재현율]]의 **조화평균**. `F1 = 2·P·R / (P + R)`. 둘의 균형을 하나의 수로 요약.

---

## 왜 필요한가

정밀도와 재현율은 보통 트레이드오프 관계라 하나만 보면 편향된다. 둘 다 높아야 F1이 높아지므로 **불균형 데이터에서 [[정확도]]보다 신뢰할 만한 단일 지표**로 쓴다.

---

## 어떻게 작동하나

```python
# titanic 실습: 손계산
f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
print(f"F1-Score:  {f1:.2%}  (harmonic mean of precision and recall)")
```

- **조화평균**이라 한쪽이 0에 가까우면 F1도 0에 가까워진다(산술평균과 달리 낮은 쪽에 끌려감).
- 예) P=1.0, R=0.0 → 산술평균 0.5지만 F1 = 0. "둘 다 좋아야 좋다"를 강제.

---

## 자주 헷갈리는 것

**왜 산술평균이 아니라 조화평균인가.** 정밀도·재현율은 비율이고, 한쪽만 극단적으로 높은 걸 방지하려면 낮은 값에 민감한 조화평균이 적합하다. "정밀도 99%·재현율 1%" 같은 쓸모없는 모델을 F1이 낮게 벌준다.

---

## 더 알면 좋은 것

📌 F1은 정밀도·재현율에 동일 가중을 준다. 재현율을 더 중시하고 싶으면 Fβ(β>1)를 쓴다(본 실습 범위 밖). titanic 실습은 F1까지 손계산해 지표 공식의 원리를 드러낸다. ⚠ 노션 원문엔 실제 F1 수치 없음.
