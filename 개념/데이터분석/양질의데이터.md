# 양질의 데이터 (Quality Data)

**정의**: 분석 목적에 맞게 **정확·신뢰·정제된** 데이터. 분석 신뢰도와 [[머신러닝]] 성능을 좌우한다.

---

## 왜 필요한가

검증 안 된 데이터를 넣으면 통계 결과·ML 정확도가 떨어진다("Garbage In, Garbage Out"). 현실에서 고품질 데이터는 **희소·고비용**이라 확보 자체가 경쟁력이다.

---

## 어떻게 작동하나

```
저품질 데이터 → (정제·가공) → 활용 데이터 → (검증) → 고품질 데이터
   ↑ 비용 낮음                              ↑ 비용 급증 (다이아몬드 가공 비유)
```

- 데이터 엔지니어 = **수집 → 처리 → 양질의 데이터(자동화 파이프라인)**.
- [[결측치]]·오류·[[편향과대표성|편향]]을 줄이는 게 품질 향상의 핵심.

---

## 실제 예시

- AI 성능 향상의 배경 = 대규모·고급 데이터 학습. 커뮤니티성 저품질 데이터 학습은 문제 소지.

---

## 자주 헷갈리는 것

**양 vs 질.** [[딥러닝]]은 "양이 깡패"(양 증가가 유리)지만 [[머신러닝]]은 **양보다 양질/정제**가 중요. 여론조사 표본이 ~1,000명인 것도 더 늘려도 개선이 제한적이기 때문.

---

## 더 알면 좋은 것

📌 강의자료의 "ML에서 결측치 처리가 성능에 가시적" 같은 주장은 **근거(레퍼런스) 확인** 후 수용할 것(비판적 데이터 리터러시).
