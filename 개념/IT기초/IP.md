# IP (Internet Protocol)

**정의**: 인터넷에 연결된 모든 기기에 부여되는 고유 주소 체계. 데이터가 목적지를 찾아가는 기준.

---

## 왜 필요한가

데이터를 목적지까지 보내려면 주소가 있어야 한다. IP 주소가 그 주소다. 편지를 보낼 때 주소를 적듯, 인터넷 패킷에는 출발지·목적지 IP가 담긴다.

---

## 어떻게 작동하나

### IPv4

32비트, 점으로 구분된 4개의 숫자(0~255).

```
192.168.0.1
└── 4개 숫자 각각 0~255 (8비트)
└── 총 2^32 = 약 42억 개 주소
```

이미 사실상 고갈 상태. NAT(주소 변환)로 연명 중.

### IPv6

128비트, 콜론으로 구분된 8그룹의 16진수.

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
└── 사실상 무제한 (2^128 = 340조의 조의 조 개)
```

아직 IPv4와 병행 전환 중.

### 공인 IP vs 사설 IP

```
공인 IP: 인터넷에서 유일한 주소. ISP(통신사)가 할당.
사설 IP: 내부 네트워크에서만 쓰는 주소.

[인터넷]
    ↕ 공인 IP: 123.45.67.89
[공유기]  ← NAT 수행
    ↓ 사설 IP: 192.168.0.x
[PC] [폰] [TV]  ← 각자 사설 IP
```

사설 IP 대역: `10.x.x.x`, `172.16.x.x ~ 172.31.x.x`, `192.168.x.x`

### NAT (Network Address Translation)

공유기가 수행. 여러 기기가 하나의 공인 IP를 공유할 수 있게 한다. 내부에서 나가는 요청을 공인 IP로 바꾸고, 들어오는 응답을 다시 해당 사설 IP로 돌려준다.

---

## 실제 예시

- `ipconfig` (Windows) / `ifconfig` (Mac/Linux): 내 사설 IP 확인
- 구글에서 "내 IP" 검색: 공인 IP 확인
- 일반적으로 집 공유기의 사설 IP는 `192.168.0.x` 또는 `192.168.1.x`
- `127.0.0.1` = localhost = 자기 자신을 가리키는 특수 IP (루프백)
- `ping 8.8.8.8` 으로 구글 DNS 서버에 연결 가능한지 테스트

---

## 자주 헷갈리는 것

**"IP 주소 = 위치 추적 가능"**: 공인 IP로 대략적인 지역(도시 수준)은 알 수 있지만 정확한 주소는 알 수 없다. 통신사 협조 없이는 개인 특정 불가.

**"MAC 주소 = IP 주소"**: 다르다.
- MAC 주소: 하드웨어에 새겨진 물리적 고유 주소, 제조사가 부여, 변경 어려움
- IP 주소: 네트워크 연결 시 부여되는 논리적 주소, 변경 가능

**"IPv6가 이미 IPv4를 대체했다"**: 아직 전환 중이다. 현재 인터넷의 상당 부분이 여전히 IPv4. 듀얼스택(둘 다 지원)으로 운영 중.

## 더 알면 좋은 것

📌 **DHCP**: 기기가 네트워크에 연결될 때 공유기(DHCP 서버)가 자동으로 사설 IP를 할당해주는 프로토콜. Wi-Fi 연결하면 자동으로 IP 잡히는 이유.

📌 **서브넷 마스크**: IP 주소에서 네트워크 부분과 호스트 부분을 구분. `255.255.255.0`이면 앞 24비트가 네트워크, 뒤 8비트가 호스트. `/24`로 표기하기도 함 (CIDR 표기).

📌 **VPN**: 가상 IP를 통해 다른 국가의 서버를 경유. 공인 IP를 가리는 데도 사용.
