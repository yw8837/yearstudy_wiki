## 01. 학습/검증 분할 & 특성-목표 분리 → [[학습검증분할]]

sklearn `train_test_split` 없이 **NumPy만으로** 80:20 분할. `np.random.seed(42)`로 재현성 → 인덱스 셔플 → 앞 80% 학습·나머지 검증. 이어 특성 6개와 목표를 `.values`로 배열화해 분리.

| 요소 | 값 |
|:--|:--|
| 특성(X) | `pclass, sex, age, sibsp, parch, fare` (6개) |
| 목표(y) | `survived` (0=사망, 1=생존) |
| 분할 | 학습 80% : 검증 20% |
| 재현성 | `np.random.seed(42)` |

```python
# NumPy로 학습/검증 분할 (sklearn 미사용)
np.random.seed(42)                          # 재현성 시드
n = len(df_model)
indices = np.arange(n)
np.random.shuffle(indices)                  # 인덱스 셔플
train_size = int(0.8 * n)
train_idx = indices[:train_size]            # 학습 80%
test_idx  = indices[train_size:]            # 검증 20%
train_df = df_model.iloc[train_idx].reset_index(drop=True)
test_df  = df_model.iloc[test_idx].reset_index(drop=True)

# 특성(X)과 목표(y) 분리
feature_cols = ['pclass', 'sex', 'age', 'sibsp', 'parch', 'fare']
X_train = train_df[feature_cols].values;  y_train = train_df['survived'].values
X_test  = test_df[feature_cols].values;   y_test  = test_df['survived'].values
```

- ⚠ **[원문 확인 필요]** 이 블록은 `df_model`이 이미 존재한다고 가정. titanic 로드·`sex` 문자열→숫자 인코딩·`age`/`fare` 결측 처리 코드는 노션에 없음. `feature_cols`에 `sex`가 들어가고 `.values`로 배열화되므로 사전 수치 인코딩 전제(코드 미제시).

## 02. 로지스틱 회귀 이론 → [[로지스틱회귀]] · [[시그모이드함수]] · [[오즈비]]

> 노션 원문엔 이론 텍스트가 없다. 아래는 코드 이해용 **표준 개념 보강**.

- **[[로지스틱회귀]]:** 이진(0/1) 종속변수의 발생 확률을 예측. 선형결합 `z = β₀ + Σβᵢxᵢ`를 [[시그모이드함수|시그모이드]]에 통과시켜 0~1 확률로 변환. 확률 ≥ 0.5면 1로 분류([[의사결정경계]]).
- **[[시그모이드함수]]:** `σ(z) = 1/(1+e^(−z))`. 실수를 0~1로 사상. z=0 → σ=0.5(임계 기준).
- **[[오즈비]]:** 오즈 = P/(1−P). 오즈비 = `exp(βᵢ)` = 특성 1단위 증가 시 생존 오즈의 배수. OR>1이면 생존 오즈↑(계수>0), OR<1이면↓.

```
z = β₀ + β₁·pclass + … + β₆·fare
        │
        ▼  σ(z) = 1/(1+e^(−z))
   P(survived=1 | x) ∈ [0,1]
        │
        ▼  ≥ 0.5 ?  ── 의사결정 경계
     y_pred ∈ {0, 1}
```

## 04. 계수 해석 4단계 → [[오즈비]] · [[특성중요도]]

적합 결과에서 특성별 **계수·표준오차·p-value·오즈비(=exp(계수))** 를 한 DataFrame으로 모아 해석. print가 해석 규칙을 직접 출력.

| 지표 | 의미 |
|:--|:--|
| 계수(Coefficient) | 부호=생존확률 방향(+/−), 크기=영향력(스케일 의존) |
| 표준오차(Std Error) | 계수 추정의 불확실성(작을수록 안정) |
| [[p-value]] | 계수=0(효과 없음) 귀무가설 유의성(<0.05면 유의) |
| [[오즈비\|오즈비 exp(β)]] | 특성 1단위 증가 시 생존 오즈 배수 |

```python
# 4단계: 계수 해석
feature_names = ['const (intercept)'] + feature_cols
coef_df = pd.DataFrame({
    'Feature': feature_names,
    'Coefficient': result.params,
    'Std Error': result.bse,
    'p-value': result.pvalues,
    'Odds Ratio': np.exp(result.params)   # exp(계수) = 오즈비
})
print(coef_df.round(4))
# Coefficient > 0 : 생존 확률↑ / < 0 : ↓
# Odds Ratio > 1  : 생존 오즈↑ / < 1 : ↓
```

- ⚠ **[출력 없음]** 노션에 실행 결과(실제 계수값·오즈비)가 없어 수치 미확보. 코드 구조와 해석 규칙만 확인.
- 지표 4개의 상세 정의는 [개념 보강](노션은 계수·오즈비 부호/1 기준 방향만 명시).

→ [[오즈비]] · [[p-value]] · [[특성중요도]] 참조

## 05. 모델 평가 → [[혼동행렬]] · [[정확도]] · [[정밀도]] · [[재현율]] · [[F1점수]]

sklearn `accuracy_score`/`confusion_matrix` 없이 **NumPy로 직접**. 정확도는 예측==실제 평균, 혼동행렬 4칸은 불리언 마스크 `&`로 카운트, 정밀도/재현율/F1은 손계산.

```python
# 정확도 (NumPy 직접)
accuracy = np.mean(y_pred == y_test)
print(f"Model Accuracy on Test Set: {accuracy:.2%}")

# 혼동행렬 (수동 카운트)
TP = np.sum((y_pred == 1) & (y_test == 1))   # 생존→생존
TN = np.sum((y_pred == 0) & (y_test == 0))   # 사망→사망
FP = np.sum((y_pred == 1) & (y_test == 0))   # 사망→생존(거짓양성)
FN = np.sum((y_pred == 0) & (y_test == 1))   # 생존→놓침(거짓음성)

# 정밀도·재현율·F1
precision = TP / (TP + FP) if (TP + FP) > 0 else 0
recall    = TP / (TP + FN) if (TP + FN) > 0 else 0
f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
```

| 지표 | 공식 | 질문 |
|:--|:--|:--|
| [[정확도]] | (TP+TN)/전체 | 전체 중 얼마나 맞췄나 |
| [[정밀도]] | TP/(TP+FP) | 생존이라 한 것 중 진짜 생존 비율 |
| [[재현율]] | TP/(TP+FN) | 실제 생존자 중 찾아낸 비율 |
| [[F1점수]] | 2PR/(P+R) | 정밀도·재현율의 조화평균 |

- ⚠ **[원문 확인 필요]** `y_pred`는 이 블록 전에 만들어졌다고 가정하나 **생성 코드가 노션에 없다**(3장: 확률 예측 후 0.5 임계값 추정, 미제시). **[출력 없음]** 실제 정확도·혼동행렬 수치 미확보.

## 06. 특성 중요도 시각화 (계수 절댓값 barh) → [[특성중요도]]

절편(const) 제외 계수를 **절댓값 크기로 정렬**해 수평 막대. 양의 계수=파랑(생존↑), 음의 계수=빨강(생존↓)으로 방향 시각화.

```python
coef_vals = result.params[1:]                      # 절편 제외
sorted_idx = np.argsort(np.abs(coef_vals))[::-1]    # 절댓값 내림차순
colors = ['steelblue' if c > 0 else 'salmon' for c in coef_vals[sorted_idx]]
plt.barh([feature_cols[i] for i in sorted_idx], coef_vals[sorted_idx], color=colors)
plt.axvline(x=0, color='black', linewidth=0.8)
plt.title('Logistic Regression Coefficients (Blue=positive, Red=negative)')
plt.show()
```

- ⚠ **주의 [개념 보강]** 계수 절댓값을 중요도로 쓰면 **특성 스케일이 다를 때 왜곡**된다(표준화 안 된 계수는 단위에 의존). 노션 코드는 표준화 여부 미명시 → 해석 주의.

→ [[특성중요도]] · [[오즈비]] 참조

## 보충

📌 **sklearn을 안 쓰는 이유.** 이 실습은 `train_test_split`·`accuracy_score`·`confusion_matrix`를 전부 NumPy로 손계산한다. 편의함수 뒤에 숨은 **지표의 정의를 직접 구현**해 원리를 드러내려는 의도. 실무에선 sklearn을 쓰지만, 각 지표가 [[혼동행렬]] 네 칸에서 어떻게 나오는지 아는 게 핵심.

📌 **정밀도 vs 재현율은 트레이드오프.** [[의사결정경계|임계값]]을 올리면 [[정밀도]]↑·[[재현율]]↓, 내리면 반대. titanic 생존예측에서 "생존자를 놓치지 않기"(재현율)와 "생존이라 한 게 맞기"(정밀도) 중 무엇이 중요한지에 따라 임계값을 조정한다. 둘의 균형이 [[F1점수]].

📌 **오즈비로 계수를 읽어라.** 로지스틱 계수 β는 로그오즈라 직관적이지 않다. `exp(β)`([[오즈비]])로 바꾸면 "이 특성 1단위 증가 시 생존 오즈가 몇 배"로 해석된다. 4장 `np.exp(result.params)`가 정확히 이것.

📌 **6/22 이론 → 6/29 실전.** [[0622-확률과통계적추론]]에서 로지스틱회귀·오즈비를 scipy/statsmodels 치트시트로 배웠다면, 오늘은 titanic이라는 실제 데이터에 **전과정(분할→적합→해석→평가→시각화)**을 적용한다. 이론 노트와 실습 노트를 함께 보면 연결된다.

📌 **파서 갭 3건은 실습 미완결 지점.** 전처리(`df_model`)·모델 적합(`result`)·예측(`y_pred`) 코드가 노션에 없다. 후속 생성자가 실습노트를 완결하려면 원본 노트북 확보 필요. 본 노트는 있는 코드만 verbatim 보존하고, 없는 건 [원문 확인 필요]로 정직하게 남긴다.
