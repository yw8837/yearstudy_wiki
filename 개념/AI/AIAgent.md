# AI Agent (AI 에이전트)

**정의**: 목표를 받아 **스스로 계획하고 도구를 사용해 실행**하는 AI. 단발성 응답을 넘어 작업을 자율적으로 수행한다.

---

## 왜 필요한가

LLM에 질문하면 답 한 번이 끝이다. 하지만 "이 버그 고쳐서 PR 올려줘" 같은 일은 여러 단계(코드 읽기→수정→테스트→커밋)를 거쳐야 한다. Agent는 이 **반복 루프를 스스로 돌린다**.

---

## 어떻게 작동하나

```
목표 입력 → [인식 Perception] → [계획] → [행동 Action: 도구·API] → 결과 관찰 → 반복 → 달성
```

**핵심 속성 4가지** (슬라이드):

| 속성 | 영어 | 의미 |
|:---|:---|:---|
| 목표 지향성 | Goal-Oriented | 목표를 향해 동작 |
| 자율성 | Autonomy | 스스로 판단·진행 |
| 인식 | Perception | 환경·상태 관찰 |
| 행동 | Action | 도구/API 호출로 실행 |

---

## 실제 예시

- **코딩 에이전트 [[Cursor]]**: 채팅 프롬프트로 코드 생성·수정·디버깅을 자동 수행, 에러 시 스스로 실행·수정 반복. 여러 모델(Claude/Gemini/ChatGPT) 선택 가능
- 코드 작성·리뷰·PR 처리, CI 연동, worktree로 병렬 실행
- 도구 연결 표준: **MCP**(Model Context Protocol), OAuth로 외부 서비스 접근

---

## 자주 헷갈리는 것

**"Agent = 똑똑한 챗봇"**: 챗봇은 대화, Agent는 **행동**(도구 호출로 실제 작업 수행)이 핵심.

**"완전 자율이라 사람이 필요 없다"**: 위험하다. 중요한 판단·검증엔 [[HumanInTheLoop]]이 필요.
