# 정렬 (sorted · sort)

**정의**: 리스트 등을 순서대로 나열하는 것. `sorted()`(새 리스트 반환)와 `list.sort()`(원본 변경) 두 가지.

---

## 왜 필요한가

순위, 랭킹, 가나다/연봉 순 정렬은 데이터 처리의 기본. 특히 **무엇을 기준으로** 정렬할지(`key`)를 자유롭게 지정할 수 있어 실무에서 강력하다.

---

## 어떻게 작동하나

```python
scores = [85, 92, 78, 96]
sorted(scores)                 # [78, 85, 92, 96]  원본 유지, 새 리스트
sorted(scores, reverse=True)   # [96, 92, 85, 78]  내림차순
scores.sort()                  # 원본 변경, 반환 None
```

| | 원본 | 반환 |
|:---|:---|:---|
| `sorted(x)` | 유지 | 새 리스트 |
| `x.sort()` | 변경 | None |

### key — 정렬 기준
```python
sorted(members, key=lambda m: m["salary"], reverse=True)   # 연봉 순
sorted(words, key=len)                                     # 글자 수 순
sorted(members, key=lambda m: (m["team"], -m["salary"]))   # 다중 기준
```

> `key=함수` → 각 요소에 함수를 적용한 결과로 정렬. 튜플 `(기준1, 기준2)`로 1차·2차 정렬.

---

## 실제 예시

```python
# 성적 순위
ranked = sorted(students, key=lambda s: s["total"], reverse=True)
for rank, s in enumerate(ranked, 1):
    print(rank, s["name"])
```

---

## 자주 헷갈리는 것

**`x = list.sort()` 함정**: `sort()`는 None을 반환 → `x`가 None이 됨. 정렬 결과를 받으려면 `sorted()`.

**문자열 정렬**: 사전순(대문자가 소문자보다 앞). 대소문자 무시하려면 `key=str.lower`.

**오름/내림**: 기본 오름차순. 내림은 `reverse=True` 또는 숫자면 `key=lambda x: -x`.

---

## 더 알면 좋은 것

📌 **안정 정렬(stable)**: 같은 key값은 원래 순서 유지 → 다중 정렬을 단계적으로 적용 가능.

📌 **`max`/`min`도 key**: `max(members, key=lambda m: m["salary"])` — 최고 연봉자.
