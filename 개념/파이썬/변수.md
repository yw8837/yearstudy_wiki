# 변수 (Variable)

**정의**: 데이터를 담는 이름 붙은 메모리 공간. `=`으로 값을 저장한다.

---

## 왜 필요한가

프로그램은 데이터를 계속 사용한다. 같은 값을 여러 곳에서 쓰거나, 연산 결과를 나중에 쓰려면 이름을 붙여 저장해야 한다. 그게 변수다.

---

## 어떻게 작동하나

### 기본 사용

```python
# 대입 연산자 =
# "오른쪽 값을 왼쪽 이름에 저장"
name = "홍길동"       # 문자열 저장
age = 25             # 정수 저장
pi = 3.14159         # 실수 저장

# 값 읽기
print(name)          # 홍길동

# 값 변경
age = 26             # 덮어쓰기
age = age + 1        # 현재값 기반 업데이트 (= 27)
age += 1             # 동일 (= 28, 축약 표현)
```

### 변수 이름 규칙

```python
# 가능
user_name = "홍길동"    # 스네이크 케이스 (Python 표준)
score1 = 95
_private = "내부용"     # 언더스코어 시작 가능

# 불가능
1score = 95            # SyntaxError: 숫자로 시작 불가
my-name = "홍"         # SyntaxError: 하이픈 불가
my name = "홍"         # SyntaxError: 공백 불가
for = 10              # SyntaxError: 예약어 사용 불가
```

### 네이밍 관례

```python
# snake_case: 파이썬 변수·함수 표준 (PEP 8)
student_name = "홍길동"
total_score = 100
is_logged_in = True

# CamelCase: 클래스 이름에 사용
class StudentInfo:
    pass

# UPPER_CASE: 상수 (변하지 않는 값)
MAX_SIZE = 100
PI = 3.14159
```

### 다중 대입

```python
# 여러 변수 동시 할당
a, b, c = 1, 2, 3
x, y = y, x          # 값 교환 (파이썬만의 간결한 방식)

# 같은 값으로 초기화
a = b = c = 0
```

## 변수의 범위 — 스코프(Scope): 지역 / 전역

변수는 **어디서 만들었느냐**에 따라 통하는 범위가 다르다. 이게 스코프(scope).

| 구분 | 정의 위치 | 접근 가능 범위 |
|:---|:---|:---|
| **지역 변수**(Local) | 함수 **안** | 그 함수 안에서만 |
| **전역 변수**(Global) | 함수 **밖** | 프로그램 어디서나 (읽기) |

### ① 지역 변수는 함수 밖에서 못 쓴다 (`NameError`)

함수 안에서 만든 변수는 함수가 끝나면 사라진다. 밖에서 부르면 "그런 이름 없다"고 에러.

```python
def greet():
    msg = "함수 안에서 안녕!"   # 지역 변수
    print(msg)

greet()          # 함수 안에서 안녕!
print(msg)       # NameError: name 'msg' is not defined
```

### ② 전역 변수는 함수 안에서도 읽을 수 있다

```python
msg = "Python is awesome!"   # 전역 변수

def display():
    print("함수 안:", msg)    # 읽기 OK

display()                    # 함수 안: Python is awesome!
print("함수 밖:", msg)        # 함수 밖: Python is awesome!
```

### ③ Shadowing — 같은 이름의 지역이 전역을 가린다

함수 안에 전역과 같은 이름의 변수를 만들면, 그 함수 안에서는 지역이 전역을 "가린다". 전역 자체는 그대로 유지된다.

```python
s = "I love yeardreamschool"

def fun():
    s = "Me too."    # 전역 s를 가리는 새 지역 s
    print(s)         # Me too.

fun()
print(s)             # I love yeardreamschool  ← 전역은 안 바뀜
```

### ④ 전역을 함수 안에서 수정하려면 `global`

함수 안에서 전역에 그냥 대입하면 **새 지역 변수**가 생길 뿐, 전역은 안 바뀐다. 진짜 바꾸려면 `global` 선언.

```python
count = 0
def increase():
    global count         # "이 count는 전역이다"
    count = count + 1

increase()
print(count)             # 1
increase()
print(count)             # 2   ← global 덕분에 누적
```

`global` 없이 매개변수로 받으면 그 변수는 **지역**이라 전역에 영향이 없다(대조).

```python
count = 0
def increase(count=0):   # 매개변수 count = 지역
    count = count + 1
    return count

increase()        # 1
increase()        # 1   ← 매번 0에서 시작
print(count)      # 0   ← 전역 count는 그대로
```

> ⚠️ `global` 남용은 코드 추적을 어렵게 한다. 가능하면 값을 `return`으로 주고받는 게 좋다.

## 실제 예시

```python
# 가독성 좋은 변수명 vs 나쁜 변수명
# 나쁨
x = 1200
y = 1.1

# 좋음
base_salary = 1200
tax_rate = 1.1
total = base_salary * tax_rate

# 의미 없는 단일 문자는 반복문 카운터에만
for i in range(10):
    print(i)
```

## 자주 헷갈리는 것

**`=` vs `==`**: `=`는 대입(저장), `==`는 비교(같은지 확인). `if x = 5`는 SyntaxError. 조건에서는 `==`.

**덮어쓰기 위험 — 의미 있는 이름이 중요한 이유**: 같은 변수명에 다시 대입하면 기존 값은 흔적 없이 사라진다. `a`, `b`, `c`처럼 모호하게 쓰면 ① 무슨 값인지 의미를 잃고 ② 코드가 커질수록 어디서 덮였는지 추적이 어렵다. 예를 들어 `기준금리` 같은 핵심 값이 실수로 덮어써지면 그걸 쓰는 모든 계산·로직이 조용히 틀어진다. → 변수명을 **의미가 드러나게** 짓는 건 단순 스타일이 아니라 오류 방지책이다.

**"변수는 데이터 자체"**: 정확하지 않다. 변수는 데이터가 저장된 메모리 위치를 가리키는 이름표다. 같은 데이터를 여러 변수가 가리킬 수 있다.

```python
a = [1, 2, 3]
b = a          # b도 같은 리스트를 가리킴
b.append(4)
print(a)       # [1, 2, 3, 4] ← a도 바뀜! (같은 메모리를 가리키기 때문)

# 독립적인 복사가 필요하면
b = a.copy()   # 또는 b = a[:]
```

**"변수명은 한글도 된다"**: 기술적으로는 가능하지만 절대 쓰지 않는다. 영어로 짓는 게 관례이고, 한글 변수명은 호환성·가독성 문제를 일으킨다.

**전역을 "바꾸려고" 그냥 대입했는데 안 바뀐다**: 함수 안에서 `x = ...`은 전역 수정이 아니라 **새 지역 변수 생성**이다. 전역을 바꾸려면 `global x`가 필요하다(위 ④ 참조).
