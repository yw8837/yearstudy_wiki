# 서열척도 (Ordinal)

**정의**: **순서·등급**은 있으나 **간격이 일정하지 않은** [[척도]]. ADsP는 "순서척도"라 부른다.

---

## 왜 필요한가

만족도·학점처럼 **순위는 있지만 간격을 수치로 못 박는** 데이터를 표현한다. 상>중>하는 알지만 "상과 중의 차이 = 중과 하의 차이"라고 단정할 수 없다.

---

## 어떻게 작동하나

- 가능한 연산: 같다/다르다 + **대소(순위) 비교**, 중앙값·백분위.
- 불가능: 간격 기반 평균(엄밀히는), 비율.

```
만족도: 매우불만 < 불만 < 보통 < 만족 < 매우만족
        (순서 O, 간격 균등 X)
```

---

## 실제 예시

만족도(상/중/하), 학점(A/B/C), 영화 별점, 직급.

---

## 자주 헷갈리는 것

**순서 ≠ 등간격.** 별점 4와 5의 차이가 1과 2의 차이와 같다는 보장이 없다 → 평균 별점은 관례적으로 쓰되 해석에 주의.
