# 오픈웨이트 모델 (Open-weight Model)

**정의**: 모델의 **가중치(weights)가 공개**되어 누구나 내려받아 직접 구동할 수 있는 모델. 단, 실행에는 GPU 등 자원이 필요하다.

---

## 왜 필요한가

웹 서비스·API는 편하지만 외부 회사에 데이터를 보내야 하고, 비용·정책에 종속된다. 오픈웨이트는 모델을 **내 환경(내 GPU)** 에 올려 직접 돌릴 수 있어, 데이터 통제·커스터마이징·오프라인 사용이 가능하다.

---

## 어떻게 작동하나

모델 활용 3가지 방식 중 가장 자유도 높은 ③번:

```
① 웹 서비스  : ChatGPT/Claude/Gemini  (설치 없이)
② API 호출   : OpenAI/Anthropic/Google (코드)
③ 오픈웨이트 : Llama/DeepSeek/Gemma   (내 GPU에 직접) ← 여기
```

**대표**: Llama(Meta), DeepSeek, Gemma(Google).

---

## 자주 헷갈리는 것

**"오픈웨이트 = 오픈소스"**: 정확히 같지 않다. 가중치는 공개돼도 학습 데이터·코드·라이선스 조건은 제한될 수 있다. "가중치 공개"가 핵심.

**"공짜로 무한정 쓴다"**: 모델은 무료여도 구동할 **GPU 인프라 비용**이 든다.
