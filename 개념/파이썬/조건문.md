# 조건문 (Conditional)

**정의**: 조건이 참(True)이면 특정 코드를 실행하고, 아니면 다른 코드를 실행하는 분기 구조.

---

## 왜 필요한가

프로그램이 항상 같은 일만 하면 의미가 없다. 상황에 따라 다르게 동작해야 한다. 로그인 성공/실패, 성인/미성년 판단, 점수에 따른 등급 — 모두 조건문으로 구현한다.

---

## 어떻게 작동하나

### 기본 구조

```python
if 조건:            # 조건이 True면 아래 블록 실행
    실행할 코드     # 들여쓰기 필수 (4칸 또는 Tab)
elif 다른조건:      # 앞 조건이 False이고, 이 조건이 True면
    실행할 코드
else:               # 모든 조건이 False면
    실행할 코드
```

### 실제 예시

```python
# 성적 판별
score = int(input("점수 입력: "))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"학점: {grade}")
```

중요: `elif`는 순서대로 체크하고 첫 번째 True에서 멈춘다. 이미 `score >= 90`이 True면 나머지 elif는 체크하지 않는다.

### 비교 연산자

```python
a, b = 5, 10

a == b      # False  (같다, = 아님!)
a != b      # True   (다르다)
a < b       # True   (작다)
a > b       # False  (크다)
a <= b      # True   (작거나 같다)
a >= b      # False  (크거나 같다)
```

### 논리 연산자

```python
age = 25
has_id = True

# and: 둘 다 True여야 True
if age >= 18 and has_id:
    print("입장 가능")

# or: 하나라도 True면 True
if age < 13 or age > 65:
    print("할인 적용")

# not: True/False 반전
if not has_id:
    print("신분증 필요")
```

### 단축 평가 (Short-circuit Evaluation)

```python
# and: 앞이 False면 뒤는 체크 안 함
False and print("이건 출력 안 됨")

# or: 앞이 True면 뒤는 체크 안 함
True or print("이건 출력 안 됨")

# 실용 예시: 0으로 나누기 방지
if divisor != 0 and dividend / divisor > 1:
    print("크다")
```

### in / not in

```python
fruits = ["사과", "바나나", "체리"]
"사과" in fruits        # True
"포도" not in fruits    # True

# 계절 판별
month = 7
if month in [6, 7, 8]:
    print("여름")

# 문자열에서도 동작
"파" in "파이썬"         # True
"z" not in "Python"     # True
```

### 삼항 연산자 (Conditional Expression)

```python
# 긴 방식
if score >= 60:
    result = "합격"
else:
    result = "불합격"

# 한 줄로 (삼항 연산자)
result = "합격" if score >= 60 else "불합격"
```

## 실제 예시

```python
# 로그인 검증
if username == stored_username and password == stored_password:
    print("로그인 성공")
elif username == stored_username:
    print("비밀번호 오류")
else:
    print("아이디 없음")

# None 체크
result = some_function()
if result is None:          # None 체크는 == 대신 is 사용 권장
    print("결과 없음")

# 빈 컨테이너 체크
items = []
if not items:               # 빈 리스트는 False로 평가
    print("목록이 비어있음")
```

## 자주 헷갈리는 것

**`=` vs `==`**: 조건문에서 대입 연산자 `=`를 쓰면 SyntaxError 또는 의도치 않은 동작.
```python
if x = 5:    # SyntaxError ❌
if x == 5:   # 올바른 비교 ✅
```

**여러 `if` vs `elif`**: 차이가 중요하다.
```python
score = 95

# 여러 if: 독립적으로 체크 — 여러 번 출력 가능
if score >= 90: print("A")   # 출력됨
if score >= 80: print("B")   # 출력됨
if score >= 70: print("C")   # 출력됨

# elif: 첫 True에서 멈춤
if score >= 90: print("A")   # 출력됨, 이후 체크 안 함
elif score >= 80: print("B") # 체크 안 함
```

**들여쓰기 혼용**: 스페이스와 탭을 섞으면 TabError. 에디터에서 탭을 스페이스로 자동 변환하도록 설정 권장.

## 더 알면 좋은 것

📌 **match-case (Python 3.10+)**: C/Java의 switch-case와 유사한 패턴 매칭.
```python
match command:
    case "quit":
        print("종료")
    case "hello":
        print("안녕")
    case _:          # default
        print("알 수 없는 명령")
```

📌 **Truthy / Falsy**: 파이썬에서 False로 평가되는 값들: `None`, `False`, `0`, `0.0`, `""`, `[]`, `{}`, `()`. 나머지는 모두 True.
