## 1. 왜 DB인가 / 어떤 DB인가 → [[데이터베이스]] · [[NoSQL]]

- **파일처리의 한계** = 데이터 종속성·중복성·무결성 훼손 → 그래서 DB.
- **[[관계형데이터베이스|RDB]]**: 표·관계·명확한 스키마·무결성(MySQL/PostgreSQL/MariaDB). **[[NoSQL]]**: 유연한 스키마·비정형·수평확장(MongoDB/Redis/Cassandra).
- 팀 프로젝트엔 파일형 SQLite 부적절 → 클라우드 DB 권장. 분석 현업은 BigQuery 등 DW.

---

## 2. SQL 3분류 + 자료형 → [[DDL]] · [[DML]] · [[DCL]] · [[SQL자료형]]

```
DDL  구조 정의   CREATE / ALTER / DROP
DML  데이터 조작 SELECT / INSERT / UPDATE / DELETE
DCL  접근 제어   GRANT / REVOKE
```

- **[[SQL자료형]]**: `VARCHAR(n)`·`INT`·`FLOAT`·`DATETIME`. DBMS마다 다름, 확장성 고려.
- **[[ALTER TABLE]]**: SQLite는 `ADD COLUMN`만 직접 가능, 수정/제약변경은 테이블 재생성 우회.
- **[[DROP TABLE]]**: FK 있으면 자식→부모 역순.

---

## 3. 제약조건 — "마지막 방어선" → [[제약조건]]

비즈니스 규칙을 DB 레벨에서 강제 → 프론트/백 실수에 대비.

```sql
CREATE TABLE student (
    student_id VARCHAR(10) PRIMARY KEY,            -- NOT NULL + UNIQUE
    name       VARCHAR(20) NOT NULL,               -- 필수
    email      VARCHAR(50) UNIQUE,                 -- 중복 금지(NULL은 허용)
    grade      INT CHECK (grade >= 1 AND grade <= 4),  -- 범위 제한
    tuition_paid VARCHAR(1) DEFAULT 'N'            -- 미입력 시 기본값
);
```

- [[NOT NULL]] 빈 값 금지 / [[UNIQUE]] 중복 금지(**NULL 중복 허용**) / [[DEFAULT]] 기본값 / [[CHECK]] 범위 제한 / [[CONSTRAINT명시]] 이름 부여.
- 이메일=UNIQUE 적합, 이름=동명이인으로 부적합. 배송지=DEFAULT보다 NOT NULL이 나을 수 있음(비즈니스 판단).

---

## 4. 키 — 식별과 연결 → [[기본키]] · [[외래키]]

- **[[기본키]]** = 행 유일 식별 = NOT NULL + UNIQUE, 테이블당 1개.
- **[[외래키]]** = 다른 테이블 PK 참조 = 관계 정의 + 참조 무결성. (SQLite는 `PRAGMA foreign_keys = ON;` 필수)
- **[[후보키대체키슈퍼키]]**: 유일성+최소성=후보키, 선택 안 된 후보키=대체키, 최소성 불만족=슈퍼키.
- **[[복합기본키]]**: 연결 테이블에서 2컬럼 묶어 PK (`enrollment(student_id, course_id)`).

## 5. 무결성 — 제약이 지키는 목표 → [[무결성제약]]

| 무결성 | 수단 |
|:---|:---|
| 개체(PK NULL·중복 불가) | [[기본키]] |
| 참조(FK는 부모 PK에 존재 or NULL) | [[외래키]] |
| 도메인(허용 범위) | [[SQL자료형]] · [[CHECK]] |
| NULL / 고유 / 키 | [[NOT NULL]] · [[UNIQUE]] · PK |

## 6. 모델링 & ERD — 설계도 → [[데이터모델링]] · [[ERD]]

- **[[데이터모델링]]**: 개체·속성·관계 / 개념→논리→물리 설계.
- **[[ERD]]**: 표기법 = [[PeterChen표기법]](사각형·타원·마름모) / [[IE까마귀발표기법]](박스+까마귀발 `┼`/`○`/`<`).
- **[[카디널리티]]**: 1:1(예외)·1:N(기본)·N:M(중간 테이블로 분해).
- **[[ERDEditor]]**: SQL↔ERD 양방향 변환(Export SQL은 검토 필수).

## ⚠ SQLite 주의 (슬라이드=MySQL/표준 ↔ 실습=SQLite)

| 항목 | 표준/MySQL | SQLite |
|:---|:---|:---|
| 컬럼 수정 | `MODIFY/CHANGE COLUMN` | 미지원 → 재생성 우회 |
| 제약 추가/삭제 | `ADD/DROP CONSTRAINT` | 미지원 |
| 제약 조회 | `information_schema` | `PRAGMA table_info/foreign_key_list` |
| 외래키 | 기본 작동 | **기본 OFF** → `PRAGMA foreign_keys = ON;` |
