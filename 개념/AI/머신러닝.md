# 머신러닝 (Machine Learning)

**정의**: 명시적으로 규칙을 프로그래밍하지 않고, 데이터에서 패턴을 스스로 학습하는 AI 기술.

---

## 왜 필요한가

기존 프로그래밍은 인간이 규칙을 직접 작성한다. "고양이면 털이 있고, 수염이 있고, 발톱이 있으면..." 이 규칙이 수천 개가 되면 관리가 불가능하다.

머신러닝은 반대다. 고양이 사진 수백만 장을 보여주면 **모델이 스스로 규칙을 찾아낸다**.

```
기존: 개발자가 규칙 작성 → 컴퓨터가 규칙 실행
ML:  데이터를 보여줌 → 컴퓨터가 규칙을 스스로 찾음
```

---

## 어떻게 작동하나

### 머신러닝 학습 흐름

```
데이터 수집 → 전처리 → 모델 선택 → 학습(Training) → 평가 → 배포
```

**학습(Training)**: 모델이 데이터를 반복해서 보면서 예측을 하고, 정답과 비교해서 틀린 만큼 파라미터를 조정한다.

**손실 함수(Loss Function)**: 예측이 정답과 얼마나 다른지 측정. 이 값을 최소화하는 방향으로 학습.

### 학습 방식 3가지

**지도학습 (Supervised Learning)**
```
입력: 집 크기 84㎡, 방 3개, 강남구
정답: 실거래가 12억
→ 패턴 학습 후 새 집 가격 예측
```
이메일 스팸 분류, 질병 진단, 주가 예측에 사용.

**비지도학습 (Unsupervised Learning)**
```
입력: 고객 구매 이력 데이터 (정답 없음)
→ 비슷한 패턴끼리 자동 그룹화
→ "20대 여성 뷰티 구매 그룹", "30대 남성 IT기기 그룹" 등 발견
```
추천 시스템, 이상 탐지, 데이터 압축에 사용.

**강화학습 (Reinforcement Learning)**
```
에이전트가 행동 → 환경에서 보상/벌 받음 → 보상 최대화 전략 학습
알파고: 바둑 한 수 → 게임 결과로 보상 → 더 나은 수 학습
```

### 주요 알고리즘

| 알고리즘 | 용도 | 특징 |
|:---|:---|:---|
| 선형 회귀 | 연속값 예측 (가격, 온도) | 단순, 해석 쉬움 |
| 로지스틱 회귀 | 분류 (스팸 여부) | 확률 출력 |
| 결정 트리 | 분류·회귀 | 직관적, 과적합 주의 |
| 랜덤 포레스트 | 분류·회귀 | 결정 트리 여러 개 앙상블 |
| SVM | 분류 | 소규모 데이터에 강함 |
| K-평균 | 군집화 | 비지도학습 대표 |

## 실제 예시

- 유튜브 추천: 시청 기록 기반 협업 필터링
- 신용카드 사기 탐지: 이상 패턴 감지 (비지도 학습)
- 넷플릭스 "회원님을 위한 추천": 협업 필터링 + 콘텐츠 기반 필터링 혼합
- Google 검색 랭킹: 수천 가지 특성 기반 랭킹 모델

---

## 자주 헷갈리는 것

**"데이터가 많으면 무조건 잘 된다"**: 질 나쁜 데이터 1억 건보다 잘 정제된 데이터 10만 건이 낫다. **"Garbage In, Garbage Out"**.

**"정확도가 높으면 좋은 모델"**: 과적합(Overfitting)을 주의해야 한다. 학습 데이터에서는 99%인데 새 데이터에서는 60%라면 실용적이지 않다.

**"머신러닝 = 딥러닝"**: 딥러닝은 머신러닝의 한 분야다. 딥러닝 외에도 선형 회귀, SVM, 랜덤 포레스트 등 수십 가지 머신러닝 알고리즘이 있다.

---

## 더 알면 좋은 것

📌 **과적합(Overfitting) vs 과소적합(Underfitting)**: 학습 데이터에 너무 딱 맞춰지면 새 데이터에서 틀림(과적합). 너무 단순하면 학습도 못 함(과소적합). 검증 데이터셋으로 균형을 찾는다.

📌 **교차 검증(Cross-Validation)**: 데이터를 여러 번 다르게 나눠서 학습·검증을 반복. 모델 성능을 더 신뢰할 수 있게 평가.

📌 **주요 Python 라이브러리**: scikit-learn (전통적 ML), XGBoost (경진대회 최강), pandas (데이터 처리), numpy (수치 계산).
