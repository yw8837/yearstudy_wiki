# 리눅스 파일·디렉터리 명령어

**정의**: 터미널에서 파일과 폴더를 보고·만들고·옮기고·지우는 기본 명령어 모음.

---

## 왜 필요한가

서버(클라우드)는 대부분 검은 화면(CLI)뿐이라 마우스가 없다. 윈도우에서 마우스로 하던 일(폴더 열기·새 폴더·복사·삭제)을 **키보드 명령어로** 해야 한다. 이게 리눅스 작업의 기본기다.

---

## 어떻게 작동하나

### 경로 기호

| 기호 | 뜻 |
|:---:|:---|
| `/` | 최상위(뿌리) |
| `~` | 홈 폴더 |
| `.` | 현재 폴더 |
| `..` | 상위 폴더 |

### 위치 확인·이동

```bash
pwd              # 현재 위치(절대 경로) 출력
ls               # 파일·폴더 목록
ls -al           # 숨김파일(-a) + 상세정보(-l)
cd ~/Desktop     # 폴더 이동
cd ..            # 상위 폴더로
cd ~             # 홈으로
```

### 폴더 만들기

```bash
mkdir myfolder        # 폴더 생성
mkdir -p a/b/c        # 중첩 폴더 한 번에
```

### 파일 만들기·내용 보기

```bash
touch hello.txt       # 빈 파일 생성
cat hello.txt         # 전체 내용 출력
head -n 5 hello.txt   # 앞 5줄
tail hello.txt        # 마지막 10줄
tail -f app.log       # 실시간 모니터링 (로그)
```

### 복사·이동·삭제

```bash
cp a.txt b.txt        # 파일 복사
cp -r src/ bak        # 폴더 복사 (-r 필수)
mv a.txt archive/     # 이동
mv a.txt b.txt        # 이름 변경 (같은 위치)
rm a.txt              # 파일 삭제 (휴지통 없음!)
rm -r folder          # 폴더 삭제
rm -rf folder         # 강제 삭제 ← 매우 주의
```

---

## 실제 예시

```bash
# 프로젝트 폴더 만들고 진입해서 파일 생성
mkdir -p project/src
cd project/src
touch main.py

# 백업 후 원본 삭제
cp -r project project_backup
```

---

## 자주 헷갈리는 것

**`rm`은 휴지통이 없다**: 삭제 즉시 영구 삭제. 특히 `rm -rf`는 경로 한 번 더 확인. `rm -rf /`는 시스템 전체 삭제 — 절대 금지.

**`cp`로 폴더 복사 시 `-r` 필수**: 폴더는 `cp -r` 안 쓰면 복사 안 됨.

**절대 경로 vs 상대 경로**: `/home/user/a`(뿌리부터) vs `../a`(현재 기준).

**디렉터리도 파일이다**: 리눅스에서 디렉터리(폴더)는 그 안에 든 파일들의 정보를 담는 **특수한 파일**이다. "모든 것은 파일이다" 철학의 한 예.

## 링크와 마운트

이름은 비슷하지만 별개 개념. 둘 다 "다른 것에 연결"한다는 점만 공통.

### 링크(Link) — 또 다른 접근 경로

Windows의 "바로가기"처럼, 원본 파일에 접근하는 별도의 경로를 만든다.

| 종류 | 설명 |
|:---|:---|
| **심볼릭 링크 (Symbolic / Soft)** | 원본 경로를 가리키는 바로가기. 원본을 지우면 깨진다. |
| **하드 링크 (Hard)** | 같은 파일 실체를 가리키는 또 하나의 이름. 원본을 지워도 살아있다. |

```bash
ln -s /원본/경로 link_name   # 심볼릭 링크 생성 (-s)
ln /원본/경로 hardlink       # 하드 링크 생성
```

### 마운트(Mount) — 저장장치를 폴더에 연결

USB·외장디스크·네트워크 드라이브 같은 **저장 공간을 특정 디렉터리에 연결**해서, OS가 그 폴더를 통해 장치 안을 읽고 쓸 수 있게 만드는 작업.

- 실생활 예) **구글 코랩(Colab)에서 구글 드라이브를 마운트**하면, 코랩이 내 드라이브의 파일을 자기 폴더처럼 읽고 쓸 수 있다.

```python
# 구글 코랩에서 드라이브 마운트
from google.colab import drive
drive.mount('/content/drive')
```

## 더 알면 좋은 것

📌 **`Tab` 자동완성**: 파일·폴더명 앞 글자만 치고 Tab → 나머지 자동완성. 오타 방지.

📌 **`↑` 방향키 / `history`**: 이전 명령어 재사용 / 입력 이력 조회.

📌 **`Ctrl + L`**: 화면 청소 (= `clear`).

📌 **`--help` / `man`**: `ls --help`(빠른 사용법), `man ls`(공식 설명서, `q`로 종료).
