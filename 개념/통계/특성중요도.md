# 특성 중요도 (Feature Importance)

**정의**: 모델에서 각 특성(변수)이 예측에 **얼마나 크게 기여하는지**를 나타낸 값. 로지스틱 회귀에서는 흔히 **계수의 절댓값 크기**로 근사한다.

---

## 왜 필요한가

"어떤 변수가 생존에 가장 큰 영향을 주는가"를 알면 모델을 해석하고 설명할 수 있다. titanic 실습은 계수를 절댓값 순으로 정렬해 수평 막대(barh)로 시각화한다.

---

## 어떻게 작동하나

```python
# titanic 실습: 절편 제외 계수의 절댓값 정렬 → barh
coef_vals = result.params[1:]                 # 절편(const) 제외
sorted_idx = np.argsort(np.abs(coef_vals))[::-1]   # 절댓값 내림차순
colors = ['steelblue' if c > 0 else 'salmon' for c in coef_vals[sorted_idx]]
plt.barh([feature_cols[i] for i in sorted_idx], coef_vals[sorted_idx], color=colors)
# 양(+)=파랑=생존확률 증가, 음(-)=빨강=감소
```

- 계수 부호 = 생존에 대한 방향(+/−), 절댓값 크기 = 영향력.
- [[오즈비]] `exp(계수)`로 바꿔 "1단위 증가 시 오즈 배수"로도 해석 가능.

---

## 자주 헷갈리는 것

**계수 절댓값 = 중요도는 특성 스케일에 좌우된다.** 표준화하지 않은 변수라면 단위가 큰 특성(예: fare)의 계수가 작게, 단위가 작은 특성의 계수가 크게 나올 수 있어 왜곡된다. 공정 비교하려면 **표준화 후 계수**를 봐야 한다.

---

## 더 알면 좋은 것

📌 titanic 실습 코드는 표준화 여부를 명시하지 않으므로 계수 크기 해석은 주의해야 한다(스케일 의존). 트리 계열 모델은 다른 방식(불순도 감소·permutation importance)으로 중요도를 잰다(본 실습 범위 밖). ⚠ 표준화 주의는 표준 개념 보강, 노션 원문엔 없음.
