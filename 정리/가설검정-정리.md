# 가설검정 정리

모수에 대한 주장을 표본으로 판단하는 절차. **오류·유의수준·p-value가 핵심.** 실전 검정 코드는 [[빅분기-작업형3유형-정리]] 참조.

> 강의 출처: [[0622-확률과통계적추론]] · 상세: [[가설검정]] · [[귀무가설과대립가설]] · [[유의수준]] · [[p-value]]

---

## 1. 가설 설정 → [[귀무가설과대립가설]]

- **귀무가설 H₀:** 기본·차이 없음(예: `p=1/2`).
- **대립가설 H₁:** 입증하려는 연구가설(관심 대상, 예: `p≠1/2`).
- **양측**(≠) / **단측**(>, <).

> **표현 규칙(중요):** 항상 **귀무가설 기준**으로 말한다.
> 대립 채택 = "H₀을 **기각한다**" / 귀무 채택 = "H₀을 **기각할 수 없다**".
> "귀무가설 채택"(X) → "귀무가설을 기각하지 못한다"(O).

---

## 2. 오류의 종류 → [[1종오류와2종오류]] · [[유의수준]]

| | H₀ 참 | H₀ 거짓 |
|:--|:--|:--|
| **H₀ 기각** | 1종 오류 α (무죄→유죄) | 옳음 |
| **H₀ 채택** | 옳음 | 2종 오류 β (유죄→무죄) |

- 1종·2종은 **반비례** → 동시 최소화 불가. **1종을 먼저 최소화**(비용이 큰 쪽).
- **[[유의수준]] α** = 1종 오류 최대 허용확률(0.01~0.10, 보통 0.05).
- 신뢰수준 = 1-α, **검정력 = 1-β**.

---

## 3. 검정 절차 → [[검정통계량과기각역]]

```
가설 설정 → 표본 관측 → 검정통계량 선택 → 관측값 계산
         → 기각역/유의확률 계산 → 판정
```

- **검정통계량:** 판정에 쓰는 표본의 함수(예: X̄로 μ 검정, Z·t·F·χ²).
- **[[검정통계량과기각역|기각역]]:** H₀을 기각하는 구간(`R: X̄ ≤ c`).

---

## 4. p-value 판정 → [[p-value]]

```
α > p-value  →  H₀ 기각 (유의함, 대립 지지)
α < p-value  →  H₀ 기각 못함
```

- p-value = 표본이 대립가설을 지지하는 정도(0~1).
- 표기: `p<0.05`(*) 유의 / `<0.01`(**) / `<0.001`(***).
- **작업형 3유형 전체를 관통하는 한 줄:** `p < 0.05`면 기각.

---

## 5. 이항검정·z검정 → [[이항검정]]

```python
scipy.stats.binom_test(x, n, p, alternative='two-sided')  # 모수 p 검정
# 최신 scipy는 binomtest 권장 (binom_test deprecated)
# 모평균 z검정: Z = (X̄ - μ₀) / (σ/√n) ~ N(0,1)  (CLT로 정규근사, n≥30)
```

- ⚠ **[원문 확인]** 슬라이드 p87 우측 단측 기각역 `R: Z ≥ -z_α`는 부호 오기 추정(통상 `Z ≥ z_α`).
