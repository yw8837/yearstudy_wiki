# 실무 문법 패턴 · 라이브러리 정리

심화 문법 6가지와 라이브러리 활용을 **한눈에**. 상세는 개념 링크에서.

## 1. 실무 심화 문법 6가지

```python
# ① f-string
f"{val:.2f}"  f"{n:,}"  f"{r:.1%}"  f"{s:>7}"

# ② 컴프리헨션 → [[컴프리헨션]]
[x**2 for x in seq]
[x for x in seq if 조건]            # 필터(뒤)
[A if 조건 else B for x in seq]      # 변환(앞)

# ③ sorted → [[정렬]]
sorted(data, key=lambda m: m["salary"], reverse=True)
sorted(data, key=lambda m: (m["team"], -m["salary"]))   # 다중

# ④ enumerate
for i, v in enumerate(seq, start=1): ...

# ⑤ lambda · map · filter → [[람다]]
list(map(lambda x: x*2, nums))
list(filter(lambda x: x%2==0, nums))

# ⑥ __name__
if __name__ == "__main__": ...       # 직접 실행 시만
```

## 2. 라이브러리 활용 → [[라이브러리]]

```bash
pip install pandas             # 설치 (우리는 uv add)
pip freeze > requirements.txt  # 목록 저장
```
```python
import pandas as pd            # 사용 (별칭 관례)
import numpy as np
```
**공유(배포)**: `python -m build` → `twine upload dist/*` → PyPI에 올라가 누구나 `pip install`.

- 표준(math·random) vs 외부(numpy·pandas·requests) / 창고 = PyPI
- 모듈(.py) ⊂ 패키지(폴더) ⊂ 라이브러리(배포단위)
