# 자료형 (Data Type)

**정의**: 데이터의 종류. 파이썬은 값에 따라 자료형이 자동 결정된다.

---

## 왜 필요한가

컴퓨터는 숫자 `3`과 문자 `"3"`을 완전히 다르게 처리한다. `3 + 3 = 6`이지만 `"3" + "3" = "33"`이다. 자료형은 이 차이를 결정한다.

---

## 어떻게 작동하나

### 5가지 기본 자료형

```python
# int (정수)
age = 25
score = -100
big = 1_000_000    # 언더스코어로 가독성 향상 (Python 3.6+)

# float (실수)
pi = 3.14159
height = 175.5
scientific = 1.5e10    # 1.5 × 10^10

# str (문자열)
name = "홍길동"
greeting = '안녕하세요'
multi = """여러 줄
문자열"""

# list (리스트)
fruits = ["사과", "바나나", "체리"]
mixed = [1, "텍스트", True, 3.14]    # 다양한 자료형 혼합 가능
nested = [[1, 2], [3, 4]]             # 중첩 리스트

# bool (불리언)
is_adult = True
has_error = False
# True/False는 대소문자 구분 (true는 오류)
```

### type() 으로 자료형 확인

```python
print(type(42))          # <class 'int'>
print(type(3.14))        # <class 'float'>
print(type("hello"))     # <class 'str'>
print(type([1, 2]))      # <class 'list'>
print(type(True))        # <class 'bool'>

# bool은 내부적으로 int
print(True + True)       # 2
print(True + 1)          # 2
print(False * 100)       # 0
```

### 형 변환 (Type Casting)

```python
# str → int
int("42")           # 42
int("42.5")         # ValueError! 소수점 있으면 불가
int(float("42.5"))  # 42 (float 먼저, 그 다음 int)

# str → float
float("3.14")       # 3.14
float("42")         # 42.0

# 숫자 → str
str(100)            # "100"
str(3.14)           # "3.14"

# str → list
list("abc")         # ['a', 'b', 'c']
list("파이썬")       # ['파', '이', '썬']

# 주의: input()은 항상 str 반환
age = input("나이: ")    # "25" (str)
age_int = int(age)       # 25 (int) — 계산하려면 변환 필수
```

### 가변(Mutable) vs 불변(Immutable)

```python
# list: 가변 — 생성 후 값 변경 가능
nums = [1, 2, 3]
nums[0] = 99
print(nums)        # [99, 2, 3]  ✅

# str: 불변 — 생성 후 변경 불가
text = "hello"
text[0] = "H"      # TypeError: 'str' object does not support item assignment ❌

# 불변 자료형: int, float, str, tuple, bool
# 가변 자료형: list, dict, set
```

## 실제 예시

```python
# 흔한 실수: 문자열 + 숫자
age = 25
print("나이는 " + age + "세")       # TypeError ❌
print("나이는 " + str(age) + "세")  # OK ✅
print(f"나이는 {age}세")            # f-string으로 더 깔끔하게 ✅

# input()의 함정
num1 = input("숫자 1: ")   # "10" 입력
num2 = input("숫자 2: ")   # "20" 입력
print(num1 + num2)          # "1020" ← 문자열 이어붙이기!
print(int(num1) + int(num2))  # 30 ✅
```

## 자주 헷갈리는 것

**"숫자처럼 보이면 숫자다"**: `phone = "010-1234-5678"`은 따옴표 안에 있으니 str. `"3"`, `"100"` 모두 str.

**"True는 1, False는 0"**: 파이썬에서 `bool`은 `int`의 서브클래스. `True == 1`이 참이고, `True + True == 2`가 된다. 의도치 않게 쓰면 버그.

**`int("3.14")`가 동작한다"**: 안 된다. ValueError. `int(float("3.14"))` 처럼 float을 거쳐야 한다.

## 더 알면 좋은 것

📌 **None**: 파이썬의 "값 없음". 다른 언어의 null/NULL에 해당. `None`은 bool로 평가하면 `False`. `if result is None`으로 체크.

📌 **튜플(tuple)**: 불변 리스트. `(1, 2, 3)` — 변경 불가. 함수가 여러 값을 반환할 때, 딕셔너리 키로 쓸 때 사용.

📌 **딕셔너리(dict)**: 키-값 쌍. `{"name": "홍길동", "age": 25}` — 이름으로 값 접근. 파이썬 3.7+부터 입력 순서 유지.

📌 **집합(set)**: 중복 없는 자료구조. `{1, 2, 3}`. 빠른 포함 여부 확인, 중복 제거에 유용.
