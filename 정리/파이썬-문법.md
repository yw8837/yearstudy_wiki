## 1. 출력·입력

```python
print("Hello", "Python")     # 콤마 → 공백 구분 출력
name = input("이름: ")        # 입력값은 항상 str!
```

- `print(a, b)` → 사이에 공백 자동
- `input()` 결과는 **무조건 문자열** → 숫자로 쓰려면 `int()`/`float()`

---

## 2. 자료형 → [[자료형]]

| 자료형 | 예시 | 변경 |
|:---|:---|:---:|
| `int` 정수 | `25` | — |
| `float` 실수 | `3.14` | — |
| `str` 문자열 | `"hi"` | ❌ 불변 |
| `list` 리스트 | `[1, 2]` | ✅ 가변 |
| `bool` 논리 | `True` | — |

```python
type(3.14)        # <class 'float'>  — 자료형 확인
int("42")         # 42   (형 변환)
str(100)          # "100"
list("ab")        # ['a', 'b']
```

---

## 3. 변수 → [[변수]]

```python
my_name = "홍길동"     # 변수 = 값
score = 50
score = 100            # 덮어쓰기 가능
```

- 숫자로 시작 ❌, 공백 ❌, 예약어 ❌
- 스네이크 표기법 권장: `total_score`

---

## 4. 연산자

```python
13 // 5    # 2   몫
13 % 5     # 3   나머지
2 ** 4     # 16  제곱
"안녕" * 3  # 안녕안녕안녕   문자열 반복
"a" + "b"  # ab            문자열 이어붙이기
```

- 나눗셈 `/`는 **항상 실수** (`6 / 2` → `3.0`)
- 문자열 + 숫자 → `TypeError` (숫자를 `str()`로 변환 필요)

---

## 5. 인덱싱·슬라이싱

```python
word = "Python"
word[0]      # P    (0부터)
word[-1]     # n    (뒤에서)
word[1:4]    # yth  ([시작:끝], 끝 미포함)
word[::-1]   # 거꾸로
```

- 문자열·리스트 공통 (둘 다 순서가 있는 '시퀀스')
- `값 in 시퀀스` 포함 여부, `len()` 길이, `+` 이어붙이기, `*` 반복

---

## 6. 조건문 → [[조건문]]

```python
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "F"
```

- 조건 뒤 `:` + 들여쓰기(4칸) 필수
- 비교: `==` `!=` `<` `>` `<=` `>=`  /  논리: `and` `or` `not`
- `값 in 리스트` → 포함 여부 (`month in [6,7,8]`)
- `=`(대입) ≠ `==`(비교) 주의

---

## 7. 리스트 (기초) → [[리스트]]

```python
nums.append(7)      # 끝에 추가
nums.insert(0, 9)   # 위치 삽입
nums.remove(3)      # 값으로 삭제 (첫 번째만)
nums.sort()         # 정렬(원본 변경, 반환 None)
nums.sort(reverse=True)  # 내림차순
```

- `str`(불변) vs `list`(가변): 리스트만 `append` 가능
- 리스트 복사: `b = a` 는 같은 리스트를 가리킴 → 진짜 복사는 `a.copy()` / `a[:]`
