# MECE (중복 없이·누락 없이)

**정의**: **M**utually **E**xclusive, **C**ollectively **E**xhaustive. 항목을 **상호 배타(중복 없이)** + **전체 포괄(누락 없이)** 로 나누는 분류 원칙. 바바라 민토 『논리의 기술』에서 근거를 짜는 기준.

---

## 왜 필요한가

근거가 서로 겹치면 같은 말을 반복하게 되고, 빠진 게 있으면 결론에 구멍이 생긴다. MECE는 **근거 묶음을 깔끔하고 빠짐없이** 만들어 [[피라미드원칙]]의 근거층을 탄탄하게 한다.

```
중복 O / 누락 O  : ❌ 산만하고 구멍 있음
중복 X / 누락 O  : ❌ 깔끔하지만 빠진 게 있음
중복 O / 누락 X  : ❌ 다 담았지만 겹쳐서 비효율
중복 X / 누락 X  : ✅ MECE
```

---

## 강사 강조

- 미들 라인(근거 3개 등)은 **서로 중복되면 안 되고, 모두 탑(결론)을 향해야** 한다.
- 사고방식은 **연역·귀납을 병행.**
- 실무에서 직접 해보면 중복·누락이 생각보다 많아 어렵다.

---

## 자주 헷갈리는 것

**"많이 나열하면 누락이 없다"**: 양이 아니라 **분류 기준** 의 문제. 기준이 흐리면 겹치거나 빠진다.

**"MECE면 무조건 좋은 글"**: MECE는 근거 **구조** 의 조건일 뿐. 각 근거가 결론을 향하는지([[피라미드원칙]]), 도입부가 설득적인지([[SCQA]])는 별개.

---

## 더 알면 좋은 것

📌 분류 기준을 먼저 정하면 MECE가 쉬워진다 (예: 시간순 / 구조순 / 중요도순).

📌 [[SCQA]]·[[피라미드원칙]]과 한 세트 — 민토식 논리 글쓰기의 3축.
