# 브로드캐스팅 (Broadcasting)

**정의**: [[NumPy]]에서 **서로 다른 [[shape]]의 배열 간 연산**을 가능하게 하는 규칙. 작은 배열이 큰 배열 모양에 맞게 "가상으로" 확장되어 연산된다(데이터 복제 없이).

---

## 왜 필요한가

🔑 **강사가 "수업 중 가장 중요한 개념"이라 강조.** 열별 표준화·스칼라 덧셈처럼 **모양이 다른 배열을 그대로 연산**하고 싶을 때 핵심. [[벡터화]]와 함께 NumPy의 빠른 연산을 떠받친다.

---

## 어떻게 작동하나

규칙: 두 shape를 **뒤에서부터 비교**해 각 축이 **같거나 한쪽이 1**이면 호환(1인 축이 상대 길이로 확장).

```python
import numpy as np
data = np.array([1.0, 2.0]); data * 1.6          # 스칼라 확장 → [1.6 3.2]
np.array([[1,2],[3,4],[5,6]]) + np.array([[1,1]])  # (3,2)+(1,2)
np.arange(3).reshape((3,1)) + np.arange(3)        # (3,1)+(3,) → (3,3) 격자
```

```
뒤에서부터 정렬:
  (3, 2)
  (1, 2)   ← 축0이 1 → 3으로 확장
  ------
  (3, 2)  ✅ 호환
```

---

## 실제 예시

- z-score 표준화 `(X - mu) / sig` — `mu`,`sig`는 (열수,) 1차원이 (행,열) X에 **열별로 브로드캐스팅**된다.

---

## 자주 헷갈리는 것

**호환 안 되면 에러.** 예: (3,2)+(3,)은 뒤축 2≠3이라 실패. 한쪽 축이 1이거나 같아야 한다.

---

## 더 알면 좋은 것

📌 "가상 확장"이라 실제로 데이터를 복제하지 않아 **메모리 효율적**. C 루프로 처리.
