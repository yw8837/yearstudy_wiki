# DIKW 피라미드

**정의**: 데이터가 가치로 발전하는 단계 모델. **데이터(Data) → 정보(Information) → 지식(Knowledge) → 지혜(Wisdom)**.

---

## 왜 필요한가

원시 데이터 자체는 가치가 작다. **패턴을 발견하고 맥락을 부여**해 정보·지식으로 쌓아야 의사결정(지혜)으로 이어진다. 데이터 활용의 큰 그림을 보여준다.

---

## 어떻게 작동하나

```
        Wisdom      지혜   ← "그래서 어떻게 할까" (판단·행동)
       ───────
      Knowledge    지식   ← "왜 그런가" (패턴·인과 이해)
     ───────────
    Information   정보    ← "무엇인가" (가공·정리된 데이터)
   ───────────────
  Data            데이터  ← 원시 사실·기록
```

- 핵심은 **패턴 발견** — 데이터에서 정보를 뽑고, 지식으로 일반화해 지혜로운 판단을 내린다.

---

## 실제 예시

- "기온 30℃"(데이터) → "더운 날 음료 매출↑"(정보) → "여름철 음료 수요 패턴"(지식) → "여름 재고를 늘린다"(지혜).

---

## 자주 헷갈리는 것

**정보 ≠ 지식.** 정보는 정리된 데이터, 지식은 패턴·인과를 이해한 상태. 단계가 올라갈수록 사람의 해석이 더해진다.
