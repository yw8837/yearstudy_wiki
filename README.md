## 🤔 이 위키, 뭐 하는 곳이에요?

- 매일 들은 강의를 **날짜별로 기록**하고(`강의/`),
- 중요한 개념은 **하나하나 깊게 풀어 쓰고**(`개념/`),
- 주제별로 **한눈에 보는 요약본**을 만들어(`정리/`),
- **인덱스/색인**으로 원하는 걸 바로 찾는

세 겹으로 쌓는 노트 모음입니다. **[Obsidian](https://obsidian.md)** 이라는 무료 앱으로 열면 노트끼리 연결돼 가장 편하게 볼 수 있어요.

| **`개념/색인.md`** | 키워드 사전 (용어로 바로 점프) | 🔍 책 뒤 찾아보기 |

## 🐣 처음이세요? — 5분 따라하기

> 컴퓨터에 아무것도 안 깔려 있어도 괜찮습니다. 1 → 2 → 3 → 4 순서대로 하세요.

### 1단계 · Obsidian 설치하기

**Obsidian**은 마크다운(`.md`) 노트를 보고 편집하는 **무료 앱**입니다. 이 위키는 Obsidian에 최적화돼 있어요.

1. 👉 **https://obsidian.md/download** 접속
2. 내 운영체제(Windows / macOS / Linux)에 맞는 버튼 클릭 → 설치 파일 실행 → 설치
3. 설치 끝! (회원가입·결제 필요 없음)

### 2단계 · 위키 폴더를 내 컴퓨터로 가져오기

**두 가지 방법 중 편한 걸** 고르세요.

#### 🟢 방법 A. ZIP 다운로드 — *git 몰라도 OK (초보자 추천)*

1. 이 GitHub 저장소 페이지에서 오른쪽 위 초록색 **`<> Code`** 버튼 클릭
2. 뜬 메뉴 맨 아래 **`Download ZIP`** 클릭 → zip 파일이 다운로드됨
3. 다운로드한 zip 파일을 **압축 해제** → `yearstudy_wiki` 폴더가 생깁니다

> ⚠️ ZIP은 "**받은 그 순간의 사본**"이에요. 나중에 내용이 업데이트되면 **다시 받아야** 최신이 됩니다.

#### 🔵 방법 B. git clone — *터미널을 쓸 줄 안다면*

```bash
git clone https://github.com/yw8837/yearstudy_wiki.git
```

> 이후엔 폴더에서 `git pull` 한 번이면 최신 내용으로 갱신돼 편합니다.

### 3단계 · Obsidian에서 위키 열기

1. Obsidian 실행
2. 첫 화면에서 **`Open folder as vault`** (폴더를 보관소로 열기) 클릭
   - 이미 다른 게 열려 있다면: 왼쪽 아래 보관소 아이콘 → **`Open another vault`** → `Open folder as vault`
3. 2단계에서 받은(압축 푼) **`yearstudy_wiki` 폴더**를 선택
4. "신뢰하시겠습니까?" 같은 안내가 나오면 **Trust author and enable plugins** (또는 그냥 열기) 선택

> 💡 **vault(볼트)** = Obsidian이 노트를 관리하는 폴더 하나를 부르는 말입니다. 우리 위키 폴더가 곧 하나의 vault예요.

### 4단계 · 둘러보기

- 좌측 사이드바에서 **`인덱스.md`** 를 먼저 열어보세요 → 위키 전체 지도가 나옵니다.
- 파란 글씨로 된 **`[[링크]]`** 를 클릭하면 해당 노트로 점프합니다.
- 끝! 이제 마음껏 탐색하시면 됩니다. 🎉

## ⌨️ Obsidian 200% 활용 꿀팁

| 기능 | 단축키 / 방법 |
|:---|:---|
| 파일 빠르게 열기 | `Ctrl/Cmd + O` → 파일명 입력 |
| 전체 내용 검색 | `Ctrl/Cmd + Shift + F` |
| 🔗 그래프 뷰 (개념 연결 지도) | 좌측 **그래프 아이콘** 클릭 |
| 보기 ↔ 편집 전환 | 우측 위 펜/책 아이콘 |
| 뒤로 가기 | `Alt + ←` |

> 💡 **`[[위키링크]]` 란?** 노트끼리 연결하는 Obsidian 문법입니다. 글자에 마우스를 올리면 미리보기가 뜨고, 클릭하면 그 노트로 이동해요. (이 링크는 **GitHub 웹에서는 클릭이 안 되고** Obsidian에서만 작동합니다 → 그래서 Obsidian을 추천!)

노트를 수정한 뒤 GitHub에도 반영하려면(백업):

```bash

```

## ❓ 자주 묻는 것

**Q. git을 꼭 알아야 하나요?**
A. 아니요. **ZIP 다운로드(방법 A)** 면 충분합니다. 보기만 할 거면 git 없이도 됩니다.

**Q. GitHub 웹에서 봐도 되나요?**
A. 읽는 건 됩니다. 다만 `[[링크]]`가 클릭이 안 되고 글자로만 보여요. 제대로 누리려면 **Obsidian으로 여세요.**

**Q. 모바일에서도 보나요?**
A. Obsidian은 iOS/안드로이드 앱도 있습니다. (동기화는 별도 설정 필요)

**Q. 내용이 업데이트되면?**
A. ZIP은 다시 받기 / git은 `git pull` 한 번.
