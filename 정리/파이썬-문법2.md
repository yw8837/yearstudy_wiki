## 1. 문자열·리스트 추가 메서드

```python
my_list.pop(0)        # 인덱스 0 꺼내며 삭제 (괄호 비우면 마지막)
[2,2,3].count(2)      # 2   값 개수
"1 2 3".split()       # ['1','2','3']   문자열 → 리스트 (공백 기준)
"Na,Mg".split(",")    # ['Na','Mg']     쉼표 기준
"-".join(["a","b"])   # "a-b"           리스트 → 문자열
```

- `split` ↔ `join`은 한 쌍 (쪼개기 ↔ 합치기)
- `join`은 `"구분자".join(리스트)` 순서 주의

## 2. 튜플 → [[튜플]] (불변)

```python
t = (1, 2, 3)         # 소괄호, 값 변경 불가
t_one = (1,)          # 원소 1개는 쉼표 필수! (1)은 그냥 정수
t[1]                  # 2     인덱싱·슬라이싱·in·len·+·* 가능
t[0] = 99             # TypeError (불변)
```

- 쓰는 곳: 좌표·날짜 등 안 바뀔 값, 딕셔너리 Key, 함수의 여러 값 반환
- 억지로 고치려 리스트↔튜플 변환하지 말 것 — 바뀔 값이면 처음부터 리스트

## 3. 딕셔너리 → [[딕셔너리]] (키-값)

```python
d = {"name": "Rabbit", "age": 22}
d["name"]             # "Rabbit"  (키로 접근)
d["mail"] = "a@b.com" # 추가 (없는 키면 새로, 있으면 수정)
del d["age"]          # 삭제
d.keys() / d.values() / d.items()    # 키 / 값 / 쌍 (view 객체, list()로 형변환)

for k, v in d.items():    # 순회 (가장 많이 쓰는 패턴, 2변수 언패킹)
    print(k, v)
```

- Key는 **불변 자료형만** (str·int·tuple O / list ❌)
- `in`은 '키' 기준으로 검사
- `items()` 등은 리스트가 아닌 **view 객체** / 변수 하나로 받으면 `(k,v)` 튜플이라 `x[1]` 필요 → 2변수 언패킹 권장

## 4. 반복문 → [[반복문]]

```python
for i in range(1, 10):      # 1~9 (끝 미포함)
    print(i)

for fruit in ["사과", "배"]: # 목록 순회
    print(fruit)

i = 5
while i > 0:                 # 조건이 참인 동안
    i -= 1                   # 조건 변화 필수 (무한루프 주의)

break      # 반복 즉시 탈출
continue   # 이번 회차만 건너뜀
```

- `for` → 횟수·범위 정해질 때 / `while` → 조건으로 멈출 때
- `range(a, b, c)` → a 이상 b 미만, c칸씩
- 실무: while은 개발엔 필수지만 **분석 업무는 빈도 낮음**(데이터 범위 정해져 for가 적합)
- 평균 분모는 상수 말고 `len()` 사용

## 5. 함수와 메서드 → [[함수]]

```python
def plus_double(a, b):     # def 이름(매개변수):
    return 2 * (a + b)     # return으로 결과 반환

plus_double(3, 4)          # 14

def greet(name, greeting="안녕"):   # default 매개변수 = 옵션
    print(f"{greeting}, {name}!")
```

- `return` 없으면 결과는 `None`
- 함수 안 변수(지역)는 함수 밖에서 못 씀 *(전역/지역 상세는 6/2로 이월 → [[0602-클래스와모듈]])*
- **함수** `len(x)` (독립) vs **메서드** `x.append()` (자료에 딸림, 점으로 호출)
- 내장 함수: `len` `sum` `max` `min` — **이 이름들을 변수로 쓰지 말 것**(덮어쓰기)
- 매개변수 에러: `missing required positional argument`(덜 넣음) / `takes N ... but M were given`(더 넣음)
- 설계: **필수 최소 + 나머지 default**(예: `read_csv`는 path 1개 필수) → 사용자 편의 우선

## 6. 📌 보충 — 타입 힌트 & 독스트링

```python
def add(a: int, b: int) -> int:   # 타입 힌트: 자료형 명시(강제 아님)
    """두 수를 더한다."""          # 독스트링: 함수 설명, help()로 조회
    return a + b
```

- 가독성·협업에 도움. 라이브러리 공식 문서도 docstring에서 생성됨
