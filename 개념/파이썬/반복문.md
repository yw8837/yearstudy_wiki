# 반복문 (Loop)

**정의**: 같은 작업을 여러 번 자동으로 되풀이하는 구조. `for`(정해진 횟수·목록 순회)와 `while`(조건이 참인 동안 반복) 두 가지가 있다.

---

## 왜 필요한가

리스트에 든 학생 100명에게 똑같이 "안녕"을 출력하려면 `print`를 100번 쓸 수는 없다. 반복문은 **"이 작업을 목록의 끝까지 / 조건이 끝날 때까지 알아서 반복해"** 라고 컴퓨터에 시키는 도구다.

리스트·딕셔너리 같은 자료구조의 진짜 힘은 반복문과 결합할 때 나온다. 데이터 분석, 크롤링, AI 학습 모두 "수많은 데이터를 하나씩 처리하는" 반복의 연속이다.

---

## 어떻게 작동하나

### for 문 — 목록을 하나씩 꺼내기

```python
for 변수 in 시퀀스:
    실행할 코드        # 들여쓰기 필수

for fruit in ["사과", "바나나", "체리"]:
    print(fruit)
# 사과
# 바나나
# 체리
```

`fruit`에 리스트의 값이 하나씩 자동으로 들어오면서 끝까지 반복한다.

### for + range() — 정해진 횟수만큼

`range()`는 연속된 숫자를 만들어 준다. **끝 숫자는 포함하지 않는다.**

```python
range(5)         # 0, 1, 2, 3, 4
range(1, 6)      # 1, 2, 3, 4, 5
range(0, 10, 2)  # 0, 2, 4, 6, 8   (2칸씩 건너뜀)

for i in range(5):
    print(i)     # 0 1 2 3 4 (한 줄씩)

# range + len + 인덱싱: 위치 번호가 필요할 때
my_list = ["a", "b", "c"]
for idx in range(len(my_list)):
    print(idx, my_list[idx])   # 0 a / 1 b / 2 c
```

### while 문 — 조건이 참인 동안 계속

```python
while 조건:
    실행할 코드
    # 조건이 언젠가 False가 되도록 반드시 '변화'를 줘야 함

i = 5
while i > 0:
    print(i)     # 5 4 3 2 1
    i -= 1       # i를 1씩 줄여서 결국 0이 되면 멈춤
```

> ⚠️ **무한 루프 주의**: 조건이 영원히 True면 프로그램이 멈추지 않는다. while 안에서 조건을 변하게 만드는 코드(`i -= 1` 등)를 꼭 넣어야 한다.

### break — 반복 도중 탈출

```python
while True:                      # 일부러 무한 루프로 시작
    guess = int(input("숫자: "))
    if guess == 42:
        break                    # 맞히면 루프 즉시 탈출
print("정답!")
```

### continue — 이번 회차만 건너뛰기

```python
for i in range(1, 6):
    if i == 3:
        continue                 # 3일 때만 건너뜀
    print(i)     # 1 2 4 5 (3은 출력 안 됨)
```

## 실제 예시

```python
# 1~10 합 구하기
total = 0
for i in range(1, 11):
    total += i
print(total)         # 55

# 리스트에서 짝수만 골라내기
nums = [1, 2, 3, 4, 5, 6]
evens = []
for n in nums:
    if n % 2 == 0:
        evens.append(n)
print(evens)         # [2, 4, 6]

# 딕셔너리 순회
scores = {"홍길동": 85, "김철수": 92}
for name, score in scores.items():
    print(f"{name}: {score}점")
```

## 자주 헷갈리는 것

**`range(5)`는 5까지가 아니라 4까지**: `0, 1, 2, 3, 4` — 다섯 개지만 5는 포함하지 않는다. 슬라이싱과 같은 규칙.

**`break` vs `continue` 혼동**:
- `break` = 반복문 **전체를 끝내고** 빠져나옴
- `continue` = 이번 회차만 건너뛰고 **다음 회차로 계속**

**무한 루프 실수**: `while i > 0:`인데 안에서 `i`를 줄이지 않으면 영원히 돈다. 실행이 멈추지 않으면 `Ctrl + C`로 강제 종료.

**리스트를 순회하면서 그 리스트를 수정**: 반복 도중 원소를 추가/삭제하면 결과가 꼬인다. 새 리스트를 따로 만드는 것이 안전하다.
```python
nums = [1, 2, 3, 4]
# 나쁜 예: 순회 중 삭제 → 일부 건너뜀
# 좋은 예: 컴프리헨션으로 새로 생성
result = [n for n in nums if n != 2]   # [1, 3, 4]
```

## 더 알면 좋은 것

📌 **`enumerate()`**: for문에서 **인덱스와 값을 동시에** 받는다. `range(len(...))`보다 깔끔하다.
```python
for i, fruit in enumerate(["사과", "바나나"]):
    print(i, fruit)     # 0 사과 / 1 바나나
```

📌 **`zip()`**: 두 리스트를 나란히 묶어 동시에 순회한다.
```python
names = ["철수", "영희"]
ages = [20, 22]
for name, age in zip(names, ages):
    print(name, age)    # 철수 20 / 영희 22
```

📌 **리스트 컴프리헨션**: 간단한 for + if 반복은 한 줄로 줄일 수 있다.
```python
squares = [x**2 for x in range(5)]            # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]
```

📌 **`for-else`**: 반복이 `break` 없이 끝까지 돌면 `else` 블록이 실행된다. (탐색 실패 처리에 유용, 수업 미커버)
