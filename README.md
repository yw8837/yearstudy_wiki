## 🔄 업데이트 받기 (최신 내용으로)

> 이 위키는 매일 업데이트됩니다. 터미널(macOS·Linux) 또는 **Git Bash**(Windows)에서 아래대로 하면 됩니다.

> ⚠️ 명령어는 반드시 받은 **`yearstudy_wiki` 폴더 "안"에서** 실행하세요.
> 바탕화면(Desktop) 등 엉뚱한 위치에서 `git pull`을 치면 `fatal: not a git repository` 에러가 납니다.
> **현재 위치 확인**: `pwd` (지금 폴더 출력) / `ls` (목록에 `README.md·강의·개념·정리`가 보이면 제대로 들어온 것).

### ✅ git clone 으로 받은 경우 — 한 줄로 업데이트 (추천)

**① 처음 한 번만 — 저장할 위치로 가서 복제(clone)**
```bash
cd ~/Documents          # 위키를 둘 위치로 이동 (원하는 곳 아무 데나)
git clone https://github.com/yw8837/yearstudy_wiki.git
```
→ 지금 위치에 `yearstudy_wiki` 폴더가 생깁니다.

**② 그다음부터 — 그 폴더 안으로 들어가서 받기 (매번 이것만 반복!)**
```bash
cd ~/Documents/yearstudy_wiki    # ★ ①에서 생긴 폴더 안으로 이동
git pull                         # 최신 내용 받기
```

### 📦 ZIP 으로 받은 경우 — `git pull` 안 됨

ZIP은 git과 연결돼 있지 않아 `git pull`로 업데이트할 수 **없습니다.**
업데이트하려면 **그때마다 ZIP을 새로 받아 폴더를 통째로 교체**해야 해요 (수동·번거로움).

> 💡 **자주 업데이트할 거면 처음부터 `git clone`을 강력 추천!** 한 번 복제해 두면 이후엔 `git pull` 한 줄이면 끝입니다.
> 💡 받은(복제·압축 푼) 폴더는 Obsidian `Open folder as vault` 로 열면 됩니다.
