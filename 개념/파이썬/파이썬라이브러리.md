# 라이브러리 (Library) · pip · PyPI

**정의**: 누군가 미리 만들어 둔 **코드 묶음**. 설치(`pip`)해서 `import`로 가져다 쓴다. 모아둔 창고가 **PyPI**.

---

## 왜 필요한가

복잡한 계산·분석·웹요청을 직접 다 짤 필요 없이, 검증된 도구를 한 줄로 가져다 쓴다("바퀴를 다시 발명하지 마라"). 데이터·AI 작업은 사실상 라이브러리 활용의 연속이다.

---

## 어떻게 작동하나

### 표준 vs 외부
| 구분 | 설치 | 예시 |
|:---|:---|:---|
| 표준 | 불필요(내장) | `math` `random` `datetime` `json` |
| 외부 | `pip`로 설치 | `numpy` `pandas` `requests` `matplotlib` |

### 설치 — pip
```bash
pip install pandas            # 설치
pip install pandas==2.2.0     # 버전 지정
pip list                      # 설치 목록
pip freeze > requirements.txt # 목록 저장
pip install -r requirements.txt
```
> 우리 과정은 **uv** 사용: `uv add pandas`, `uv sync`. → [[uv]]

### 사용 — import
```python
import pandas as pd      # 관례 별칭
df = pd.DataFrame({"점수": [95, 82]})
print(df["점수"].mean())  # 88.5
print(pd.__version__)     # 버전 확인 습관
```

### 공유 — PyPI 배포
```bash
uv add --dev pytest twine   # 테스트·업로드 도구
uv run pytest               # 테스트 통과 후
uv run twine upload dist/*  # PyPI 업로드 → 누구나 pip install 가능
```
> 우리 과정의 배포 흐름은 **uv + hatchling(빌드) + twine(업로드)**가 메인. `pip install build` → `python -m build`는 대안. 전 과정·주의는 → [[PyPI배포]]

## 실제 예시

- `numpy`(수치)·`pandas`(표)·`matplotlib`(그래프)·`scikit-learn`(ML)·`requests`(웹)
- [PyPI](https://pypi.org)에서 검색 → `pip install` → `import`
- 직접 배포 예: `mathlib-evanjjh`(사칙연산 클래스 패키지, 실제 v0.1.5). → [[PyPI배포]]

## 자주 헷갈리는 것

**모듈 vs 패키지 vs 라이브러리**: 모듈=`.py` 파일 / 패키지=모듈 담은 폴더 / 라이브러리=배포 단위(패키지들). → [[모듈과패키지]]

**`pip install`이 안 될 때**: 가상환경 활성화 확인, `python -m pip` 시도, 오타·대소문자 확인.

**버전 표기**: `major.minor.patch`(예 2.2.0). 큰 변화·기능추가·버그수정 순.
