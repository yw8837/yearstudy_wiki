# 딕셔너리 (Dictionary)

**정의**: 데이터를 **키(key)와 값(value)의 쌍**으로 저장하는 자료구조. 중괄호 `{}`로 만들고, 순서 번호가 아니라 **이름(키)** 으로 값을 꺼낸다.

---

## 왜 필요한가

리스트는 `students[0]`, `students[1]`처럼 **번호**로 값을 꺼낸다. 그런데 "3번 학생의 이름"이 아니라 "이름이 뭐고, 나이가 몇이고, 이메일이 뭔지"처럼 **항목에 이름표가 필요한 데이터**가 많다.

딕셔너리는 사전(辭典)과 같다. 사전에서 단어(키)를 찾으면 뜻(값)이 나오듯, 딕셔너리는 `person["name"]`처럼 **키로 값을 즉시 찾는다**. 실무에서 API 응답(JSON)이 거의 다 이 구조라 매우 자주 쓴다.

---

## 어떻게 작동하나

### 기본 생성·접근

```python
person = {"name": "Rabbit", "age": 22}
#          └키┘   └─값─┘   └키┘  └값┘

# 값 꺼내기 — 키로 접근
person["name"]      # "Rabbit"
person["age"]       # 22

empty = {}          # 빈 딕셔너리
```

### 추가·수정·삭제

```python
person = {"name": "Rabbit", "age": 22}

# 추가 — 없는 키에 값을 넣으면 새로 생김
person["mail"] = "rabbit@elice.com"

# 수정 — 있는 키에 값을 넣으면 덮어씀 (추가와 문법이 같음!)
person["age"] = 23

# 삭제
del person["age"]

print(person)       # {'name': 'Rabbit', 'mail': 'rabbit@elice.com'}
```

### 자주 쓰는 메서드

```python
person = {"name": "Rabbit", "age": 22}

person.keys()       # dict_keys(['name', 'age'])      — 키 전체
person.values()     # dict_values(['Rabbit', 22])     — 값 전체
person.items()      # dict_items([('name','Rabbit'), ('age',22)])  — 쌍 전체

# get() — 키가 없어도 에러 없이 처리
person["phone"]            # KeyError! (없는 키)
person.get("phone")        # None      (에러 대신 None)
person.get("phone", "없음") # "없음"    (기본값 지정)
```

> 💡 **view 객체**: `keys()`·`values()`·`items()`가 돌려주는 `dict_keys` / `dict_values` / `dict_items`는 **리스트처럼 보이지만 리스트가 아닌 뷰(view) 객체**다. 딕셔너리를 바라보는 "창"이라 원본이 바뀌면 같이 바뀐다. 인덱싱 등 리스트 기능이 필요하면 `list(person.items())`로 형변환한다.

### for문과 조합 (가장 많이 쓰는 패턴)

```python
my_dict = {"a": 1, "b": 2, "c": 3}

# items()로 키와 값을 한 번에 — 2개 변수로 언패킹 (권장)
for key, value in my_dict.items():
    print(f"{key}: {value}")
# a: 1
# b: 2
# c: 3
```

> ⚠️ **변수 하나로만 받으면 함정**: `for x in my_dict.items():`이면 `x`는 한 쌍씩 들어온 `(key, value)` **튜플**이다. 그래서 값만 쓰려면 `x[1]`처럼 인덱싱해야 한다. 처음부터 `for key, value in my_dict.items():`로 **2개 변수 언패킹**하면 `x[0]`/`x[1]` 없이 깔끔하다.
> ```python
> for x in my_dict.items():
>     print(x)        # ('a', 1) ... 튜플 통째로
>     print(x[1])     # 1        ... 값만 쓰려면 인덱싱 필요
> ```

## 실제 예시

```python
# 학생 성적표 — 이름으로 점수 관리
scores = {"홍길동": 85, "김철수": 92, "이영희": 78}

print(scores["김철수"])          # 92

# 평균 계산
avg = sum(scores.values()) / len(scores)
print(f"평균: {avg:.1f}")        # 평균: 85.0

# 90점 이상만 출력
for name, score in scores.items():
    if score >= 90:
        print(f"{name}: 우수")   # 김철수: 우수

# 단어 빈도 세기 — 키가 있으면 +1, 없으면 1 (반복+조건 조합, 초보 난관 구간)
words = "사과 배 사과 귤 배 사과".split()
freq = {}
for word in words:
    if word in freq:
        freq[word] += 1
    else:
        freq[word] = 1
print(freq)                      # {'사과': 3, '배': 2, '귤': 1}

# API 응답(JSON)이 바로 이 모양
user = {"id": 1, "name": "Rabbit", "active": True}
print(user["name"])              # Rabbit
```

## 자주 헷갈리는 것

**Key 규칙 — 불변 자료형만 가능**: 키에는 바뀌지 않는 값만 쓸 수 있다.
```python
{"name": 1}      # str 키 → OK
{1: "a"}         # int 키 → OK
{(0,0): "시작"}  # tuple 키 → OK
{[1,2]: "x"}     # list 키 → TypeError! (리스트는 가변이라 불가)
```

**키 중복은 불가능 — 나중 값이 이김**:
```python
d = {"a": 1, "a": 2}
print(d)         # {'a': 2}  ← 같은 키는 하나만 남고 덮어써짐
```

**없는 키를 꺼내면 에러**: `d["없는키"]`는 `KeyError`. 안전하게 꺼내려면 `.get()`을 쓰거나 `if "키" in d:`로 먼저 확인.
```python
if "phone" in person:        # in은 '키'를 기준으로 확인
    print(person["phone"])
```

**`in`은 키를 검사한다**: `"name" in person`은 True지만, `"Rabbit" in person`(값)은 False다. 값으로 찾으려면 `"Rabbit" in person.values()`.

**`items()`는 리스트가 아니다**: view 객체라 `dict_items([...])`처럼 출력된다. 리스트로 다루려면 `list(d.items())`.

## 더 알면 좋은 것

📌 **순서 보장**: 파이썬 3.7부터 딕셔너리는 **입력한 순서를 유지**한다. 그 이전 버전에서는 순서가 보장되지 않았다.

📌 **`zip()`으로 빠르게 만들기**: 키 리스트와 값 리스트를 묶어 딕셔너리를 만든다.
```python
keys = ["name", "age"]
values = ["Rabbit", 22]
dict(zip(keys, values))      # {'name': 'Rabbit', 'age': 22}
```

📌 **딕셔너리 컴프리헨션**: 리스트 컴프리헨션처럼 한 줄로 생성.
```python
squares = {x: x**2 for x in range(1, 4)}   # {1: 1, 2: 4, 3: 9}
```

📌 **JSON과의 관계**: 웹에서 데이터를 주고받는 JSON 형식이 파이썬 딕셔너리와 거의 똑같이 생겼다. `import json`으로 서로 변환한다. → [[HTTP]], [[크롤링]]
