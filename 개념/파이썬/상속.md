# 상속 (Inheritance)

**정의**: 기존 클래스(부모)의 속성·메서드를 **물려받아** 새 클래스(자식)를 만드는 것. 공통 코드를 한 곳에 두고 재사용한다.

---

## 왜 필요한가

개발팀·기획팀·영업팀은 "팀원 추가·예산" 같은 공통 기능이 있고, 각자 다른 점도 있다. 매번 똑같은 코드를 반복하지 않고 **공통은 부모에, 차이만 자식에** 두면 중복이 사라지고 수정이 쉬워진다.

---

## 어떻게 작동하나

### 기본 상속 · `super()`

```python
class Department:                    # 부모
    def __init__(self, name, budget):
        self.name = name
        self.budget = budget
    def add_member(self, m):
        print(f"{self.name}에 {m} 합류")

class DevTeam(Department):            # 자식: 괄호 안에 부모
    def __init__(self, budget, tech):
        super().__init__("개발팀", budget)   # 부모 __init__ 호출
        self.tech = tech                      # 자식만의 추가 속성

dev = DevTeam(50000, ["Python"])
dev.add_member("Alice")     # 개발팀에 Alice 합류  (물려받은 메서드)
```

- **`super()`**: 부모 클래스를 가리킴. `super().__init__()`으로 부모 초기화 실행.

### 오버라이딩 (Overriding)

부모 메서드를 자식이 **자기 방식대로 재정의**.

```python
class Department:
    def meeting(self): print(f"{self.name} 정기 회의")
class DevTeam(Department):
    def meeting(self): print("개발팀 스프린트 회의")   # 재정의
```

### 다형성 (Polymorphism)

**같은 메서드 호출**인데 객체(클래스)마다 **다르게 동작**.

```python
for team in [DevTeam(...), SalesTeam(...)]:
    team.meeting()        # 팀마다 다른 회의 출력
```

## 실제 예시

```python
class Animal:
    def __init__(self, name): self.name = name
    def sound(self): print("...")

class Dog(Animal):
    def sound(self): print(f"{self.name}: 멍멍")
class Cat(Animal):
    def sound(self): print(f"{self.name}: 야옹")

for a in [Dog("바둑이"), Cat("나비")]:
    a.sound()       # 멍멍 / 야옹 (다형성)
```

---

## 자주 헷갈리는 것

**`super().__init__()` 빼먹기**: 자식 `__init__`에서 부모 초기화를 안 부르면 부모 속성(name·budget 등)이 안 생긴다.

**오버라이딩 ≠ 오버로딩**: 파이썬엔 (다른 언어식) 오버로딩이 없다. 같은 이름 메서드를 또 정의하면 **덮어쓰기**.

**상속 남용**: "A는 B다(is-a)" 관계일 때만 상속. 단순히 기능 빌려 쓰려면 **포함(composition)** 이 나을 때도 많다.

---

## 더 알면 좋은 것

📌 **`isinstance(obj, 클래스)`**: 객체가 그 클래스(또는 부모)의 인스턴스인지 → `isinstance(dev, Department)` True.

📌 **`issubclass(자식, 부모)`**: 클래스 간 상속 관계 → `issubclass(DevTeam, Department)` True.

📌 **MRO(메서드 탐색 순서)**: 다중 상속 시 `super()`가 부모를 찾는 순서. `클래스.__mro__`로 확인.

📌 **`object`**: 모든 클래스는 암묵적으로 최상위 `object`를 상속한다.
