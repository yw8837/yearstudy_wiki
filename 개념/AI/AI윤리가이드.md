# AI 윤리·안전 활용 가이드

**정의**: AI를 책임감 있고 안전하게 사용하기 위한 원칙·실무 가이드의 묶음. 데이터 보호, 보안, 환각/아첨 대응, 책임, 인간 검토를 포괄한다.

---

## 왜 필요한가

AI가 '기본 도구'로 빠르게 확산되고 있다. 한국IDC 조사 기준 국내 조직의 **72%**가 생성형 AI를 도입(사용 중이거나 곧 도입 예정), **78%**가 도입으로 직원 생산성이 개선됐다고 평가, 개인의 **86.0%**가 개인·조직 차원에서 AI 도구를 활용 중이다. 이렇게 일상화된 만큼 잘못 쓰면 정보 유출·오답·법적 책임으로 이어진다. "되는 것"을 넘어 "보안·팩트체크·에티켓을 갖춰 안전하게 되는 것"이 중요해졌다.

AI 윤리가 중요한 이유는 4대 위험으로 요약된다 — **개인정보 유출 / 기업 기밀 유출 / 허위 정보 생성 / 저작권 문제.**

### 안전한 생성형 AI 보안 4단계 (국정원 가이드 기반)

```
① 도입 전 점검 → ② 사용 준비 → ③ 사용 중 준수 → ④ 사용 후 관리
```

| 단계 | 핵심 점검 항목 |
|:---|:---|
| **① 도입 전 점검** | 서비스 약관·보안·데이터 정책 근거 검토 / 개인정보 처리 위탁 여부·법적 근거 확인 / 조직 내부 정책·허용 업무 범위 명시 |
| **② 사용 준비** | 민감·기밀정보 분류 및 리스트업 / 사내 가이드·금지 사례 공지 / 업무용 계정·MFA 설정, 계정 분리 |
| **③ 사용 중 준수** | 개인·민감·기밀정보 입력 금지 / URL·파일 업로드 최소화 / 조직명·실명 노출 최소화 / 비인가 확장·플러그인 사용 금지 |
| **④ 사용 후 관리** | 결과물 저장 위치·공유 권한 통제 / 로그·대화 기록 보존·삭제 정책 / 유출·오류 시 즉시 신고·조치 |

## 실제 사례 — 삼성전자 ChatGPT 기밀 유출

강사가 데이터 입력 위험의 대표 사례로 강조. 초기 ChatGPT 시기, **삼성전자 직원들이 회사 기밀을 ChatGPT에 입력** 해 보안 이슈가 된 실제 사례. ("삼성전자 ChatGPT 보안"으로 검색하면 관련 기사 확인 가능하다고 안내.)

- 교훈: **비밀번호·API 키·회사 기밀·개인정보는 절대 업로드 금지.**
- DeepSeek 등 일부 모델의 과도한 데이터 수집 우려도 언급. (개인 사용 수준에선 큰 차이 없으나, **회사 차원에선 반드시 가려 쓰라** 는 강사 견해.)

## 실제 사례 — AIR CANADA 챗봇 / 가짜 판례

**AIR CANADA — 규정에 없는 AI의 할인 안내**: 캐나다 최대 항공사 AIR CANADA의 자사 웹사이트 AI 챗봇이 (규정에 없는) 항공료 할인 정보를 안내했고, **회사가 그 안내에 책임을 지고 그대로 할인해 줘야 한다는 민사 중재 결정**이 나왔다. 검증되지 않은 AI의 말 한 마디로 회사가 분쟁에서 패하고 손실을 본 사례.

**가짜 판례 — 노무사 사례**: 노무사가 AI가 생성한 **가짜 판례(존재하지 않는 판례)를 검증 없이 인용·제출**했다가 발각된 사례. AI 출력을 검증 없이 공식 문서에 쓰면 안 된다는 경고.

- 교훈: **챗봇이 틀려도 책임은 그 도구를 쓴 기업/사람에게.** 책임 없는 무분별한 AI 사용을 조심하고, 사람이 철저히 검증해야 한다.

## 자주 헷갈리는 것

**"AI가 책임진다"**: 아니다. AI는 도구. 결과의 책임은 사용자/기업.

**"비식별화하면 100% 안전"**: 위험을 줄일 뿐. 입력 자체를 최소화하는 게 우선.

## 저작권 위험과 사용 판단

AI 생성물에는 저작권 위험 4가지가 따른다 — **학습 데이터 출처 불분명 / 원문과 유사한 문장 재생산 / 책임 소재 불분명 / 저작권자의 소송.** 원칙은: AI 생성물을 자기 창작물처럼 제출하면 표절, 학술·공식 문서엔 AI 사용 여부를 명시, 이미지·음악 생성 시 학습 데이터 라이선스를 확인.

AI 생성 콘텐츠 **사용 의사결정 4단계**:

```
① 유사성 점검 → ② 권리·기간 확인 → ③ 사용 목적 구분 → ④ 리스크 관리
```
