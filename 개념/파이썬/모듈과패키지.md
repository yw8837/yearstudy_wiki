# 모듈과 패키지 (Module & Package)

**정의**: **모듈** = 파이썬 코드가 담긴 `.py` 파일 하나. **패키지** = 모듈들을 담은 폴더. 잘 만든 코드를 `import`로 가져다 쓴다.

---

## 왜 필요한가

좋은 코드를 매번 새로 짤 필요 없이 **가져다 쓰기** 위해서다. 전 세계 개발자가 만든 도구(난수·수학·데이터분석)를 `import` 한 줄로 쓰고, 내 코드도 기능별 파일로 나눠 정리·재사용할 수 있다.

---

## 어떻게 작동하나

### 모듈 가져오기 — `import`

```python
import random
print(random.randrange(1, 7))   # 1~6 주사위 (모듈명.함수)

import math
print(math.pi, math.sqrt(16))   # 3.141592... 4.0
```

### import 4가지 방법

```python
import math               # ① 통째로 → math.sqrt()
import random as rd       # ② 별칭 → rd.randrange()
from math import sqrt, pi # ③ 콕 집어 → sqrt() (모듈명 생략)
from math import *        # ④ 전부 (비권장 — 어디서 왔는지 모호)
```

### 내가 만든 모듈

```python
# cal.py
def plus(a, b):
    return a + b
```
```python
# main.py (같은 폴더)
import cal
print(cal.plus(3, 4))     # 7
from cal import plus
print(plus(3, 4))         # 7
```
> `import cal` — `.py`는 빼고 파일명만.

### 패키지 — 폴더로 묶기

```
project/
├── script/main.py
└── sound/
    ├── audio.py
    └── play.py
```
```python
import sound.audio            # 점(.)으로 폴더 경로 따라가기
from sound.play import start
```

## 실제 예시

```python
# 표준 라이브러리 활용
import random
menu = ["김치찌개", "비빔밥", "냉면"]
print("오늘 점심:", random.choice(menu))

from datetime import datetime
print(datetime.now().year)    # 올해 연도
```

---

## 자주 헷갈리는 것

**표준 라이브러리 vs 외부 패키지**: `math`·`random`은 설치 없이 바로 `import`. `numpy`·`pandas`는 `pip`(또는 uv)로 **설치 후** import.

**`from module import *` 남용**: 어떤 이름이 들어오는지 불명확 → 충돌·혼란. `import module` 또는 `from module import 특정함수` 권장.

**모듈명 = 파일명**: `import cal`은 `cal.py`를 찾음. 파일명에 하이픈(`-`)·공백 있으면 import 불가 → 언더스코어 사용.

---

## 더 알면 좋은 것

📌 **`if __name__ == "__main__":`**: 모듈을 **직접 실행할 때만** 동작, import될 때는 실행 안 됨. 모듈 안 테스트 코드에 사용.

📌 **`__init__.py`**: 패키지 폴더 표시용(관례). 지금은 없어도 인식되지만 두는 게 안전.

📌 **모듈 검색 경로**: `import sys; print(sys.path)` — 파이썬이 모듈을 찾는 폴더 목록.
