# 로지스틱 회귀 (Logistic Regression)

**정의**: 이진(0/1) 종속변수의 **발생 확률**을 예측하는 회귀. 예측확률 ≥ 0.5면 1로 분류. β>0이면 해당 변수 증가 시 발생 확률↑.

---

## 왜 필요한가

합격/불합격, 이직/잔류처럼 Y가 이진일 때 [[회귀분석|선형회귀]]는 부적절(확률이 0~1을 벗어남). 로지스틱은 확률로 매핑한다.

---

## 어떻게 작동하나

```python
import statsmodels.formula.api as smf
import numpy as np
model = smf.logit("y ~ x1 + x2", data=df).fit(disp=False)
prob = model.predict(df); y_pred = (prob >= 0.5).astype(int)
odds = np.exp(model.params["x1"])         # 오즈비 exp(β)
# sm.Logit + add_constant 방식도 사용
```

- 지표: [[오즈비]] `exp(β)` / 잔차이탈도 `-2·llf` / 정확도 / 오분류율 / AUC(`roc_auc_score`).

---

## 자주 헷갈리는 것

**계수 β vs [[오즈비]] exp(β).** 계수는 로그 오즈 변화, 오즈비는 "변수 1단위 증가 시 오즈가 몇 배". 해석은 보통 오즈비로 한다.
