# 연산자 (Operator)

**정의**: 값끼리 계산·비교·판단을 수행하는 기호. `+`, `==`, `and` 등.

---

## 왜 필요한가

프로그램은 결국 "값을 계산하고(산술), 비교하고(비교), 조건을 따지는(논리)" 일의 연속이다. 연산자는 그 도구다. 점수 합계(산술), 합격 여부(비교), 여러 조건 결합(논리) 모두 연산자로 표현한다.

---

## 어떻게 작동하나

### 산술 연산자

```python
a, b = 13, 5
a + b     # 18
a - b     # 8
a * b     # 65
a / b     # 2.6    ← 나눗셈은 항상 실수(float)
a // b    # 2      ← 몫 (소수점 버림)
a % b     # 3      ← 나머지
a ** b    # 371293 ← 거듭제곱 (13의 5승)
```

### 비교 연산자 (결과는 True/False)

```python
3 == 3    # True   같다
3 != 5    # True   다르다
3 < 5     # True
5 >= 5    # True
```

### 논리 연산자

```python
True and False   # False  (둘 다 True여야 True)
True or False    # True   (하나라도 True면 True)
not True         # False  (반전)

# 실제 조건 결합
age = 25
age >= 18 and age < 65    # True
```

### 대입 연산자

```python
x = 10        # 기본 대입
x += 3        # x = x + 3  → 13   (복합 대입)
x -= 2        # 11
x *= 2        # 22
```

### 문자열 연산자

```python
"안녕" + "하세요"   # 안녕하세요   (+ 이어붙이기)
"안녕" * 3          # 안녕안녕안녕  (* 반복)
```

### 멤버십 연산자 `in`

```python
"파" in "파이썬"        # True
3 in [1, 2, 3]          # True
"x" not in "Python"     # True
```

## 실제 예시

```python
# 홀짝 판별 — 나머지 연산
num = 7
num % 2 == 0       # False → 홀수

# 평균이 60 이상이면서 결석 3회 미만 → 합격
avg, absent = 75, 2
avg >= 60 and absent < 3    # True

# 누적 합계 — 복합 대입
total = 0
for s in [80, 90, 70]:
    total += s     # 240
```

## 자주 헷갈리는 것

**`/` vs `//`**: `/`는 항상 실수(`6 / 2` → `3.0`), `//`는 몫만 정수(`7 // 2` → `3`).

**`=` vs `==`**: `=`는 대입(값 넣기), `==`는 비교(같은지 확인). 조건문에서 `=` 쓰면 에러.

**문자열 + 숫자 → `TypeError`**: `"나이" + 25` 불가. `"나이" + str(25)` 로 변환 필요.

**우선순위**: `2 + 3 * 4` 는 `20`이 아니라 `14` (곱셈 먼저). 헷갈리면 괄호 `( )`로 명확히.

---

## 더 알면 좋은 것

📌 **연산자 우선순위**: `**` > `*` `/` `//` `%` > `+` `-` > 비교 > `not` > `and` > `or`. 애매하면 괄호.

📌 **단축 평가(short-circuit)**: `and`는 앞이 False면 뒤를 안 봄, `or`는 앞이 True면 뒤를 안 봄. → 0으로 나누기 방지 등에 활용: `b != 0 and a / b > 1`.

📌 **`is` vs `==`**: `==`는 값이 같은지, `is`는 같은 객체인지. `None` 체크는 `x is None` 권장.

📌 **비트 연산자**: `&` `|` `^` `<<` `>>` — 2진수 단위 연산 (수업 미커버, 저수준 처리에 사용).
