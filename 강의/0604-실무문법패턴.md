# 06/04 · 실무 문법 패턴

실무에서 자주 쓰는 파이썬 심화 문법 6가지.
한 줄 요약: f-string·컴프리헨션·sorted·enumerate·lambda·`__name__`으로 코드를 짧고 깔끔하게.

## 다룬 개념

- [[컴프리헨션]] — 한 줄 리스트/딕셔너리
- [[람다]] — 익명 함수·map·filter
- [[정렬]] — sorted·key·다중 기준
- (+ f-string, enumerate, `if __name__ == "__main__"`)

## 수업 포인트

- f-string: `{:.2f}` `{:,}` `{:%}` `{:>7}`
- 컴프리헨션: 필터 `if`는 뒤 / `if-else`는 앞
- sorted: `key=lambda`, 다중기준 튜플 `(a, -b)`
- enumerate(start=1), lambda+map/filter는 `list()`로 감싸기
- `__name__ == "__main__"`: 직접 실행 시에만
