# 정확도 (Accuracy)

**정의**: 전체 예측 중 **맞춘 비율**. `(TP + TN) / 전체`. 가장 직관적인 분류 성능 지표.

---

## 왜 필요한가

"이 모델 몇 % 맞혀?"라는 가장 기본적인 질문에 답한다. 다만 이 한 숫자만으로는 부족할 때가 많아 [[정밀도]]·[[재현율]]과 함께 본다.

---

## 어떻게 작동하나

```python
# titanic 실습: sklearn accuracy_score 없이 NumPy로 직접
accuracy = np.mean(y_pred == y_test)
print(f"Model Accuracy on Test Set: {accuracy:.2%}")
# = (TP + TN) / (TP + TN + FP + FN) 와 동일
```

- `y_pred == y_test`는 맞으면 True(1)·틀리면 False(0)인 배열 → 평균이 곧 정답 비율.
- [[혼동행렬]] 관점으로는 대각선(TP+TN)을 전체로 나눈 값.

---

## 자주 헷갈리는 것

**불균형 데이터의 함정.** 생존자가 10%뿐이면 "전부 사망(0)"이라 찍어도 정확도 90%가 나온다. 하지만 생존자를 하나도 못 찾으니 [[재현율]]은 0. 그래서 정확도만 믿으면 안 되고 [[F1점수]]를 함께 본다.

---

## 더 알면 좋은 것

📌 titanic처럼 생존/사망이 크게 불균형하지 않은 데이터에선 정확도가 꽤 유용하다. 하지만 습관적으로 혼동행렬 전체를 같이 출력해 어떤 오류가 많은지 확인하는 게 안전하다. ⚠ 노션 원문엔 실제 정확도 수치가 없음(실행 결과 미기재) — 계산식만 확인.
