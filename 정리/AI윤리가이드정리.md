# AI 윤리·안전 활용 가이드 정리

AI를 안전하고 책임감 있게 쓰는 핵심 가이드를 **섹션별로 한눈에**. 상세는 개념 페이지 링크에서.

## 1. 데이터 입력 위험 → [[AI윤리가이드]]

```
민감정보를 AI에 입력 → 학습/유출 가능성 → 정보 노출 위험
```

- **왜 위험?** AI에 넣은 입력이 학습 데이터로 쓰이거나 저장될 수 있어서.
- **그래서?** 회사 기밀·개인정보는 그대로 넣지 말고, 입력 자체를 최소화한다.
- AI 도입/활용률 통계 `72% / 78% / 86.0%` (IDC 추정, 출처·정의 `[원문 확인 필요]`)
- OpenAI·Anthropic 이용약관에서 입력 데이터 처리 정책 확인 권장

## 2. 개인정보 비식별화 → [[개인정보비식별화]]

```
[원본]   전화 123-4567-890, 이메일 asdfgh@gmail.com, 12월 15일
[방법1]  플레이스홀더: XXX-YYYY-ZZZZ, sample@email, XX월 YY일
[방법2]  변수형:      [전화번호1], [이메일1], [날짜1]
```

- **왜?** 이름만 가려도 전화·이메일·날짜·금액 조합으로 신원이 드러나서.
- **그래서?** 식별 가능한 항목을 전부 마스킹/치환 후 입력. 변수형은 결과 복원에 유리.
- 단, 비식별화는 위험 완화일 뿐 — 민감정보 입력 최소화가 우선.

## 3. API 키 보안 → [[API키보안]]

```
키 하드코딩 금지 → 환경변수/별도 파일로 분리 → .gitignore에 추가
GitHub 공개 저장소 노출 금지 (노출 시 악용 위험)
```

- **왜?** 키는 곧 "내 계정으로 호출할 권한" — 새면 남이 내 비용·데이터를 쓴다.
- **그래서?** 코드에 박지 말고 환경변수로 분리, `.gitignore`로 깃 추적 제외.
- 이미 커밋·노출됐다면 지우는 것으로 끝이 아니라 **즉시 키 폐기·재발급**.

## 4. 안전한 AI 활용 4단계

```
01 → 02 → 03 → 04
(데이터 식별·분류 / 마스킹·MFA / URL·접근관리 / 권한)
```

- **왜 단계화?** 한 번에 다 막기 어려우니 식별→보호→접근→권한 순으로 좁혀가서.

## 5. 환각 · 아첨 → [[Hallucination]] · [[Sycophancy]]

```
Hallucination : 근거 없는 정보를 사실처럼 생성 → 교차검증 필요
Sycophancy    : 사용자에 무비판 동조 → 반론 요청·객관자료 대조
```

- **환각이 왜?** LLM은 "그럴듯한 다음 토큰"을 예측할 뿐, 사실 여부를 보장 안 해서.
- **그래서?** 자신감 있는 어조에 속지 말고 1차 출처로 확인.
- **아첨이 왜?** 사람이 동의해주는 답을 더 좋게 평가 → 모델이 맞장구를 학습해서.
- **그래서?** 내 결론을 미리 흘리지 말고 중립적으로 질문, 일부러 반론을 요청.
- 둘이 겹치면 "원하는 거짓을 자신 있게" 말해 가장 위험 → 6·7번이 안전망.

## 6. AI 답변 교차검증 (원문 C8)

```
한 모델의 답 → [다른 모델/다른 출처로 대조] → [1차 출처 확인] → 사용
```

- **왜?** 환각·아첨 탓에 단일 답은 틀려도 그럴듯하게 보여서.
- **그래서?** 중요한 사실은 여러 모델·여러 출처로 교차검증하고, 가능하면 원문(1차 자료)을 직접 확인한다.
- 코드·수치·법규처럼 틀리면 손해 큰 영역일수록 교차검증을 강하게.

## 7. 책임 — AIR CANADA 사례 → [[AI윤리가이드]]

```
항공사 챗봇 오안내 → 회사가 책임 인정 (실제 분쟁 사례)
```

- **왜 중요?** "AI가 틀렸다"는 면책 사유가 안 됐다 — 도구의 출력도 그 도구를 쓴 주체의 책임.
- **그래서?** 고객 응대·법규 안내 등은 사람이 최종 검수. 세부 사실관계는 `[원문 확인 필요]`.

## 8. Human in the Loop → [[HumanInTheLoop]]

```
Human (지시·맥락 Context) → AI (초안 Draft) → Human (검토·수정·최종 책임)
```

- **왜?** 환각·아첨·책임 문제를 한 번에 막는 실용적 안전장치라서.
- **그래서?** AI는 빠른 초안 담당, 사실·품질·책임의 최종 판단은 사람이 쥔다.
- 마무리 메시지: **"AI는 도구(tool)"** — 운전대는 사람이 잡는다.
