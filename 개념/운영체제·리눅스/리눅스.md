# 리눅스 (Linux)

**정의**: 오픈소스 운영체제 커널. 서버·클라우드·임베디드 환경의 사실상 표준.

---

## 왜 필요한가

전 세계 서버의 90% 이상이 Linux다. AWS, Google Cloud, Azure — 모두 Linux 위에서 돌아간다. 개발자·데이터 분석가·DevOps 어느 방향이든 Linux 기초는 필수다.

Linux의 핵심 철학: **"모든 것은 파일이다"** — 텍스트, 장치, 소켓, 심지어 프로세스도 파일처럼 다룬다.

---

## 어떻게 작동하나

### 구조

```
사용자
  ↕
Shell (bash, zsh, ...)     ← 명령어 입력받아 커널에 전달
  ↕
Kernel                     ← 하드웨어 직접 제어
  ↕
Hardware
```

**Shell**: 검은 화면(터미널). 명령어를 입력하면 커널에 전달한다. 기본 Shell은 `bash`, Mac은 `zsh`.

### 필수 명령어

**위치·탐색**:
```bash
pwd                    # 현재 위치 출력 (/home/user/projects)
ls                     # 파일 목록
ls -al                 # 숨김파일 포함 + 상세 정보 (권한·크기·날짜)
cd /home/user          # 절대 경로로 이동
cd ..                  # 상위 폴더로
cd ~                   # 홈 폴더로
```

**파일·폴더 관리**:
```bash
mkdir mydir            # 폴더 생성
mkdir -p a/b/c         # 중첩 폴더 한번에 생성
touch hello.txt        # 빈 파일 생성
cp a.txt b.txt         # 복사
cp -r src/ src_backup  # 폴더 복사 (-r 필수)
mv a.txt b.txt         # 이동 또는 이름 변경
rm a.txt               # 파일 삭제 (휴지통 없음!)
rm -r mydir            # 폴더 삭제
rm -rf mydir           # 강제 삭제 (물어보지 않음) ← 주의!
```

**파일 내용**:
```bash
cat a.txt              # 전체 출력
head -20 a.txt         # 앞 20줄
tail -20 a.txt         # 뒤 20줄
tail -f server.log     # 실시간으로 추가되는 내용 보기 (로그 모니터링)
grep "error" a.txt     # 특정 단어 포함 줄만 출력
grep -n "error" a.txt  # 줄 번호 포함
```

**파이프(|)** — 명령어 연결:
```bash
# 앞 명령의 출력을 뒷 명령의 입력으로
ps -aux | grep python          # 실행 중 프로세스 중 python만
cat access.log | grep "404"    # 로그에서 404 에러만
ls -al | grep ".py"            # .py 파일만 필터
```

**권한**:
```bash
ls -al
# -rwxr-xr--  파일명
#  ↑↑↑ ↑↑↑ ↑↑↑
#  소유자 그룹 기타

chmod 755 script.sh    # rwxr-xr-x (소유자 전권, 나머지 읽기·실행)
chmod 644 index.html   # rw-r--r-- (소유자 읽기·쓰기, 나머지 읽기만)
sudo chmod 777 file    # rwxrwxrwx (모두 전권, 보안상 비권장)
```

권한 숫자: r=4, w=2, x=1 → 7=rwx, 6=rw-, 5=r-x, 4=r--

**프로세스**:
```bash
ps -aux                # 전체 프로세스 목록
top                    # 실시간 모니터링
kill -9 1234           # PID 1234 강제 종료
```

**예약 작업(cron)**:
```bash
crontab -e             # 예약 작업 편집
# 분 시 일 월 요일  명령어
0  9  *  *  1  /backup.sh    # 매주 월요일 오전 9시
*/5  *  *  *  *  /check.sh   # 5분마다
```

**원격 접속(SSH)**:
```bash
ssh user@192.168.0.100         # IP로 접속
ssh user@server.example.com   # 도메인으로 접속
```

## 실제 예시

- AWS EC2 서버를 생성하면 터미널로 SSH 접속해서 Linux 명령어로 관리
- GitHub Actions, Docker 컨테이너도 Linux 환경에서 실행
- Python 스크립트를 서버에서 자동 실행할 때 cron 사용
- `tail -f server.log` 로 실시간 서버 로그 모니터링

## 자주 헷갈리는 것

**"Linux = Ubuntu"**: Linux는 커널 이름. Ubuntu, CentOS, Debian, Rocky Linux 등은 Linux 커널을 기반으로 만든 배포판.

**"`rm -rf /`"**: 루트 디렉토리를 강제 삭제한다는 의미. 시스템 전체 파일이 삭제된다. 인터넷에서 장난으로 알려주는 악의적인 명령어.

**"sudo는 항상 써도 된다"**: sudo는 관리자 권한으로 실행. 잘못 쓰면 시스템 파일을 망가뜨릴 수 있다. 일반 작업에는 쓰지 않는 게 원칙.

## 더 알면 좋은 것

📌 **셸 스크립트(Shell Script)**: 명령어들을 파일로 묶어 자동화. `.sh` 확장자. 반복 작업 자동화, 배포 스크립트 등에 활용.

📌 **환경 변수**: `export API_KEY="abc123"` — 프로그램에 설정을 전달하는 방법. `.env` 파일로 관리하는 게 관례.

📌 **패키지 관리자**:
- Ubuntu/Debian: `apt install nginx`
- CentOS/RHEL: `yum install nginx` 또는 `dnf install nginx`
- macOS: `brew install nginx` (Homebrew)

📌 **[explainshell.com](https://explainshell.com/)**: 명령어를 붙여넣으면 각 옵션의 의미를 자세히 설명해줌.
