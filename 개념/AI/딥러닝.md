# 딥러닝 (Deep Learning)

**정의**: 인간 뇌의 신경망 구조를 모방한 인공신경망(Artificial Neural Network)을 여러 층 쌓아 학습하는 머신러닝 방법.

---

## 왜 필요한가

기존 머신러닝은 사람이 직접 "어떤 특징을 봐야 하는지"를 알려줘야 했다. 고양이 분류라면 "털의 길이, 귀 모양, 수염 유무..." 같은 특징(Feature)을 개발자가 직접 설계해야 했다.

딥러닝은 이걸 자동으로 한다. 사진을 그냥 넣으면 어떤 특징이 중요한지 스스로 찾아낸다.

---

## 어떻게 작동하나

### 인공신경망 구조

```
[입력층]   [은닉층들 (깊이)]              [출력층]

X1 ──┐
X2 ──┤──→ [뉴런]──→ [뉴런]──→ ... ──→ [결과]
X3 ──┘      층1         층2
```

- **뉴런**: 입력을 받아 가중치를 곱하고 활성화 함수를 거쳐 출력
- **가중치(Weight)**: 학습을 통해 조정되는 값. 학습 = 가중치 최적화
- **깊이(Depth)**: 은닉층이 많을수록 "딥"러닝

### 학습 과정

```
1. 데이터 입력 (고양이 사진)
2. 순전파(Forward): 각 층을 통과하며 예측값 계산
3. 오차 계산: 예측값 vs 정답 비교
4. 역전파(Backpropagation): 오차를 역방향으로 전달, 가중치 조정
5. 반복 → 오차가 줄어듦
```

### 주요 아키텍처

| 아키텍처 | 특화 분야 | 대표 사용처 |
|:---|:---|:---|
| **CNN** (합성곱 신경망) | 이미지 처리 | 얼굴 인식, 의료 영상 분석 |
| **RNN** (순환 신경망) | 순서 있는 데이터 | 번역, 음성 인식 (과거) |
| **LSTM** | 장기 의존성 학습 | 자연어 처리 (과거) |
| **Transformer** | 병렬 처리, 문맥 이해 | GPT, BERT, Claude (현재 표준) |
| **GAN** | 이미지 생성 | Deepfake, Stable Diffusion |

---

## 실제 예시

- **스마트폰 얼굴 인식**: CNN이 얼굴 특징점 감지
- **Google 번역**: Transformer 기반 번역 모델
- **ChatGPT, Claude**: GPT·Claude는 모두 Transformer 기반 LLM
- **유튜브 자동 자막**: RNN/Transformer 기반 음성 인식
- **Midjourney**: GAN + Diffusion 모델로 이미지 생성
- **Tesla 자율주행**: CNN으로 카메라 영상 실시간 분석

---

## 자주 헷갈리는 것

**"딥러닝은 항상 머신러닝보다 낫다"**: 아니다.
- 데이터가 적으면 과적합 심해짐
- 해석이 어려움 (블랙박스)
- 학습 시간·비용이 많이 필요
- 데이터가 충분하고 복잡한 패턴이 있을 때 효과적

**"딥러닝 = AI"**: 딥러닝은 AI의 한 방법론이다. AI > 머신러닝 > 딥러닝 순으로 포함 관계.

---

## 더 알면 좋은 것

📌 **GPU가 필요한 이유**: 딥러닝은 행렬 연산이 핵심. CPU는 순차 처리에 강하지만 GPU는 병렬 처리에 최적화되어 있어 행렬 연산이 수백 배 빠르다. NVIDIA CUDA가 딥러닝 표준.

📌 **Transformer의 핵심 — Attention**: "이 단어를 이해하려면 문장의 어떤 부분에 집중해야 하는가"를 학습. "I saw a man with a telescope" — "saw"가 "I"와 "man" 중 어느 것과 연결되는지 파악 가능.

📌 **사전학습(Pre-training) + 파인튜닝(Fine-tuning)**: 대규모 데이터로 사전학습 후, 특정 태스크에 맞게 소량 데이터로 추가 학습. LLM이 일반적으로 강한 이유.
