# Peter Chen 표기법

**정의**: [[ERD]]를 그리는 고전적 표기법. 개체·속성·관계를 **사각형·타원·마름모** 같은 도형으로 나타낸다.

---

## 왜 필요한가

데이터 모델을 사람이 한눈에 읽도록 시각화하는 표준 중 하나. 개념 설계 단계에서 개체와 관계를 도형으로 정리할 때 쓴다.

---

## 어떻게 작동하나

| 기호 | 의미 |
|:---|:---|
| 사각형 □ | 개체(Entity) |
| 타원 ○ | 속성(Attribute) |
| 마름모 ◇ | 관계(Relationship) |
| 밑줄 _ | 기본키 |
| 이중타원 ◎ | 다중값 속성 |

**카디널리티 표기:** `1` = 1:1 / `<` = 1:N / `><` = N:M.

```
[고객] ──1── ◇대여◇ ──<── [직원]
   (한 고객은 한 번에 하나의 직원으로 대여 = 1:N)
```

---

## 실제 예시

- 슬라이드 요구사항: 고객(이름·ID·PW·전화·생년월일), 직원(고유번호·이름·역할·연락처), 대여(상태·반납시간·위치) → Chen 표기로 개체·관계 도식화. 도구는 draw.io.

---

## 자주 헷갈리는 것

**Chen vs [[IE까마귀발표기법]].** Chen은 속성을 **타원으로 따로** 그려 도식이 커진다. IE/까마귀발은 속성을 **박스 안에 목록**으로 넣어 실무 ERD에서 더 흔하다.

---

## 더 알면 좋은 것

📌 다중값 속성(이중타원)은 한 개체가 여러 값을 갖는 속성(예: 전화번호 여러 개) → 실제 구현 시 별도 테이블로 분리되기도 한다.
