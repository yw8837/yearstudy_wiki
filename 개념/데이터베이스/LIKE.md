# LIKE (패턴 검색)

**정의**: 특정 문자가 **포함된 문자열**을 찾을 때 쓰는 조건 명령. 와일드카드 `%`와 함께 사용한다.

---

## 왜 필요한가

"정확히 같다"(`=`)가 아니라 "~로 시작/끝/포함" 같은 **부분 일치** 검색이 필요할 때 쓴다(제목·이름 검색 등).

---

## 어떻게 작동하나

`%`는 임의의 문자열(0글자 이상)을 의미한다.

| 패턴 | 의미 |
|:---|:---|
| `'K%'` | K로 **시작** |
| `'%K'` | K로 **끝** |
| `'%K%'` | K **포함** |

```sql
SELECT * FROM albums WHERE Title LIKE 'Rock%';          -- Rock으로 시작
SELECT * FROM albums WHERE Title LIKE '%Live';          -- Live로 끝
SELECT * FROM tracks WHERE Name LIKE '%Love%' LIMIT 10; -- Love 포함
```

---

## 실제 예시

- 제목에 'the'가 들어간 책: `WHERE title LIKE '%the%'` (SQLite는 기본 대소문자 무시).

---

## 자주 헷갈리는 것

**`%` 위치가 의미를 바꾼다**: 앞·뒤·양쪽에 따라 시작/끝/포함이 결정된다.

**`_`(언더스코어)**: 한 글자 매칭 와일드카드(이번 수업 범위 밖이지만 존재).

---
