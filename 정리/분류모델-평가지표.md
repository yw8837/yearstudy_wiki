# 분류 모델 평가지표 정리

> 출처: [[0629-로지스틱회귀실습]] · 상세: [[혼동행렬]] · [[정확도]] · [[정밀도]] · [[재현율]] · [[F1점수]]
> ⚠ titanic 실습은 sklearn 없이 **NumPy 손계산**. 노션 원문엔 실행 결과 수치 없음([출력 없음]) — 공식·구조만.

이진 분류 성능을 재는 지표들. 전부 [[혼동행렬]] 네 칸에서 파생된다.

---

## 1. 혼동행렬 (모든 지표의 재료) → [[혼동행렬]]

```
              Predicted 0    Predicted 1
Actual 0        TN            FP        (거짓양성)
Actual 1        FN            TP        (거짓음성=놓침)
```

```python
TP = np.sum((y_pred == 1) & (y_test == 1))   # 앞글자 T/F=맞췄나
TN = np.sum((y_pred == 0) & (y_test == 0))   # 뒷글자 P/N=뭐라 예측
FP = np.sum((y_pred == 1) & (y_test == 0))
FN = np.sum((y_pred == 0) & (y_test == 1))
```

- 불리언 마스크 `&`로 네 칸 수동 카운트.
- **FP**(아닌데 맞다 함) vs **FN**(맞는데 놓침) — 어느 오류가 더 나쁜지는 상황마다 다르다.

---

## 2. 정확도 → [[정확도]]

```python
accuracy = np.mean(y_pred == y_test)    # = (TP+TN)/전체
```

- 전체 중 맞춘 비율. 가장 직관적.
- ⚠ **불균형 함정**: 양성이 드물면 "전부 0" 찍어도 높게 나옴 → 정밀도/재현율 병행.

---

## 3. 정밀도 → [[정밀도]]

```python
precision = TP / (TP + FP) if (TP + FP) > 0 else 0
```

- **예측 양성 기준**: 1이라 한 것 중 진짜 1 비율.
- 거짓양성(FP)이 비쌀 때 중요(스팸 필터).

---

## 4. 재현율 → [[재현율]]

```python
recall = TP / (TP + FN) if (TP + FN) > 0 else 0
```

- **실제 양성 기준**: 진짜 1 중 찾아낸 비율(=민감도).
- 놓침(FN)이 치명적일 때 중요(암 진단).

---

## 5. F1 점수 → [[F1점수]]

```python
f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
```

- 정밀도·재현율의 **조화평균**. 한쪽이 낮으면 F1도 낮음.
- 불균형 데이터의 단일 지표로 정확도보다 신뢰.

## 한눈 요약표

| 지표 | 공식 | 분모 기준 | 언제 중요 |
|:--|:--|:--|:--|
| [[정확도]] | (TP+TN)/전체 | 전체 | 균형 데이터 |
| [[정밀도]] | TP/(TP+FP) | 예측 양성 | FP 비쌀 때 |
| [[재현율]] | TP/(TP+FN) | 실제 양성 | FN 치명적일 때 |
| [[F1점수]] | 2PR/(P+R) | — | 불균형·균형 요약 |

- **정밀도↔재현율 트레이드오프**: [[의사결정경계|임계값]] 올리면 정밀도↑·재현율↓.
