## 수업 포인트

- **라이브러리** = 미리 만들어진 코드 묶음. 표준(내장: math·random) vs 외부(설치: numpy·pandas)
- **PyPI** = 외부 라이브러리 창고 → `pip install`로 내려받음
- **설치**: `pip install 이름`, `pip freeze > requirements.txt`, `-r`로 일괄 설치 (우리는 uv)
- **사용**: `import 라이브러리 as 별칭`(pd·np 관례), 공식 문서 보는 습관
- **공유(배포)**: 패키지 구조 + `pyproject.toml` → `python -m build` → `twine upload` → 누구나 `pip install`
- 4개 섹션(세계 탐험 / 설치 / 사용 / 공유) 순서로 진행

## 보충

📌 **가상환경**: 프로젝트별 독립 패키지 공간(버전 충돌 방지). uv가 `.venv`로 자동 관리.

📌 **TestPyPI**: 실제 배포 전 연습용. / **시맨틱 버저닝**: `major.minor.patch`.

📌 주요 외부 라이브러리: numpy·pandas·matplotlib·seaborn·scikit-learn·requests·BeautifulSoup.
