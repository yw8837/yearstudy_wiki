## 01. 자료의 형태 → [[자료의형태]]

자료를 **측정 가능 여부**로 분류한다. 이 분류가 이후 모든 요약 기법(어떤 그래프·어떤 측도)을 결정한다.

```
자료
├─ 수치형(Numerical=양적) ── 수치 측정 가능 ── 선형회귀 등
│   ├─ 연속형(Continuous) : 연속 관측값 (3.1415…, 시간 09:12:23.21…)
│   └─ 이산형(Discrete)   : 셀 수 있는 값 (조회수, 인원수)
└─ 범주형(Categorical=질적) ── 측정 불가 ── 로지스틱회귀 등
    ├─ 명목형(Nominal) : 순서 의미 없음 (혈액형 A·B·O·AB)
    └─ 순위형(Ordinal) : 순서 의미 있음 (학점 A+·A·A-)
```

- **구분 주의점(PDF p10~11) — 숫자 표현 여부로 판단하지 말 것:**
  - 범주형이 숫자로 코딩돼도 범주형: 성별을 남=1·여=0으로 코딩 → 여전히 **범주형**.
  - 수치형을 구간화하면 범주형: 나이(수치형)를 10~19세/20~29세로 구간화 → **범주형**.
  - 연속↔이산: 시간은 본래 연속이나 "09시12분"으로 반올림하면 이산형으로 사용.
- **메모:** `viz_basic_01` cell 6의 tips 컬럼 분류와 직접 대응 — 연속(total_bill·tip), 이산(size 1~6명), 명목(sex·smoker·time), 순위(day Thur<Fri<Sat<Sun).

## 02. 범주형 자료 요약 → [[도수분포표]] · [[교차표]]

| 용어 | 정의 | pandas |
|:--|:--|:--|
| [[도수분포표\|도수(Frequency)]] | 각 범주에 속하는 관측값 개수 | `value_counts()` |

| [[교차표\|두 범주 교차표]] | 두 범주 동시 도수 | `pd.crosstab(index=범주, columns=또다른범주)` |

| 차트 | 코드 | 장점 | 단점 |
|:--|:--|:--|:--|

## 03. 수치형 자료 요약 → [[히스토그램]] · [[도수다각형]]

관측값 종류 수가 **적으면 범주형 기법, 많으면 연속형 기법**. 연속형 요약 5기법: [[점도표]]·도수분포표·[[히스토그램]]·[[도수다각형]]·[[줄기잎그림]].

- **[[점도표|점도표(dot diagram)]]:** 관측값 적을 때(20~25 이하). 줄 위에 각 관측값을 점으로. **[노트북 미커버 — PDF 이론에만]**.
- **도수분포표 작성순서(p34~35):** ① 범위(max-min) → ② 계급의 폭 → ③ 계급구간 경계점 → ④ 도수 → ⑤ 상대도수. (계급=구간, 계급폭=구간 크기)
- **[[히스토그램|히스토그램(Histogram)]]:** `plt.hist()`. X=계급, Y=빈도. 도수분포표 기반, 각 계급을 범주처럼 사용(막대그래프와 동일 방식). 계급폭이 같으면 도수/상대도수를 막대높이로.
- **[[도수다각형|도수다각형]]:** 각 계급 중앙에 점을 찍어 직선 연결. 집중 위치·치우침·꼬리 두터움 등 분포 상태 파악. **여러 자료 비교 시 히스토그램보다 도수다각형이 적합**(꺾은선 겹쳐 비교).
- **[[줄기잎그림|줄기-잎그림(stem-leaf)]]:** 앞단위=줄기(세로 배열), 뒷단위=잎(오름차순). 예) 35 → 줄기 3, 잎 5. 장점=원 관측값 유지+최대/최소 위치 파악 / 단점=관측값 많으면 부적합. **[노트북 미커버 — PDF 이론에만]**.

> ⚠ **노트북 미커버:** 점도표·줄기잎그림·"분포의 모양"은 **시각화 PDF 이론에만** 존재하고 `viz_basic_01`에 코드 구현이 없다. 히스토그램·도수다각형은 cell 14·16에 구현.

## 04. 중심위치의 측도 → [[평균]] · [[중앙값]] · [[최빈값]]

- **왜 수치 요약(p4~5):** 그림/도표는 ① 작성자 주관에 따라 결과가 달라지고(객관성 부족) ② 이론적 근거 제시가 어렵다 → 많은 자료를 의미 있는 **수치**로 요약. 수치 요약 4주제 = 중심위치·산포·도수분포표 요약·두 변수 요약.

| 측도 | 정의 | 코드 | 특징 |
|:--|:--|:--|:--|
| [[평균\|평균(Mean)]] | $\bar{x}=\frac{x_1+\cdots+x_n}{n}$ | `np.mean()` | 가장 많이 사용, **극단값에 민감** |
| [[중앙값\|중앙값(Median)]] | 정렬 후 가운데 값 | `np.median()` | **극단값 영향 없음(강건)** |
| [[최빈값\|최빈값(Mode)]] | 가장 자주 나오는 값 | `stats.mode()` | 이산/범주형 적합, **단봉형에서만 유용** |

- **중앙값 계산:** n 홀수 → $\frac{n+1}{2}$번째 / n 짝수 → $\frac{n}{2}$번째와 $\frac{n}{2}+1$번째 평균.
- **세 측도 비교(p15~19):** 극단값 배제 → 중앙값 / 전체 반영 → 평균 / 이산·범주 → 최빈값.
  - 단봉형 대칭: **평균 = 중앙값 = 최빈값**.
  - 다봉형: 평균 = 중앙값 ≠ 최빈값(최빈값은 중심측도 역할 못함).
  - 비대칭: 평균 ≠ 중앙값 ≠ 최빈값.

### ⚠ 치우친 분포 — 두 관례 병기 (출처 상충, 단정 금지)

같은 비대칭 분포를 두고 **두 출처가 반대 라벨**을 쓴다. 둘은 "치우침"의 기준이 다르다.

| 관례 | 기준 | 왼쪽으로 치우침 | 오른쪽으로 치우침 | 출처 |
|:--|:--|:--|:--|:--|
| **봉우리 기준** (한국 통계교재식) | 봉우리(밀집부)가 어느 쪽 | 평균 **>** 중앙값 | 평균 **<** 중앙값 | 논리 PDF p19 슬라이드 + `viz_basic_01` cell 20 마크다운 |
| **꼬리 기준** (영어 skewness) | 긴 꼬리가 어느 쪽 | 평균 **<** 중앙값 (left-skewed) | 평균 **>** 중앙값 (right-skewed) | `viz_basic_01` cell 21 코드 주석/출력 |

- **tips 실측(cell 21):** 평균 **19.79** > 중앙값 **17.80** > 최빈값 13.42. 노트북 코드는 이를 `mean > median → right-skewed(오른쪽 꼬리)`로 라벨(영어 꼬리 기준). 같은 데이터를 봉우리 기준(슬라이드)으로 표현하면 "왼쪽으로 치우친 분포"가 된다.
- **→ 같은 데이터·반대 용어.** 한쪽으로 단정하지 말고 **"어느 기준(봉우리/꼬리)으로 말하는가"를 먼저 명시**할 것. 강사 확인 권장. (지어내지 말 것 — 보충 참조)

- **출처 교차:** `viz_basic_01` cell 21(mean/median/mode 계산 + axvline 시각화).

## 05. 퍼진 정도의 측도 → [[분산]] · [[표준편차]] · [[IQR]] · [[변동계수]]

중심위치만으로는 분포 파악이 부족하다. 평균이 같아도(A σ=10 vs B σ=20) 산포가 다르다.

| 측도 | 정의 | 코드 | 특징 |
|:--|:--|:--|:--|
| [[분산\|분산(Variance)]] | $s^2=\frac{\sum(x_i-\bar{x})^2}{n}$ | `np.var(ddof=1)` | 편차의 합=0이라 **제곱**해 양수화, 단위가 제곱 |
| [[표준편차\|표준편차(Std)]] | $s=\sqrt{s^2}$ | `np.std(ddof=1)` | 분산의 양의 제곱근, **원 변수와 단위 동일** |
| [[범위\|범위(Range)]] | max - min | `np.max()-np.min()` | 간편하나 중간값 무시·극단값 민감 |
| [[IQR]] | Q3 - Q1 | `percentile(75)-percentile(25)` | **극단값 영향 없음** |
| [[변동계수\|변동계수(CV)]] | $\frac{s}{\bar{x}}\times100$ (%) | — | **단위 없음** → 이종 변수 산포 비교 |

> ⚠ **분산의 분모:** 논리 PDF는 **모분산(분모 n)**, 노트북은 **표본분산(ddof=1=n-1, 불편추정량)**. n이 크면 차이 미미하나 정의가 다르다.

- **[[백분위수|백분위수(Percentile)]]:** `np.percentile()`. 제100×p 백분위수 = 정렬 후 n×p가 정수면 (n×p)·(n×p+1)번째 평균, 정수 아니면 정수부+1=m번째 값.
- **[[사분위수|사분위수(Quartile)]]:** Q1=`percentile(25)`, Q2=`percentile(50)`=중앙값, Q3=`percentile(75)`. **IQR = Q3 - Q1**.
- **산포 측도 비교:** 표준편차=전체 골고루 반영(극단값 민감) / IQR=극단값 무관 / 범위=가장 단순(표준편차·IQR 단점 모두 가짐).
- **tips 실측(cell 23):** 분산 79.25 · 표준편차 8.90 · 범위 47.74 · IQR 10.78(Q1 13.35·Q3 24.13) · 변동계수 45.0%. 백분위수(cell 25): P10 10.34·P25 13.35·P50 17.80·P75 24.13·P90 32.24.

## 06. 도수분포표 요약 + [[상자그림]] → [[상자그림]]

- **도수분포표에서의 요약(p43~45):** 원 자료 없이 그룹화된 도수분포표만 있을 때, **각 계급의 모든 값이 중간값(midpoint)을 갖는다고 가정**.
  - 평균: $\bar{x}=\sum m_i\cdot\frac{f_i}{n}$ (계급 중간값 × 상대도수의 합)
  - 분산: $s_g^2=\frac{1}{n-1}\sum(m_i-\bar{x}_g)^2 f_i$
  - **주의: 그룹화는 정보 손실** → 가능하면 원 자료 사용. (cell 29: 원자료 평균 19.79 vs 그룹 평균 19.66, 원자료 σ 8.90 vs 그룹 σ 8.95)
- **[[상자그림|상자그림(Box-Whisker)]]:** `plt.boxplot()`. **다섯 수치 요약**(최솟값·Q1·Q2·Q3·최댓값).

```
      Q1   Q2   Q3
  ├───┤ ▓▓▓│▓▓▓ ├───┤      수염 = Q1-1.5×IQR ~ Q3+1.5×IQR
  └─┬─┘            └─┬─┘    그 바깥 점 = 이상값(outlier)
  최솟값            최댓값
```

- **주의:** 봉우리 하나인 단봉형에 적절, 다봉형엔 부적합 → **상자그림 전 [[히스토그램]]으로 분포 형태를 먼저 파악**.
- **출처 교차:** `viz_basic_01` cell 27(요일별 total_bill / 흡연별 tip boxplot), cell 29(midpoint 가정 도수분포표 요약).

## 07. 두 변수 자료 요약 → [[공분산]] · [[상관계수]] · [[분할표]]

둘 이상 변수를 동시 분석. **범주형×범주형 → [[분할표]] / 연속형×연속형 → [[산점도]]·[[공분산]]·[[상관계수]]**.

- **[[분할표|분할표(Contingency Table)]]:** `pd.crosstab(index=기준범주, columns=관측범주)`. 도수분포표를 2차원으로 확장. (행/열/전체 기준 상대도수: `normalize="index"/"columns"`)
  - cell 31 tips 요일×식사시간: Thur(Lunch 61/Dinner 1), Fri(7/12), Sat(0/87), Sun(0/76). 행 기준%: Thur(98.4/1.6).
- **[[산점도|산점도(Scatter)]]:** `plt.scatter(x, y)`. 두 연속형 관계 시각화. 관측값 많으면 띠 형태. **상관계수 계산 전 반드시 산점도 먼저 확인.**
- **[[공분산|공분산(Covariance)]]:** `df.cov()`. $S_{xy}=\frac{1}{N}\sum(x_i-\bar{x})(y_i-\bar{y})$. 같은 방향 변화 → 양수, 반대 → 음수. **단점: 단위 있어 스케일 의존, 크기 해석 어려움.**
- **[[상관계수|상관계수(Correlation, 피어슨)]]:** `df.corr()`. $r=\frac{S_{xy}}{\sqrt{S_{xx}}\sqrt{S_{yy}}}$, 항상 **-1 ~ 1**.

```
 r>0 좌하→우상 띠(비례)   r<0 좌상→우하 띠(반비례)
 r=±1 모든 점이 직선 위   r≈0 선형관계 없음
```

  - 특징: **단위 없음** → 이종 변수 직선관계 비교 가능. **직선(선형) 관계만** 측정(곡선은 r≈0 가능), 이상값 하나에 크게 변함.
  - tips 실측(cell 33): cov(total_bill, tip)=8.3235, **r=0.6757**. 상관행렬 total_bill–tip 0.676 · total_bill–size 0.598 · tip–size 0.489.
- **★[[상관과인과|상관 ≠ 인과]](p72~75):** 큰 상관계수가 인과를 의미하지 않음. 예) 상어 물림 사고↑ ↔ 아이스크림 판매↑ — 공통 원인은 "여름"(허위 상관, spurious correlation). 어제 [[상관관계와인과관계]](6/17)의 통계적 재확인.

→ [[공분산]] · [[상관계수]] · [[분할표]] · [[산점도]] · [[상관과인과]] · [[상관관계와인과관계]] 참조

# 방식 1 — plt 직접 호출 (암묵적, 비권장)

## 09. [[시각화디자인원칙|시각화 디자인 원칙]] — Wilke / Okabe-Ito

Claus O. Wilke 『Fundamentals of Data Visualization』 반영. 어제 [[데이터시각화-원칙]] 이론의 코드화.

- **6원칙:** ① 색은 **데이터를 인코딩할 때만**(장식용 무지개 금지) ② **동일 범주 → 동일 색**(노트북 전체 일관) ③ **색각 이상 친화**(Okabe-Ito 팔레트, [[CVD]]) ④ **강조 절제**(한 그래프 강조만 vermillion #D55E00) ⑤ 연속형·분포는 단일 색조(청색)의 농도/투명도 ⑥ **Data-ink**(상·우 spine 제거, 격자는 필요 축만).

```python
PALETTE_OI = ["#E69F00","#56B4E9","#009E73","#F0E442",
              "#0072B2","#D55E00","#CC79A7","#000000"]  # Okabe-Ito (색각친화)
COLOR_SEQ="#0072B2"; COLOR_EMPHASIS="#D55E00"; COLOR_NEUTRAL_BAR="#B0B0B0"
def stable_cat_colors(values, palette=PALETTE_OI):   # 범주→색 고정 매핑(차트 간 공유)
    cats = sorted(pd.Series(values).dropna().unique())
    return {c: palette[i % len(palette)] for i, c in enumerate(cats)}
```

- **[코드노트용 디버깅]** Colab 최초 1회 `!sudo apt-get install -y -qq fonts-nanum` 후 **런타임 재시작**, `drive.mount("/content/drive")`.
