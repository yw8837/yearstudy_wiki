# 자기회귀 (Auto Regression)

**정의**: 이전에 생성된 토큰들을 입력으로 받아 **다음 토큰의 확률분포를 산출하고 샘플링**해, 한 토큰씩 이어붙여 문장을 만드는 [[LLM]]의 생성 방식.

---

## 왜 필요한가

LLM은 문장을 통째로 한 번에 뱉지 않는다. "다음에 올 가장 그럴듯한 토큰"을 하나 고르고, 그것을 다시 입력에 더해 또 다음 토큰을 고른다. 이 반복이 곧 글쓰기다.

---

## 어떻게 작동하나

입력 `Second law of robotics : a` 에 대한 다음 토큰 확률:

| 후보 | 확률 |
|:---|:---:|
| **Robot** | **0.80** |
| Person | 0.16 |
| Bird | 0.02 |
| Lion | 0.01 |

→ `Robot` 선택 → `... : a Robot` → 이 결과를 다시 입력으로 → 반복.

```
입력 → 다음 토큰 확률분포 → 샘플링 → 이어붙이기 → (다시) 입력 → ...
```

---

## 자주 헷갈리는 것

**"항상 최고 확률만 고른다"**: 꼭 그렇진 않다. temperature 등으로 확률적으로 샘플링하면 다양성이 생긴다. 최고 확률만 고르면(greedy) 단조로워진다.

**"앞으로만 본다"**: 자기회귀 생성은 왼→오 한 방향. 그래서 이미 쓴 토큰은 못 고친다.

---
