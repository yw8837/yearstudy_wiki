# 📚 yearstudy_wiki

> 이어드림스쿨 AI 6기 수업을 들으면서 쌓아가는 **개인 학습 위키**.

매일 들은 강의를 **이해한 내용**으로 정리해 둔 지식 저장소입니다.
[Obsidian](https://obsidian.md)으로 열면 노트끼리 `[[링크]]`로 연결돼 가장 편하게 볼 수 있습니다.

---

## 🗂️ 구조 — 3층 + 지도

이 위키는 **강의 → 개념 → 정리** 3층으로 쌓고, **인덱스/색인**으로 찾습니다.

| 폴더 | 역할 | 비유 |
|:---|:---|:---|
| **`강의/`** | 날짜별로 그날 들은 강의 노트 | 일기 |
| **`개념/`** | 개념 하나를 깊게 파는 페이지 (주제별 하위폴더) | 백과사전 |
| **`정리/`** | 한 주제를 섹션별로 요약한 치트시트 | 요약본 |
| **`인덱스.md`** | 위키 전체 지도 (큰 목차) | 책 앞 목차 |
| **`개념/색인.md`** | 키워드 사전 (세부 용어로 바로 점프) | 책 뒤 찾아보기 |

```
yearstudy_wiki/
├── 인덱스.md            ← 전체 지도 (여기서 시작!)
├── 강의/               ← 날짜별 강의 노트 (0526, 0527, …)
├── 정리/               ← 주제별 요약 (파이썬-문법, 리눅스-기초, 개발환경-설정 …)
├── 개념/
│   ├── 색인.md          ← 키워드로 찾기
│   ├── 파이썬/          (자료형·변수·연산자·문자열·반복문·함수 …)
│   ├── 운영체제·리눅스/   (리눅스·파일명령어·권한·검색파이프·프로세스 …)
│   ├── IT기초/          (HTTP·IP·DNS·TCP·UDP·네트워크·해시 …)
│   ├── AI/             (AI·머신러닝·딥러닝·LLM·크롤링)
│   └── 도구/           (Git·uv·Docker·VSCode·마크다운)
└── raw/                ← 원본 자료 (수정 금지)
```

## 🚀 사용 방법

### 방법 1. Obsidian으로 열기 (✅ 권장)

노트 연결(`[[링크]]`), 그래프 뷰, 검색이 모두 작동합니다.

1. **Obsidian 설치** → **https://obsidian.md/download** (Windows / macOS / Linux 무료)
2. 이 저장소를 내 컴퓨터로 내려받기 — 아래 **두 방법 중 하나**

   **🟢 방법 A. ZIP 다운로드 — git 몰라도 OK (초보자 추천)**
   1. 이 저장소 페이지 오른쪽 위 초록색 **`<> Code`** 버튼 클릭
   2. 메뉴 맨 아래 **`Download ZIP`** 클릭 → zip 파일이 다운로드됨
   3. 받은 zip을 **압축 해제** → `yearstudy_wiki` 폴더가 생김

   > ⚠️ ZIP은 "받은 그 시점의 사본"이라, 나중에 내용이 바뀌면 **다시 받아야** 합니다(자동 갱신 안 됨).

   **🔵 방법 B. git clone — 터미널을 쓸 줄 알면**
   ```bash
   git clone https://github.com/yw8837/yearstudy_wiki.git
   ```
   > 이후 `git pull` 한 번이면 최신 내용으로 갱신돼서 편합니다.

3. Obsidian 실행 → **`Open folder as vault`** (폴더를 보관소로 열기) → 내려받은(압축 푼) `yearstudy_wiki` 폴더 선택
4. 끝! 좌측 사이드바에서 폴더를 탐색하거나, `인덱스.md`부터 시작하세요.

> 💡 **검색**: `Ctrl/Cmd + Shift + F` 전체 검색, `Ctrl/Cmd + O` 빠른 파일 열기.
> 💡 **그래프 뷰**: 좌측 그래프 아이콘 → 개념들이 어떻게 연결됐는지 한눈에.

### 방법 2. GitHub에서 바로 읽기

설치 없이 브라우저로 읽을 수 있습니다. 다만 **`[[위키링크]]`는 GitHub에서 클릭되지 않고 글자로만 보입니다** (Obsidian 전용 문법). 링크까지 누리려면 방법 1을 권장합니다.

## 🧭 어디서부터 볼까?

| 상황 | 여기로 |
|:---|:---|
| 전체 큰 그림 보기 | **`인덱스.md`** |
| 특정 용어 찾기 (예: "range가 뭐였지?") | **`개념/색인.md`** → 키워드 클릭 |
| 그날 배운 것 복습 | **`강의/`** 날짜 파일 |
| 한 주제 빠르게 훑기 | **`정리/`** (파이썬 문법, 리눅스 기초 …) |
| 개념 깊게 이해 | **`개념/<주제>/`** 페이지 |

## ✍️ 작성 규칙 (요약)

자세한 운영 규칙은 [`CLAUDE.md`](CLAUDE.md) 참고.

- 확실한 정보만 (할루시네이션 방지). 수업 내용과 보충(📌)을 구분
- 코딩·AI 비전공 초보자도 이해하게 쉽게 풀어쓰기
- 개념 페이지 양식: `정의 → 왜 필요한가 → 어떻게 작동하나 → 실제 예시 → 자주 헷갈리는 것 → 더 알면 좋은 것 → 관련 개념`
- `raw/` 원본 자료는 수정하지 않음

```bash
git push
```
