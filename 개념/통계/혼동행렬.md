# 혼동행렬 (Confusion Matrix)

**정의**: 이진 분류 결과를 **실제 × 예측** 2×2 표로 집계한 것. 네 칸(TP·TN·FP·FN)이 [[정밀도]]·[[재현율]]·[[정확도]]·[[F1점수]] 모든 지표의 재료가 된다.

---

## 왜 필요한가

정확도 하나만 보면 불균형 데이터(예: 생존자가 드문 경우)에서 착각한다. "어떤 종류의 오류를 얼마나 내는지"(놓친 건지 잘못 잡은 건지)를 봐야 하고, 그걸 한눈에 보여주는 게 혼동행렬이다.

---

## 어떻게 작동하나

```
              Predicted 0    Predicted 1
Actual 0        TN            FP        (실제 사망)
Actual 1        FN            TP        (실제 생존)
```

```python
# titanic 실습: sklearn 없이 NumPy 불리언 마스크로 수동 카운트
TP = np.sum((y_pred == 1) & (y_test == 1))   # 생존을 생존으로 맞춤
TN = np.sum((y_pred == 0) & (y_test == 0))   # 사망을 사망으로 맞춤
FP = np.sum((y_pred == 1) & (y_test == 0))   # 사망을 생존으로 오판(거짓양성)
FN = np.sum((y_pred == 0) & (y_test == 1))   # 생존을 놓침(거짓음성)
```

- **TP** True Positive / **TN** True Negative / **FP** False Positive(거짓 양성) / **FN** False Negative(거짓 음성).
- 앞글자 T/F = 맞췄나, 뒷글자 P/N = 뭐라고 예측했나.

---

## 자주 헷갈리는 것

**FP와 FN을 헷갈리기 쉽다.** FP는 "아닌데 맞다고 함"(거짓 경보), FN은 "맞는데 놓침"(누락). 의료 진단이면 FN(암을 놓침)이 더 치명적, 스팸 필터면 FP(정상 메일을 스팸 처리)가 더 성가심 — **상황마다 어느 오류가 더 나쁜지 다르다.**

---

## 더 알면 좋은 것

📌 titanic 실습은 `sklearn.metrics.confusion_matrix`를 쓰지 않고 불리언 마스크 `&`로 네 칸을 손계산한다. 원리를 드러내려는 의도. ⚠ 노션 원문엔 실행 결과 수치(각 칸 값)가 없어 실제 TP/TN/FP/FN 값은 미확보. 정의·계산 구조만 확인됨.

## 관련 개념

- [[F1점수]] — 정밀도·재현율의 조화평균
- [[정확도]] — (TP+TN)/전체
