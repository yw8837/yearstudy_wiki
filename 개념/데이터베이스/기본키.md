# 기본키 (PRIMARY KEY)

**정의**: 테이블에서 각 **행을 고유하게 식별**하는 컬럼. 테이블 생성 시 지정한다.

---

## 왜 필요한가

같은 행을 정확히 가리키고(수정·삭제 대상 지정), 테이블끼리 [[JOIN]]으로 연결하려면 "행을 구분하는 기준"이 필요하다. 그게 기본키다.

---

## 어떻게 작동하나

```sql
CREATE TABLE book (
    id INTEGER PRIMARY KEY,   -- 기본키
    title TEXT,
    price REAL
);
```

- 기본키 값은 **중복 불가·NULL 불가**(각 행을 유일하게 구분).
- 다른 테이블에서 이 키를 참조하면 **외래키(Foreign Key)** 가 된다.

---

## 실제 예시

- chinook: `albums.AlbumId`(PK)를 `tracks.AlbumId`(FK)가 참조 → JOIN 연결.

---

## 자주 헷갈리는 것

**기본키 vs 외래키**: 기본키는 "이 테이블의 식별자", 외래키는 "다른 테이블의 기본키를 가리키는 컬럼".

**컬럼명만으론 FK 의미 파악 어려움**: `Customer.SupportRepId` 같은 FK는 [[데이터정의서]]가 있으면 의미를 명확히 알 수 있다.

---

## 더 알면 좋은 것

📌 `INTEGER PRIMARY KEY`는 SQLite에서 자동 증가(rowid) 역할도 한다.
