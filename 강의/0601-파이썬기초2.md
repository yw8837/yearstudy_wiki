## 01. 문자열/리스트 추가 메서드

```python
my_list = [2, 3, 5, 7, 11]
my_list.pop(0)      # 2  반환 후 삭제 (인덱스 지정)
my_list.pop()       # 11 반환 후 삭제 (마지막)
# [3, 5, 7] 남음

my_list.count(2)              # 특정 값 등장 횟수
"elice and alice".count("e")  # 3

# split: 문자열 → 리스트
"1 2 3".split()         # ['1', '2', '3']  (괄호 비우면 공백 기준)
"Na,Mg,Al".split(",")   # ['Na', 'Mg', 'Al']

# join: 리스트 → 문자열  (구분자.join(리스트) 순서 주의!)
"".join(["e","l","i","c","e"])     # "elice"
"→".join(["서울","대전","대구"])    # "서울→대전→대구"
```

> split ↔ join은 한 쌍. "쪼개서 가공 → 다시 합치기"는 데이터 처리의 기본 흐름.

## 02. 튜플 (Tuple)

```python
t = (1, 2, 3)           # 소괄호로 생성
t_one = (1,)            # 원소 1개: 반드시 쉼표 필요 ( (1)은 그냥 정수 )

# 리스트처럼: 인덱싱, 슬라이싱, in, len, +, * 가능
t[1]        # 2
t[:2]       # (1, 2)
2 in t      # True

# 다른 점: 값 변경 불가 (불변)
t[0] = 99   # TypeError!
```

**쓰는 경우**: 바뀌면 안 되는 데이터(좌표·날짜), 딕셔너리 Key, 함수에서 여러 값 반환.

## 03. 딕셔너리 (Dictionary)

```python
person = {"name": "Rabbit", "age": 22}

person["name"]      # "Rabbit"   (접근)
person["mail"] = "rabbit@elice.com"  # 추가
person["age"] = 23  # 수정 (추가와 문법 동일)
del person["age"]   # 삭제

person.keys()       # dict_keys([...])
person.values()     # dict_values([...])
person.items()      # dict_items([(k, v), ...])
```

**Key 규칙**: 불변 자료형만 가능. str, int, tuple → OK / list → ❌ TypeError

**for문과 조합**:
```python
for key, value in my_dict.items():        # 권장 (Pythonic)
    print(f"{key}: {value}")

for key, value in zip(my_dict.keys(), my_dict.values()):  # 동일 결과
    print(f"{key}: {value}")
```

## 04. 반복문

### for 문
```python
for fruit in ["사과", "바나나"]:
    print(fruit)
```

### for-range 문 (끝 숫자 미포함)
```python
range(5)        # 0~4
range(1, 6)     # 1~5
range(0, 10, 2) # 0,2,4,6,8

for i in range(len(my_list)):   # range + len + 인덱싱
    print(my_list[idx])
```

### while 문
```python
i = 5
while i > 0:
    print(i)
    i -= 1      # 조건이 False가 되도록 반드시 변화를 줘야 함
```
> ⚠️ 조건이 항상 True → 무한루프. `break`로 탈출.

### break 문
```python
while True:
    guess = int(input("숫자: "))
    if guess == 42:
        break
```

> for → 횟수·범위가 정해진 경우 / while → 조건이 있는 경우.

## 05. 함수와 메서드

### 내장 함수
```python
len([1,2,3])     # 3
sum([1,2,3])     # 6
max([1,2,3])     # 3
min([1,2,3])     # 1
```

### 사용자 정의 함수
```python
def plus_double(a, b):      # def 이름(매개변수):
    c = a + b
    return 2 * c            # return으로 값 돌려주기

plus_double(3, 4)          # 14
```
> `return` 없으면 결과는 `None`. 외부에서 값을 쓰려면 반드시 `return`.

### 전역 변수 vs 지역 변수
```python
x = "전역"          # 어디서든 접근

def f():
    y = "지역"      # 함수 안에서만 존재
    print(x)        # 전역변수 읽기 OK

f()
print(y)            # NameError! — 함수 밖엔 y 없음
```

### 함수 vs 메서드
- **함수**: `len(my_list)` — 독립적, 괄호 안에 대상
- **메서드**: `my_list.append(4)` — 자료형에 딸림, 점(`.`)으로 호출

## 수업 포인트

- `split()` / `join()`은 문자열 처리의 핵심 콤보 — 데이터 분석에서 자주 씀
- 딕셔너리 `items()`로 for문 돌리는 패턴이 가장 많음 (`zip`보다 간결)
- `while True: ... break` 패턴 — 사용자 입력 받을 때 단골
- `return` 없는 함수는 결과가 `None` — 함정 조심
- 종합 실습으로 **FizzBuzz / 소수 판별 / 회문 판별 / 단어 빈도 / 성적 분석**을 직접 구현 → 자료형+반복문+함수의 결합

## 보충

📌 **`zip()`**: 두 리스트를 병렬로 묶어 튜플 쌍 반환. `dict(zip(keys, values))`로 딕셔너리 빠르게 생성.

📌 **`enumerate()`**: for문에서 인덱스+값 동시에. `for i, val in enumerate(list):`

📌 **`continue`**: `break`와 짝. 현재 반복만 건너뛰고 다음 반복으로.

📌 **타입 힌트(Type Hint)** *(수업에서 추가로 다룸)*: 매개변수·반환값의 자료형을 명시. 강제는 아니지만 가독성↑.
```python
def add(a: int, b: int) -> int:
    return a + b
```

📌 **독스트링(Docstring)** *(수업에서 추가로 다룸)*: 함수 첫 줄 `"""설명"""`. `help(함수명)`으로 조회, 라이브러리 공식 문서의 원천. → 출처: [Python 공식 문서 typing](https://docs.python.org/ko/3/library/typing.html)
