## 01. 컴퓨터의 이해

컴퓨터는 오직 **0과 1**만 이해한다. 이게 **기계어**다. TV 켜고 끄는 것도, 화면에 나오는 글자도 전부 0과 1의 조합이다.

직접 기계어를 쓰는 건 불가능에 가까워서 **프로그래밍 언어**가 생겼다. 개발자가 코드를 쓰면 번역기(인터프리터/컴파일러)가 기계어로 바꿔준다.

```
Code 작성 → 번역기(컴파일러/인터프리터) → 기계어 → 컴퓨터 실행
```

언어는 기계와의 거리에 따라 나뉜다:
- **Low-level** (C, Assembly): 기계에 가까움. 빠르지만 어려움
- **High-level** (Python, JavaScript): 사람에게 가까움. 배우기 쉬움

모든 앱·웹은 **클라이언트(프론트엔드) ↔ 서버(백엔드)** 구조로 동작한다. 배달앱 화면 = 클라이언트, 주문 처리 = 서버.

## 02. 앱/웹 서비스의 뼈대

### HTTP

웹 통신의 공통 규약. 기기·OS·브라우저에 상관없이 같은 방식으로 대화한다. 기본 원칙: **1요청 → 1응답**.

| 메서드 | 역할 | 예시 |
|:---|:---|:---|
| GET | 데이터 가져오기 | 피드 불러오기 |
| POST | 데이터 보내기 | 댓글 달기, 주문 |
| PUT/PATCH | 수정 | 프로필 변경 |
| DELETE | 삭제 | 게시글 삭제 |

주고받는 데이터 형식: **JSON** (`{"id": 1, "name": "홍길동"}`) 이 현재 표준.

### 동기 vs 비동기

- **동기**: 요청하고 → 응답 올 때까지 기다림
- **비동기**: 요청하고 → 기다리지 않고 다음 작업 → 응답 오면 그때 처리

카카오톡에서 메시지 보내면서 다른 채팅방도 볼 수 있는 게 비동기 덕분이다.

## 03. 데이터베이스와 API

### 데이터베이스 (DB)

데이터를 엑셀 표처럼 **행(Row)과 열(Column)** 구조로 저장하는 시스템. 은행 입출금 기록, 쇼핑몰 재고, 도서관 도서 목록 모두 DB로 관리한다.

모든 DB의 핵심 기능 = **CRUD**:
- **C**reate (저장) → HTTP POST
- **R**ead (검색) → HTTP GET
- **U**pdate (수정) → HTTP PUT/PATCH
- **D**elete (삭제) → HTTP DELETE

| 종류 | 예시 | 특징 |
|:---|:---|:---|
| 관계형 DB | MySQL, PostgreSQL | 표 형태, 정형 데이터 |
| 비관계형 DB (NoSQL) | MongoDB, Redis | 유연한 구조, 대용량 |

### API

프로그램끼리 소통하는 창구. **손님(앱) → 웨이터(API) → 주방(서버/DB)** 구조.

```
로그인 API 예시
주소: shoppingmall.com/login
방식: POST로 아이디/비밀번호 전송
처리: DB에서 확인 → 성공/실패 응답
```

## 04. 라이브러리 vs 프레임워크

웹은 **HTML(뼈대) + CSS(피부) + JavaScript(근육)** 로 구성된다.

| 구분 | 비유 | 특징 |
|:---|:---|:---|
| **라이브러리** | 공구 세트 | 필요할 때 꺼내 씀. 내가 주도권 |
| **프레임워크** | 건물 골조 | 구조가 정해져 있고 그 안에서 개발 |

주요 프레임워크:

| 분야 | 예시 |
|:---|:---|
| Front-end | React, Vue |
| Back-end (Python) | Django, FastAPI, Flask |
| 모바일 | Flutter, React Native |

## 05. SEO와 크롤링

**SEO(검색엔진 최적화)**: 돈 안 쓰고 검색 상위에 노출되게 하는 작업.

- **크롤링**: 검색엔진 봇(Googlebot)이 웹을 돌아다니며 페이지 수집
- **색인(Indexing)**: 수집한 페이지를 분석해 DB에 저장
- **파싱**: 수집한 HTML에서 필요한 정보만 뽑아내는 것

크롤링은 AI 훈련 데이터 수집에도 핵심적으로 쓰인다. GPT가 인터넷 텍스트로 학습한 것 = 크롤링으로 모은 데이터.

## 06. 현업 용어

**Git**: 코드 변경 이력을 관리하는 버전 관리 시스템. "언제든 원하는 시점으로 되돌아갈 수 있는 타임머신". GitHub·Bitbucket이 대표 서비스.

**클라우드**: 실물 서버 없이 인터넷으로 서버를 빌려 쓰는 방식. 트래픽 늘면 클릭 몇 번으로 증설, 줄면 축소. 사용한 만큼만 비용. AWS·GCP·Azure가 3대장.

**SaaS(Software as a Service)**: 설치 없이 인터넷으로 바로 쓰는 소프트웨어. Notion, Figma, Slack, Zoom. Adobe가 Figma를 28조 원에 인수.

**오픈소스**: 코드가 공개되어 누구나 쓸 수 있는 소프트웨어. 무료지만 라이선스 준수 필수.

## 07. AI / 머신러닝 / 딥러닝 / LLM

세 개념의 포함 관계:
```
AI (인공지능)
└── 머신러닝 (데이터로 스스로 학습)
     └── 딥러닝 (뇌 신경망 모방)
          └── LLM (수천억 문장 학습한 언어 모델)
```

- **AI**: 스팸 필터, 넷플릭스 추천, 얼굴 인식, 길찾기 모두 AI
- **머신러닝**: 데이터 많이 줄수록 스스로 패턴 학습 → 더 똑똑해짐
- **딥러닝**: 뇌 신경망 구조 모방. 이미지 인식·음성 인식·LLM 기반
- **LLM**: 인터넷 수천억 문장 학습. ChatGPT·Claude가 여기에 해당

생성형 AI: 분류·예측을 넘어 새로운 콘텐츠를 직접 만들어냄. 텍스트(ChatGPT·Claude), 이미지(Midjourney), 코드(Copilot).

## 보충

📌 **High-level ≠ 고급**: 수업에서 "고차원 언어"처럼 표현했는데, 정확히는 "기계에서 멀고 사람에게 가까운 언어". 파이썬이 C보다 더 대단한 게 아니라 더 추상화된 것.
