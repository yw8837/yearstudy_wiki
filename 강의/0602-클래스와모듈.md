# 06/02 · 클래스(OOP) · 모듈과 패키지

객체지향(클래스)으로 "팀원·부서가 있는 IT 회사"를 만들고, 코드를 모듈·패키지로 나눠 `import`하는 법. 한 줄 요약: **데이터+행동을 클래스로 묶고(캡슐화) → 물려받고(상속) → 같은 명령에 다르게 반응(다형성), 그리고 코드를 파일·폴더로 나눠 가져다 쓰기(모듈·패키지).**

---

## 01. 클래스 = 설계도, 인스턴스 = 객체

**클래스**는 물건을 찍어내는 **설계도(붕어빵 틀)**, 그 틀로 만든 실제 물건 하나하나가 **인스턴스(객체)**.

| 구분 | 의미 | 예 |
|:---|:---|:---|
| 클래스 | 설계도 (틀) | `TeamMember` |
| 인스턴스 | 설계도로 만든 실제 객체 | `alice = TeamMember(...)` |
| 속성 | 객체가 가진 **데이터** | 이름·직책·연봉 |
| 메서드 | 객체가 하는 **행동** | 자기소개·연봉협상 |

```python
class TeamMember:        # 이름 첫 글자 대문자(관례)
    pass

a = TeamMember()
b = TeamMember()
print(a is b)            # False — 서로 다른 객체
```

## 02. `__init__` 와 `self`

`__init__` = 객체가 **생성되는 순간 자동 실행**되는 생성자. `self` = **"이 객체 자신"**.

```python
class TeamMember:
    def __init__(self, name, role, salary):
        self.name = name        # self.속성 = 값 → 이 객체에 저장
        self.role = role
        self.salary = salary

alice = TeamMember("Alice", "시니어 개발자", 6000)
print(alice.name, alice.salary)   # 객체.속성 으로 꺼냄
```

---

## 03. 메서드 — 객체의 행동

클래스 안에 정의한 함수. 첫 인자는 항상 `self`(호출 시 자동 전달).

```python
class TeamMember:
    def __init__(self, name, salary):
        self.name, self.salary = name, salary
    def introduce(self):
        print(f"{self.name}입니다.")
    def negotiate(self, amount):
        self.salary += amount

alice = TeamMember("Alice", 3000)
alice.introduce()        # self = alice 자동
alice.negotiate(2000)    # salary → 5000
```

## 04. 클래스 변수 vs 인스턴스 변수

| 구분 | 값 | 위치 |
|:---|:---|:---|
| **인스턴스 변수** | 객체마다 **다름** (이름·연봉) | `__init__` 안 `self.x` |
| **클래스 변수** | 모든 객체가 **공유** (회사명·카운터) | 클래스 안, `__init__` 밖 |

```python
class TeamMember:
    company = "이어드림"        # 클래스 변수 (공유)
    total = 0
    def __init__(self, name):
        self.name = name        # 인스턴스 변수
        TeamMember.total += 1   # 새 객체마다 +1

TeamMember("A"); TeamMember("B")
print(TeamMember.total)         # 2
```

## 05. 매직(던더) 메서드 — `__이름__`

앞뒤 밑줄 2개. 파이썬이 **특정 순간 자동 호출**.

| 메서드 | 자동 호출 시점 |
|:---|:---|
| `__init__` | 객체 생성 |
| `__str__` | `print()` — 사람이 읽기 좋게 |
| `__repr__` | 디버깅·콘솔 표현 |
| `__len__` | `len()` |
| `__eq__` | `==` 비교 |

```python
class TeamMember:
    def __init__(self, name): self.name = name
    def __str__(self): return f"팀원 {self.name}"

print(TeamMember("Alice"))   # 팀원 Alice  (없으면 <...object at 0x..>)
```

## 06. classmethod vs staticmethod

| 종류 | 데코레이터 | 첫 인자 | 쓰임 |
|:---|:---|:---|:---|
| 인스턴스 메서드 | 없음 | `self` | 객체 데이터 사용 |
| **클래스 메서드** | `@classmethod` | `cls` | 클래스 변수·대체 생성자 |
| **정적 메서드** | `@staticmethod` | 없음 | 클래스 관련 독립 기능 |

```python
class TeamMember:
    total = 0
    @classmethod
    def get_total(cls): return cls.total      # cls = 클래스 자신
    @staticmethod
    def valid_salary(s): return 1000 <= s <= 10000   # self·cls 없음
```

> `@`는 **데코레이터** — 함수에 기능을 "표시/포장"하는 장치. → [[함수]]

## 07. 상속 (Inheritance)

부모 클래스의 속성·메서드를 **물려받아** 자식 클래스를 만듦. 공통은 부모에, 차이만 자식에.

```python
class Department:                  # 부모: 공통
    def __init__(self, team):
        self.team = team
        self.members = []

class DevTeam(Department):         # 자식: 상속
    def __init__(self, stack):
        super().__init__("개발팀")    # 부모 __init__ 호출
        self.stack = stack          # 자식만의 속성

dev = DevTeam(["Python"])
print(dev.team)                    # 개발팀 (물려받음)
```

> `super()` = 부모 클래스. `super().__init__(...)`로 부모 초기화 그대로 실행.

## 08. 오버라이딩 · 다형성

- **오버라이딩**: 부모 메서드를 자식이 **자기 방식으로 다시 정의**
- **다형성**: **같은 메서드 호출**인데 객체마다 **다르게 동작**

```python
class Department:
    def meeting(self): print("회의")
class DevTeam(Department):
    def meeting(self): print("개발팀: 스프린트 회의")
class SalesTeam(Department):
    def meeting(self): print("영업팀: 매출 회의")

for t in [DevTeam(), SalesTeam()]:   # 같은 호출, 다른 결과
    t.meeting()
```

## 09. 모듈 — `import` 4가지

**모듈 = 파이썬 코드가 담긴 `.py` 파일.** 잘 만든 코드를 `import`로 가져다 씀.

| 방법 | 코드 | 사용 |
|:---|:---|:---|
| 통째로 | `import math` | `math.sqrt(9)` |
| 별칭 | `import random as rd` | `rd.choice(...)` |
| 콕 집어 | `from math import sqrt, pi` | `sqrt(9)` |
| 전부(`*`) | `from math import *` | 비권장 (이름 충돌) |

```python
import math
print(math.pi, math.sqrt(16))     # 3.141.. 4.0
```

## 10. 패키지 — 모듈을 폴더로 묶기

모듈(`.py`)이 많아지면 폴더로 분류. 그 폴더가 **패키지**. 점(`.`)으로 경로를 따라감.

```
project/
├── script/main.py
└── sound/
    ├── audio.py
    └── play.py
```

```python
import sound.audio               # sound 폴더의 audio 모듈
from sound.play import start      # sound/play.py 의 start
```

> 정리: **모듈 = 파일(.py)**, **패키지 = 모듈 담은 폴더**.

## 보충

📌 **`if __name__ == "__main__":`** — 모듈을 **직접 실행할 때만** 동작, `import`되면 안 돌아감. 모듈 안 테스트 코드용. (실무문법에서 다시 등장 → [[0604-실무문법패턴]])

📌 **isinstance() / issubclass()** *(예습 — 수업 미진행, 배운 뒤 보강)*: 객체 타입·상속 관계 확인. `isinstance(dev, Department)` → True(부모 타입도 True), `issubclass(DevTeam, Department)` → True.

📌 **캡슐화 — `_`, `__` 관례**: `_name`="직접 쓰지 마세요"(약속), `__name`=이름 맹글링(name mangling)으로 외부 접근 차단. 파이썬은 강제 private 없이 **관례**로 표현.

📌 **표준 모듈 ≠ 외부 패키지**: 표준 라이브러리(math·random)는 설치 없이 `import`, 외부(numpy·pandas)는 `pip`/`uv`로 설치 후 사용. → [[0604-라이브러리활용]]
