# 집계 함수 (Aggregate Function)

**정의**: 여러 행의 값을 하나로 **요약**하는 내장함수 — COUNT / SUM / AVG / MAX / MIN.

---

## 왜 필요한가

"몇 개인가", "합계·평균은", "최대·최소는" 같은 통계를 한 번에 구하려면 집계함수가 필요하다. [[GROUP BY]]와 합치면 그룹별 통계가 된다.

---

## 어떻게 작동하나

| 함수 | 역할 | 비고 |
|:---|:---|:---|
| `COUNT` | 개수 | **NULL 제외.** `COUNT(*)`(행) vs `COUNT(컬럼)`(NULL 제외) |
| `SUM` | 합계 | 숫자 컬럼 총합 |
| `AVG` | 평균 | SUM/COUNT 안 써도 평균 |
| `MAX` / `MIN` | 최대 / 최소 | **숫자·문자 모두 가능** |

```sql
SELECT COUNT(*) FROM book;      -- 전체 행 수
SELECT COUNT(id) FROM book;     -- id 값 개수(NULL 제외)
SELECT AVG(korean), AVG(math) FROM grade;
SELECT MAX(korean), MIN(english) FROM grade;
```

---

## 실제 예시

- 국가별 매출 합계: `SELECT BillingCountry, SUM(Total) FROM invoices GROUP BY BillingCountry;`

---

## 자주 헷갈리는 것

**COUNT는 NULL 제외**: 전체 10행 중 컬럼에 NULL 3개면 `COUNT(컬럼)`은 7. 전체 행은 `COUNT(*)`.

**집계 vs 일반 컬럼**: 집계함수와 일반 컬럼을 함께 SELECT하면 보통 [[GROUP BY]]가 필요하다.
