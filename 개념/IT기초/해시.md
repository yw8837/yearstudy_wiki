# 해시 (Hash)

**정의**: 임의 길이의 데이터를 고정 길이의 문자열로 변환하는 단방향 함수. 원본으로 되돌릴 수 없다.

---

## 왜 필요한가

비밀번호를 DB에 그대로 저장하면 DB가 털렸을 때 전부 노출된다. 해시는 이 문제를 해결한다 — 원본 대신 해시값만 저장하면, 해킹당해도 공격자는 해시값만 얻고 원본은 알 수 없다.

파일 전송에서도 쓴다. 파일을 받기 전후 해시값이 같으면 전송 중 변조가 없었다는 증거다.

---

## 어떻게 작동하나

같은 알고리즘으로 같은 입력이면 항상 같은 출력이 나온다.

```
"hello"        → SHA-256 → 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
"hello!"       → SHA-256 → ce06092fb948d9af4d43b9bc0f234f952ea81e3a9f6b3e65fd75f20a54f43b3f
"Hello"        → SHA-256 → 185f8db32921bd5b2de07b14f89cb7fe485eb6d2b8c1e8a6f25f5e24f0c25d7
```

입력 한 글자만 달라도 결과가 완전히 달라진다 → **입력이 조금만 달라도 결과가 완전히 달라진다 (눈사태 효과)**.

**핵심 특성 4가지**:
- **단방향**: 해시값 → 원본 복원 불가
- **고정 길이**: 입력 크기와 무관하게 출력 길이 항상 동일
- **항상 같은 결과**: 같은 입력이면 항상 같은 출력
- **눈사태 효과**: 입력 한 글자만 달라도 출력이 완전히 달라짐

### 알고리즘 비교

| 알고리즘 | 출력 길이 | 상태 | 현재 용도 |
|:---|:---:|:---:|:---|
| MD5 | 128 bit | ❌ 깨짐 | 파일 체크섬 정도만 (보안 불가) |
| SHA-1 | 160 bit | ❌ 깨짐 (2017) | 레거시 시스템만 |
| **SHA-256** | 256 bit | ✅ 안전 | **현재 표준** — 비밀번호·인증서 |
| SHA-512 | 512 bit | ✅ 안전 | 고보안 요구 환경 |

## 실제 예시

**비밀번호 저장**:
```
사용자 가입: 비밀번호 "1234" 입력
DB에 저장:  { password_hash: "03ac674216..." }  ← 원본 아닌 해시값

로그인 시:  입력한 "1234"를 해시 → DB 해시값과 비교
            일치하면 로그인 성공 (서버도 원본 비밀번호를 모름)
```

**파일 무결성 검증**:
```
공식 다운로드 페이지: SHA-256: a3f5b2c1...
내가 받은 파일의 SHA-256: a3f5b2c1...  → 동일 → 변조 없음
```

---

## 자주 헷갈리는 것

**"해시 = 암호화"**: 다르다. 암호화는 키를 알면 복호화 가능. 해시는 복호화 자체가 불가능하다. 패스워드 저장에 해시를 쓰는 이유가 바로 이것 — 서버도 원본을 알 필요가 없다.

**"MD5 아직 써도 됨"**: 보안 용도엔 절대 안 된다. 이미 2004년에 충돌(서로 다른 입력이 같은 해시를 만드는 것)이 발견됐다. 파일 체크섬처럼 보안과 무관한 용도에만 쓴다.

**"SHA-256이면 충분히 안전하다"**: 단순 SHA-256으로 비밀번호를 해시하면 **레인보우 테이블 공격**에 취약하다. 자주 쓰는 비밀번호("1234", "password")의 해시값을 미리 계산해놓고 비교하는 방식이다.

---

## 더 알면 좋은 것

📌 **솔트(Salt)**: 레인보우 테이블 방어법. 비밀번호에 랜덤 문자열(솔트)을 붙여서 해시한다.
```
비밀번호: "1234"
솔트:     "x7k2m"
해시 대상: "1234x7k2m" → SHA-256 → db924...
```
같은 비밀번호라도 솔트가 다르면 해시값이 달라진다.

📌 **bcrypt / scrypt / Argon2**: 실무에서 비밀번호 해시에 쓰는 알고리즘. 단순 SHA-256보다 의도적으로 느리게 설계되어 무차별 대입 공격을 어렵게 만든다.

📌 **블록체인**: Bitcoin, Ethereum 모두 SHA-256 사용. 블록의 해시가 이전 블록을 참조하는 구조라 하나를 수정하면 이후 모든 블록을 다시 계산해야 한다 → 변조 사실상 불가능.
