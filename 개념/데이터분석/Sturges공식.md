# Sturges 공식

**정의**: 도수분포표/히스토그램의 **적절한 계급 수**를 정하는 경험식. $k = 1 + \log_2 n$ (n=관측값 개수). 결과를 올림/반올림해 계급 수로 쓴다.

---

## 왜 필요한가

계급 수를 너무 적게 잡으면 분포가 뭉개지고, 너무 많으면 들쭉날쭉해진다. Sturges 공식은 **데이터 크기에 맞는 합리적 출발점**을 준다.

---

## 어떻게 작동하나

```python
import numpy as np
n = 244
k = int(np.ceil(1 + np.log2(n)))   # 8.9 → 올림 → 9
# 계급폭 = (max - min) / k
```

- tips total_bill(n=244): $k=1+\log_2 244 \approx 8.9$ → 계급 9개, 범위 47.74 → 계급폭 6.0.

---

## 자주 헷갈리는 것

**절대 규칙이 아니라 출발점이다.** 데이터가 매우 크거나 분포가 치우치면 Sturges가 부적절할 수 있다(다른 규칙: Scott, Freedman-Diaconis). 결국 분포를 보며 bins를 조정한다.

---

## 더 알면 좋은 것

📌 [[히스토그램]]은 bins(계급 수)에 민감하므로 Sturges로 시작해 시각적으로 조정하는 게 실무. matplotlib `plt.hist(x, bins='sturges')`로도 지정 가능.
