# 생성형 AI (Generative AI)

**정의**: 학습한 데이터의 패턴을 바탕으로 텍스트·이미지·오디오·비디오 등 **새로운 콘텐츠를 생성**하는 AI.

---

## 왜 필요한가

기존 AI는 주어진 입력을 **분류·예측·탐지**하는 데 머물렀다(→ [[판별형AI]]). 생성형 AI는 한 발 더 나아가 결과물 자체를 만들어낸다. 글을 쓰고, 그림을 그리고, 영상을 제작한다. 이 "생성" 능력이 업무·창작·개발의 도구를 통째로 바꾸고 있다.

생성형 AI 부상의 3축:

| 축 | 키워드 | 의미 |
|:---|:---|:---|
| 데이터 | IoT 등 | 폭증한 디지털 데이터 |
| 컴퓨팅 | GPU | 대규모 병렬 연산 발전 |
| 모델 | LLM | 모델 구조·규모 발전 |

---

## 어떻게 작동하나

생성 유형별로 기반 기술이 다르다.

| 유형 | 기반 기술 | 대표 |
|:---|:---|:---|
| 텍스트 | [[LLM]] (Auto-regression) | GPT, Claude, Gemini |
| 이미지 | [[Diffusion모델]] | Nano Banana Pro |
| 비디오 | (영상 생성 모델) | Sora / Sora2 |
| 오디오 | (음성 생성 모델) | Fish Audio |

여러 모달을 한 모델에서 다루면 [[멀티모달AI]]가 된다.

### 모델 활용 3가지 방식

```
① 웹 서비스  : ChatGPT/Claude/Gemini  (설치 없이 바로)
② API 호출   : OpenAI/Anthropic/Google (코드로 통합)
③ 오픈웨이트 : Llama/DeepSeek/Gemma   (내 GPU에 직접) → [[오픈웨이트모델]]
```

---

## 실제 예시

- **글쓰기·요약·번역·코딩**: ChatGPT, Claude
- **이미지 생성**: Gemini 3 Pro Image(Nano Banana Pro)
- **영상 제작**: Sora
- **음성 합성**: Fish Audio

---

## 자주 헷갈리는 것

**"생성형 = 더 똑똑한 AI"**: 똑똑함의 문제가 아니라 **목적**이 다르다. 분류가 목적이면 [[판별형AI]], 생성이 목적이면 생성형이다.

**"생성형은 진짜를 안다"**: 아니다. 학습 데이터의 패턴으로 "그럴듯한" 결과를 만들 뿐, 사실 여부를 보장하지 않는다 → [[Hallucination]].

## 더 알면 좋은 것

📌 **모델 vs 서비스**: ChatGPT(서비스)와 GPT(모델)는 다르다. 서비스는 모델을 감싼 제품.

📌 **이름보다 원리**: 모델명은 빨리 낡는다. Auto-regression·Diffusion·멀티모달 같은 원리를 기억하는 게 오래 간다.
