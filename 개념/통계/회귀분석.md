# 회귀분석 (Regression Analysis)

**정의**: 하나의 연속형 종속변수 Y를 여러 독립변수로 예측·설명하는 모형. `H₀: 회귀계수(기울기)=0`.

---

## 왜 필요한가

"어떤 변수가 Y에 영향을 주는가, 얼마나 설명하는가"를 정량화한다. 예측과 변수 중요도 파악에 쓴다.

---

## 어떻게 작동하나

```python
import statsmodels.formula.api as smf
model = smf.ols("y ~ x1 + x2 + C(cat)", data=df).fit()
model.rsquared        # R² (설명력 0~1)
model.rsquared_adj    # 조정 R² (변수 수 페널티)
model.pvalues         # 변수별 유의성 (<0.05 = 유의변수)
model.params          # 회귀계수
```

- R² = Y 변동을 모형이 설명하는 비율. 유의변수 = `p<0.05`인 계수.

---

## 자주 헷갈리는 것

**회귀 진단 4가정은 잔차로 검증.** 선형성·독립성(Durbin-Watson)·등분산성·정규성([[정규성검정|Shapiro]]·Q-Q) — 모두 잔차(Residual = 실제-예측)로 확인한다.
