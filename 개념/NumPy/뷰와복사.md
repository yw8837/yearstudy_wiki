# 뷰 vs 복사 (View vs Copy)

**정의**: [[NumPy]]에서 배열 일부를 가져올 때 **원본과 메모리를 공유하면 뷰(view)**, **독립 데이터를 새로 만들면 복사(copy)**.

---

## 왜 필요한가

🔑 **강사가 강조한 함정.** 슬라이스(뷰)를 수정하면 **원본도 바뀐다**. 이를 모르면 의도치 않게 원본 데이터를 망가뜨린다. 파이썬 [[리스트]] 슬라이스가 복사인 것과 정반대라 특히 주의.

---

## 어떻게 작동하나

```python
import numpy as np
a = np.array([10, 2, 3, 4, 5, 6])

b = a[3:]      # 슬라이스 → 뷰 (같은 버퍼를 offset/stride로 참조)
b[0] = 40
print(a)       # [10  2  3 40  5  6]   ← 원본도 변경!

c = a[3:].copy()   # 독립 복사본
c[0] = 99
print(a)       # 변하지 않음
```

```
뷰:  a ─┐
        ├─▶ 같은 메모리 버퍼  (수정 전파)
     b ─┘
복사: a ─▶ [버퍼1]    c ─▶ [버퍼2]   (독립)
```

---

## 실제 예시

- 열 슬라이스 `X[:, :2]`도 뷰일 수 있어, 수정할 거면 `.copy()`를 붙인다.

---

## 자주 헷갈리는 것

🔑 **정정(공식 기준):** ipynb 주석 "뷰인 경우가 많음"은 완곡. NumPy 공식상 **기본 인덱싱(슬라이싱) = 항상 뷰**, **고급 인덱싱([[불리언인덱싱|불리언]]·정수배열) = 항상 복사**. 즉 `a[3:]`=뷰, `a[a>0]`·`a[[1,2]]`=복사.

**flatten vs ravel:** `flatten()`=항상 복사, `ravel()`=가능하면 뷰.
