# 포트 (Port)

**정의**: 한 컴퓨터(IP) 안에서 여러 프로그램의 통신을 구분하는 번호. IP가 "건물 주소"라면 포트는 "호실 번호".

---

## 왜 필요한가

한 대의 컴퓨터에서 웹 서버, 데이터베이스, Jupyter 등 여러 프로그램이 동시에 네트워크 통신을 한다. IP 주소만으로는 "이 데이터가 어느 프로그램으로 가야 하는지" 구분할 수 없다. 포트 번호가 그 구분을 맡는다.

```
같은 컴퓨터(IP 127.0.0.1) 안에서
  :8888 → Jupyter Notebook
  :5432 → PostgreSQL
  :3000 → 개발 서버
```

---

## 어떻게 작동하나

### URL 속 포트

웹 주소는 사실 `프로토콜://IP(또는 도메인):포트/경로` 구조다.

```
http://localhost:8888/notebooks
              ↑      ↑
             IP     포트
```

`http`는 기본 포트 80, `https`는 443을 쓰기 때문에 **기본 포트는 보통 생략(숨김)** 된다. 그래서 평소엔 포트가 안 보인다.

### 자주 쓰는 기본 포트

| 포트 | 용도 |
|:---:|:---|
| 80 | HTTP |
| 443 | HTTPS |
| 22 | SSH |
| 8888 | Jupyter Notebook |
| 5432 | PostgreSQL |
| 3306 | MySQL |

### 포트 충돌 (Port Conflict)

하나의 포트는 **한 번에 한 프로그램만** 쓸 수 있다. 이미 사용 중인 포트를 다른 프로그램이 또 쓰려고 하면 충돌이 나서 실행이 안 된다.

- 예) Jupyter Notebook을 두 번 켜면, 두 번째는 8888이 이미 점유돼 있어 충돌.
- 일부 프로그램은 충돌 시 **다음 빈 포트(8889, 8890…)를 자동으로 잡아준다**.

---

## 실제 예시

```bash
# (참고) 특정 포트를 누가 쓰는지 확인
#   Windows: netstat -ano | findstr 8888
#   Linux/Mac: lsof -i :8888

# Jupyter를 다른 포트로 강제 실행
jupyter notebook --port 8889
```

수강 중 가장 흔히 만나는 상황: **"Jupyter가 안 켜져요"** → 8888 포트가 이미 점유된 경우가 많다. 포트를 바꾸거나 기존 프로세스를 종료하면 해결.

---

## 자주 헷갈리는 것

**"IP만 있으면 통신된다"**: 아니다. IP는 컴퓨터를 찾고, 포트는 그 안의 프로그램을 찾는다. 둘 다 있어야 통신이 성립한다.

**"포트 충돌 = 에러"**: 충돌 자체는 정상 동작이다. OS가 "이미 쓰는 중"이라고 알려주는 것일 뿐. 포트를 바꾸거나 점유 프로세스를 정리하면 된다.

---

## 더 알면 좋은 것

📌 **잘 알려진 포트(0~1023)**: HTTP·SSH 등 표준 서비스용으로 예약된 범위. 일반 앱은 보통 1024 이상을 쓴다.

📌 **`localhost` / `127.0.0.1`**: 내 컴퓨터 자신을 가리키는 주소. 개발할 때 `localhost:포트`로 내 PC에서 띄운 서버에 접속한다.

📌 **방화벽**: 외부에서 특정 포트로 들어오는 접속을 막거나 허용하는 보안 장치. 서버 운영 시 필요한 포트만 열어둔다.
