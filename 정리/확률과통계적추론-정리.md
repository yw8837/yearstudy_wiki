# 확률과 통계적 추론 정리

확률 기초부터 확률변수·확률분포, 표본→모집단 추론(추정)까지 한눈에. **가설검정 이론은 [[가설검정-정리]], 실전 검정 코드는 [[빅분기-작업형3유형-정리]]** 참조.

> 강의 출처: [[0622-확률과통계적추론]] · 상세: [[확률]] · [[확률변수]] · [[정규분포]] · [[중심극한정리]] · [[신뢰구간]]

---

## 1. 확률의 기초 → [[확률]]

- `P(A) = 사건 A 원소 수 / 표본공간 Ω 원소 수`, 값은 0~1.
- **공리:** 0≤P(A)≤1 / P(Ω)=1 / 배반사건 `P(∪Aᵢ)=ΣP(Aᵢ)`.
- **정리:** `P(Aᶜ)=1-P(A)` / `P(A∪B)=P(A)+P(B)-P(A∩B)`.
- **복원/비복원:** 꺼낸 것을 다시 넣는지. 비복원은 앞 시행이 뒤에 영향(→ [[초기하분포]]).

---

## 2. 조건부확률·독립 → [[조건부확률]] · [[사건의독립]]

```
P(A|B) = P(A∩B) / P(B)          # B가 주어졌을 때 A
독립 ⇔ P(A∩B) = P(A)·P(B) ⇔ P(A|B) = P(A)
```

- 조건부확률 = 다른 사건 정보를 반영한 확률(정보로 확률이 바뀜).
- 독립 = 한 사건이 다른 사건에 영향을 주지 않음.

## 4. 확률변수·확률분포 → [[확률변수]] · [[확률분포]]

- **확률변수 X:** 근원사건에 실수를 대응시킨 함수.
- **이산** → [[확률질량함수|PMF]] `f(x)`(`Σf=1`) / **연속** → [[확률밀도함수|PDF]] `f(x)`(`∫f=1`).
- **[[누적분포함수|CDF]]:** `F(x)=P(X≤x)` — 누적 확률.

---

## 5. 주요 확률분포 (scipy.stats) → [[정규분포]]

```python
from scipy import stats
stats.binom(n, p)        # 이항 B(n,p): 베르누이 n번 성공 수
stats.hypergeom(M,n,N)   # 초기하: 비복원 성공 수
stats.poisson(lam)       # 포아송 Poi(λ): 드문 사건 수 (n크고 p작으면 이항≈포아송)
stats.uniform(a, b)      # 균일 U(a,b)
stats.norm(mu, sigma)    # 정규 N(μ,σ²) — .pmf/.pdf/.cdf
# 표준화: Z = (X - μ) / σ  → 표준정규 N(0,1)
```

| 이산 | 연속 |
|:--|:--|
| 베르누이·[[이항분포]]·[[초기하분포]]·[[포아송분포]] | [[균일분포]]·[[정규분포]]·[[표준정규분포]] |

## 6. 모집단·표본·추론 → [[통계적추론]]

```
모집단(모수·미지) ──표집──▶ 표본 ──통계량──▶ 추론 ──▶ 모수
```

- **모수** = 모집단 값(미지) / **통계량** = 표본 값(모수 추정).
- **통계적 추론 = 모수추정 + [[가설검정]].** 표본→전체 추론이라 **오류 존재**(부정확도 명시).
- **[[중심극한정리|CLT]]:** 표본평균들의 분포는 **n≥30이면 정규분포**에 근사 → z·t검정의 근거.

---

## 7. 점추정·구간추정 → [[점추정과구간추정]] · [[신뢰구간]]

- **점추정:** 모수에 가까울 하나의 값(모평균 ← 표본평균 X̄).
- **구간추정:** `X̄ ± z_(α/2)·σ/√n` = [[신뢰구간]]. [[신뢰구간|신뢰수준]]=포함 확률(95% 등).
- 예) N(100,10²), n=15, x̄=105 → 95% CI `105 ± 1.96·10/√15 = (99.94, 110.06)`.
