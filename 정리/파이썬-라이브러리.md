# 파이썬 라이브러리 활용 정리

라이브러리 설치·사용·배포를 **섹션별로 한눈에**. 자세한 설명은 개념 페이지 링크에서.

> 강의 출처: [[0604-라이브러리활용]] · 상세: [[파이썬라이브러리]]

---

## 1. 라이브러리란 → [[파이썬라이브러리]]

| 구분 | 설명 | 예시 |
|:---|:---|:---|
| **표준 라이브러리** | 파이썬 기본 내장 (설치 불필요) | `math`·`random`·`json` |
| **외부 라이브러리** | 따로 설치해서 사용 | `numpy`·`pandas`·`requests` |

- **라이브러리** = 누군가 미리 만들어 둔 코드 묶음 (바퀴를 다시 발명하지 않기)
- 외부 라이브러리는 **PyPI**(창고)에 모여 있고 `pip`로 내려받음
- 포함 관계: 모듈(`.py`) ⊂ 패키지(폴더) ⊂ 라이브러리(배포 단위)

## 2. 설치 — pip

```bash
pip install pandas             # 설치 (우리 과정은 uv add)
pip install pandas==2.2.0      # 특정 버전
pip freeze > requirements.txt  # 현재 목록을 파일로
pip install -r requirements.txt  # 그 목록대로 일괄 설치
```

- `pip install 이름`으로 설치, `pip list`로 확인
- **`requirements.txt`** = 팀원이 똑같은 환경을 재현하는 의존성 목록

## 3. 사용 — import

```python
import pandas as pd            # 관례 별칭 (pd·np)
import numpy as np

df = pd.DataFrame({"점수": [95, 82]})
df["점수"].mean()              # 88.5
```

- 설치한 라이브러리는 `import 이름 as 별칭`으로 불러옴 (`pd`·`np`는 관례)
- 사용법이 막히면 **공식 문서** 보는 습관이 중요

## 4. 배포 — PyPI 공유

```bash
pip install build twine
python -m build        # dist/ 에 배포 파일 생성
twine upload dist/*    # PyPI 업로드 → 누구나 pip install
```

```toml
# pyproject.toml — 패키지 이름·버전·의존성
[project]
name = "my-package"
version = "0.1.0"
```

- 내가 만든 코드도 패키지로 만들어 올리면 누구나 `pip install` 가능
- 처음엔 **TestPyPI**에 먼저 올려 연습 권장 / 버전은 `major.minor.patch`
