# 정규화 (Normalization)

**정의**: [[이상현상]]을 제거하기 위해 데이터베이스를 **구조화(테이블 분해)**하는 과정. 데이터 간 **중복을 줄여 무결성↑·중복↓**.

---

## 왜 필요한가

중복 저장은 [[이상현상]](삽입/갱신/삭제 이상)을 부른다. 같은 사실이 여러 행에 흩어지면 일부만 바뀌어 불일치가 생긴다. 정규화는 **한 사실을 한 곳에만** 두도록 분해해 이 문제를 막는다.

---

## 어떻게 작동하나

[[함수종속]]을 기준으로 단계적으로 분해한다.

```
비정규화 → 1NF → 2NF → 3NF → BCNF → 4NF → 5NF
```

| 단계 | 제거 대상 |
|:---|:---|
| [[1NF]] | 다중값 → 원자값 |
| [[2NF]] | [[부분함수종속]] |
| [[3NF]] | [[이행함수종속]] |
| [[BCNF]] | 결정자이면서 후보키 아닌 것 |
| [[4NF]] | [[다치종속]] |
| [[5NF]] | [[조인종속]] |

---

## 실제 예시

- `student_course_all`(다중값·중복) → 1NF(원자값) → 2NF(학생/과목/수강 분리) → 3NF(학과·교수 독립) 으로 단계 분해 (실습 `normalization_compare`).

---

## 자주 헷갈리는 것

**정규화는 한 번에 그리는 게 아니다.** ERD를 한 번에 완성형으로 그리는 게 아니라 비정규화→1NF→2NF→3NF로 **지속적으로 분해·변경**해 나가는 과정이다(강사 강조).

**어디까지?** 실무는 보통 **3NF로 충분**(99%). 더 가면 [[BCNF]]/[[4NF]]/[[5NF]], 반대로 성능 위해 되돌리면 [[역정규화]].

---

## 더 알면 좋은 것

📌 이론 출처: 1NF·관계형 모델 = Codd(1970), 2NF·3NF = Codd(1971/72), 1~5NF 해설 = Kent(1983).
📌 정규화↔[[역정규화]]는 트레이드오프. 무결성(정규화) vs JOIN 성능(역정규화).
