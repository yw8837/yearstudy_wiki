# 포아송분포 (Poisson Distribution)

**정의**: 단위 시간·공간에서 **드물게** 나타나는 사건의 횟수 분포. 평균 λ회 발생. `X ~ Poi(λ)`, `P(X=x)=e^(-λ)λˣ/x!`.

---

## 왜 필요한가

"일정 시간 동안 몇 번"류 사건(톨게이트 통과 차량 수, 페이지당 오타 수, 시간당 불량품 수)을 모형화한다.

---

## 어떻게 작동하나

```python
from scipy import stats
import numpy as np
stat = stats.poisson(lam)     # lam = λ (평균 발생 횟수)
stat.pmf(x); stat.cdf(x)
np.random.poisson(lam, size)
```

- 모수는 λ 하나. 평균과 분산이 모두 λ로 같은 것이 특징.

---

## 자주 헷갈리는 것

**[[이항분포]]의 극한.** B(n,p)에서 n이 매우 크고 p가 매우 작으면 λ=np인 포아송으로 근사된다. "시행 횟수는 많지만 성공은 드문" 상황.

---

## 더 알면 좋은 것

📌 사건이 서로 독립이고 발생률이 일정하다는 가정(포아송 과정)이 전제. 이 가정이 깨지면(군집 발생) 부적합.
