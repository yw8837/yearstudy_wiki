# 컴프리헨션 (Comprehension)

**정의**: `for` 반복문으로 리스트·딕셔너리를 만드는 코드를 **한 줄로 압축**하는 문법.

---

## 왜 필요한가

"리스트를 만들어 for로 채우는" 3~4줄 패턴이 너무 잦다. 컴프리헨션은 이를 한 줄로 줄여 **읽기 쉽고 짧게** 만든다. 데이터 전처리·필터링에서 매일 쓴다.

---

## 어떻게 작동하나

```python
# 기본: [표현식 for 변수 in 시퀀스]
[i**2 for i in range(1, 6)]              # [1, 4, 9, 16, 25]

# 필터: 뒤에 if
[i for i in range(10) if i % 2 == 0]     # [0, 2, 4, 6, 8]

# 변환(if-else): 앞에 — 순서 주의!
["합격" if s >= 60 else "불합격" for s in scores]
```

### 딕셔너리·집합 컴프리헨션
```python
{m["name"]: m["salary"] for m in members}   # 딕셔너리
{x % 3 for x in range(10)}                   # 집합 {0,1,2}
```

---

## 실제 예시

```python
raw = [' Python ', 'SQL', ' ', '']
clean = [s.strip() for s in raw if s.strip()]   # ['Python', 'SQL']

names = [m["name"] for m in members if m["salary"] >= 5000]
```

---

## 자주 헷갈리는 것

**if 위치**: 필터 `if`는 **뒤**(`for x in seq if 조건`), 변환 `if-else`는 **앞**(`A if 조건 else B for x in seq`).

**남용 금지**: 너무 복잡하면 그냥 for문이 더 읽기 쉽다. 중첩 컴프리헨션은 2단까지만 권장.

---

## 더 알면 좋은 것

📌 **제너레이터 표현식**: `(x for x in seq)` — 대괄호 대신 소괄호. 메모리를 아끼며 하나씩 생성. `sum(x for x in nums)`.

📌 **map/filter 대체**: `[f(x) for x in seq]` = `map(f, seq)`, 보통 컴프리헨션이 더 읽기 쉬움. → [[람다]]
