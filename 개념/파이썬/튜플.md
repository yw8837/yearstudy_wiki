# 튜플 (Tuple)

**정의**: 여러 값을 순서대로 담되, 한 번 만들면 값을 바꿀 수 없는(불변) 파이썬 자료구조. 소괄호 `()`로 생성한다.

---

## 왜 필요한가

리스트는 자유롭게 수정할 수 있어서 편하다. 하지만 **"절대 바뀌면 안 되는 데이터"** 도 있다. 예를 들어 화면 좌표 `(x, y)`, 생년월일 `(2026, 6, 1)`, RGB 색상 `(255, 0, 0)` 같은 값이 코드 중간에 실수로 바뀌면 큰 버그가 된다.

튜플은 "이 데이터는 고정이야"라고 못을 박아 두는 자료형이다. 실수로 값을 바꾸려 하면 파이썬이 에러를 내서 막아 준다.

---

## 어떻게 작동하나

### 기본 생성

```python
t = (1, 2, 3)          # 소괄호로 생성
point = (10, 20)       # 좌표
empty = ()             # 빈 튜플

# 원소가 1개일 때는 반드시 쉼표!
t_one = (1,)           # 튜플 (O)
not_tuple = (1)        # 그냥 정수 1 (X) — 괄호일 뿐
print(type((1,)))      # <class 'tuple'>
print(type((1)))       # <class 'int'>
```

> 💡 **괄호 없이도 만들어진다**: `t = 1, 2, 3` 처럼 쉼표만 찍어도 튜플이 된다. 파이썬에서 튜플의 본질은 괄호가 아니라 **쉼표**다.

### 리스트와 똑같이 쓸 수 있는 것

순서가 있으므로 인덱싱·슬라이싱·`in`·`len`·`+`·`*`가 전부 동작한다.

```python
t = (1, 2, 3, 4, 5)

t[1]        # 2          (인덱싱)
t[-1]       # 5          (음수 인덱싱)
t[:2]       # (1, 2)     (슬라이싱)
2 in t      # True       (포함 여부)
len(t)      # 5          (길이)
(1, 2) + (3, 4)   # (1, 2, 3, 4)   (이어 붙이기)
(0,) * 3          # (0, 0, 0)      (반복)
```

### 리스트와 다른 점 — 값을 바꿀 수 없다

```python
t = (1, 2, 3)
t[0] = 99        # TypeError: 'tuple' object does not support item assignment

# .append() / .remove() / .sort() 같은 수정 메서드도 없음
t.append(4)      # AttributeError
```

### 튜플이 가진 메서드는 단 2개

수정이 안 되니 "읽기" 메서드만 있다.

```python
t = (1, 2, 2, 3, 2)

t.count(2)    # 3   (값 2가 몇 번 나오는지)
t.index(3)    # 4   (값 3이 처음 나오는 위치)
```

## 실제 예시

### 함수가 여러 값을 한 번에 반환할 때

파이썬 함수는 원래 값을 하나만 반환하지만, 튜플을 쓰면 여러 개를 묶어 돌려줄 수 있다.

```python
def min_max(numbers):
    return min(numbers), max(numbers)   # 쉼표 → 튜플로 묶임

result = min_max([3, 1, 9, 5])
print(result)        # (1, 9)

# 언패킹(unpacking): 한 번에 나눠 받기
low, high = min_max([3, 1, 9, 5])
print(low, high)     # 1 9
```

### 변수 여러 개 한 줄에 교환(swap)

```python
a, b = 10, 20
a, b = b, a          # 튜플 언패킹으로 두 값 교환
print(a, b)          # 20 10
```

### 딕셔너리의 Key로 사용

좌표처럼 묶인 값을 키로 쓸 때 유용하다.

```python
grid = {(0, 0): "시작", (1, 2): "보물"}
print(grid[(1, 2)])  # 보물
```

## 자주 헷갈리는 것

**원소 1개 튜플의 쉼표를 빠뜨림**:
```python
x = (5)      # 정수 5
y = (5,)     # 원소 1개짜리 튜플
```

**"튜플은 절대 안 바뀐다"는 오해**: 튜플 자체는 불변이지만, 튜플 안에 **리스트(가변)** 가 들어 있으면 그 리스트의 내용은 바꿀 수 있다.
```python
t = (1, [2, 3])
t[1].append(4)       # OK — 안에 든 리스트는 가변
print(t)             # (1, [2, 3, 4])
t[1] = [9]           # TypeError — 튜플 자리 자체는 못 바꿈
```

**리스트로 바꾸고 싶을 때**: 직접 수정은 불가하지만 `list()`로 변환하면 된다.
```python
t = (1, 2, 3)
temp = list(t)       # [1, 2, 3]
temp.append(4)
t = tuple(temp)      # (1, 2, 3, 4) — 새 튜플로 교체
```

## 더 알면 좋은 것

📌 **왜 굳이 불변을 쓸까**: ① 실수로 데이터가 바뀌는 사고를 막는다, ② 불변이라 딕셔너리 Key·집합(set) 원소로 쓸 수 있다, ③ 리스트보다 메모리를 약간 적게 쓰고 약간 빠르다.

📌 **네임드 튜플(namedtuple)**: 인덱스 번호 대신 이름으로 접근하는 튜플. `from collections import namedtuple` → `Point = namedtuple("Point", ["x", "y"])` → `p.x`, `p.y`로 읽기. 좌표·레코드를 다룰 때 가독성이 좋다. (수업 미커버)

📌 **`enumerate()`·`zip()`의 결과**: 반복문에서 자주 쓰는 이 함수들이 내부적으로 튜플 쌍을 만들어 준다. → [[반복문]]
