# 축 (axis)

**정의**: [[ndarray]]의 **방향(차원)**. 집계 함수에서 `axis`로 **어느 방향을 접을지** 지정한다.

---

## 왜 필요한가

🔑 **강사: "판다스에서도 동일 개념으로 반복".** 행별 합·열별 평균처럼 **방향을 정해 집계**하려면 axis를 정확히 이해해야 한다. 분석 전반에서 가장 자주 쓰는 개념.

---

## 어떻게 작동하나

```python
import numpy as np
b = np.array([[1,1],
              [2,2]])
b.sum()          # 6        전체 합
b.sum(axis=0)    # [3 3]    축0(행)을 접음 → 열 합처럼 보임
b.sum(axis=1)    # [2 4]    축1(열)을 접음 → 행 합
```

```
axis=0 ↓ (행 방향으로 접기 → 열별 결과)
  [[1 1]
   [2 2]]
axis=1 → (열 방향으로 접기 → 행별 결과)
```

- "axis=k를 접는다" = 그 축이 사라지고 나머지 축 모양으로 결과가 나온다.

---

## 실제 예시

- `np.mean(X, axis=0)` — 열별 평균(특성별 평균, z-score 표준화에 사용).
- `~np.any(np.isnan(X), axis=1)` — 행 단위 결측 검사.

---

## 자주 헷갈리는 것

**axis=0이 "행"이 아니라 "행 방향으로 접기".** 결과가 열별로 나와 헷갈리기 쉽다. "그 축을 없앤다"로 기억.
