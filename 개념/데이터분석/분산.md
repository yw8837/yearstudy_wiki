# 분산 (Variance)

**정의**: 관측값이 [[평균]]에서 얼마나 퍼져 있는지를 나타내는 산포 측도. **편차의 제곱의 평균**. 모분산 $s^2=\frac{\sum(x_i-\bar{x})^2}{n}$, 표본분산은 분모가 n-1.

---

## 왜 필요한가

중심위치만으로는 분포를 알 수 없다. 평균이 같아도(A σ=10 vs B σ=20) 퍼짐이 다르다. 분산이 그 "퍼짐"을 수치화한다.

---

## 어떻게 작동하나

```python
import numpy as np
np.var(df['total_bill'], ddof=1)   # 79.25 (표본분산, tips)
```

- 편차 $(x_i-\bar{x})$의 **합은 항상 0** → 그냥 더하면 의미 없다 → **제곱**해 양수화한 뒤 평균.
- 단점: 제곱했으므로 **단위가 원 변수의 제곱**(해석이 어려움) → 제곱근 [[표준편차]]를 함께 쓴다.

---

## 자주 헷갈리는 것

**분모 n vs n-1.** 모집단 전체면 n(모분산), **표본으로 모집단을 추정**하면 n-1(표본분산, 불편추정량, `ddof=1`). 강의 PDF는 모분산(n), numpy/노트북은 표본분산(n-1)을 써서 **정의가 다르다**.

---

## 더 알면 좋은 것

📌 분산의 양의 제곱근이 [[표준편차]]다. 실무에선 단위가 같은 표준편차를 주로 쓰고, 분산은 계산 중간 단계로 본다.
