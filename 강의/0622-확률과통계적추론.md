## 01. 확률의 기초 → [[확률]] · [[조건부확률]] · [[사건의독립]]

확률 = 여러 결과 중 하나(또는 일부)가 일어날 가능성을 **0~1 값**으로 정의. `P(A) = 사건 A의 원소 수 / 표본공간 Ω의 원소 수`.

| 용어 | 정의 | 예 |
|:--|:--|:--|
| 시행(Trial) | 결과를 내는 행위 | 동전 던지기 |
| 표본공간(Ω) | 모든 결과의 집합 | 동전: {H, T} |
| 사건(A) | Ω의 부분집합 | 앞면 A={H}, P(A)=1/2 |

- **추출 방법:** 복원추출(꺼내 확인 후 다시 넣음, 매 시행 동일) / 비복원추출(다시 안 넣음, 앞 시행이 뒤에 영향).
- **사건 연산:** 여사건 Aᶜ / 합사건 A∪B / 곱사건 A∩B / 배반사건 A∩B=∅.
- **경우의 수:** 합의 법칙(배타적이면 m+n) / 곱의 법칙(동시·연속이면 m×n). 팩토리얼 `n! = n·(n-1)!`, `0!=1`.
- **확률의 공리:** ① `0≤P(A)≤1` ② `P(Ω)=1` ③ 배반사건이면 `P(∪Aᵢ)=ΣP(Aᵢ)`.
- **확률의 정리:** 여집합 `P(Aᶜ)=1-P(A)` / 덧셈정리 `P(A∪B)=P(A)+P(B)-P(A∩B)` / `A⊂B → P(A)≤P(B)`.

**조건부확률**(다른 사건 정보가 주어질 때): `P(A|B) = P(A∩B)/P(B)` (단 P(B)≠0). **독립**(서로 영향 없음): `P(A∩B)=P(A)P(B)` ⇔ `P(A|B)=P(A)`.

→ [[확률]] · [[조건부확률]] · [[사건의독립]] · [[순열조합]] 참조

## 02. 순열·조합 (itertools) → [[순열조합]]

서로 다른 n개에서 k개를 뽑을 때 **순서 고려 여부 × 중복 허용 여부**로 4분류.

| 구분 | 공식 | itertools |
|:--|:--|:--|
| 순열(순서 O) | ₙPₖ = n(n-1)…(n-k+1) | `permutations(seq, k)` |
| 조합(순서 X) | ₙCₖ = ₙPₖ / k! | `combinations(seq, k)` |
| 중복순열(순서 O·중복) | ₙΠᵣ = nʳ | `product(seq, repeat=k)` |
| 중복조합(순서 X·중복) | ₙHᵣ = ₙ₊ᵣ₋₁Cᵣ | `combinations_with_replacement(seq, k)` |

- 예) 중복조합 {1,2,3,4}에서 3개 = ₄H₃ = ₆C₃ = 20.
- ⚠ **[원문 확인]** 슬라이드 p24 예시-라벨이 뒤바뀜: 반장/부반장 뽑기=순열, 2명 대표 선발=조합이 정의상 맞다.

## 03. 확률변수와 확률분포 → [[확률변수]] · [[확률분포]] · [[확률질량함수]] · [[확률밀도함수]] · [[누적분포함수]]

**확률변수(X)**: 각 근원사건에 실수를 대응시킨 함수(대문자로 표기). 예) 동전 2번 던져 앞면 수 X∈{0,1,2}, `P(X=2)=1/4`, `P(X=1)=1/2`.

- **이산확률변수**(셀 수 있음) → [[확률질량함수|PMF]] `f(x)`, 조건 `0≤f(xᵢ)≤1`, `Σf(xᵢ)=1`.
- **연속확률변수**(구간) → [[확률밀도함수|PDF]] `f(x)`, 조건 `f(x)≥0`, `P(a≤X≤b)=∫ₐᵇf(x)dx`, `∫f=1`.
- **[[누적분포함수|CDF]]**: `F(x)=P(X≤x)` — 최솟값부터 x까지 확률을 누적. 이산은 합, 연속은 적분.

→ [[확률변수]] · [[확률분포]] · [[확률질량함수]] · [[확률밀도함수]] · [[누적분포함수]] 참조

## 04. 여러 가지 확률분포 (scipy.stats) → [[이항분포]] · [[포아송분포]] · [[정규분포]]

scipy는 분포 객체를 만들고 `.pmf()`/`.pdf()`/`.cdf()`로 확률을 계산한다.

| 분포 | 표기 | 핵심 | scipy |
|:--|:--|:--|:--|
| 베르누이 | — | 성공/실패 1회 시행, p | — |
| [[이항분포]] | B(n,p) | 베르누이 n번 반복 성공 수 | `stats.binom(n,p)` |
| [[초기하분포]] | Hyper(M,n,N) | **비복원**추출 성공 수(불량률) | `stats.hypergeom(M,n,N)` |
| [[포아송분포]] | Poi(λ) | 단위 시공간 드문 사건 수 | `stats.poisson(λ)` |
| [[균일분포]] | U(a,b) | 구간 내 균일 | `stats.uniform(a,b)` |
| [[정규분포]] | N(μ,σ²) | 종형 곡선 | `stats.norm(μ,σ)` |

```python
from scipy import stats
import numpy as np
stat = stats.binom(n, p)          # 이항분포 확률변수 객체
stat.pmf(x); stat.cdf(x)          # 확률질량·누적분포
np.random.binomial(n, p, size)    # 랜덤 샘플
```

- **포아송 근사:** B(n,p)에서 n이 크고 p가 작으면 λ=np인 포아송으로 근사.
- **[[표준정규분포]]:** μ=0, σ=1인 N(0,1). 표준화 `Z=(X-μ)/σ`.

→ [[이항분포]] · [[포아송분포]] · [[정규분포]] · [[표준정규분포]] · [[초기하분포]] · [[균일분포]] 참조

## 05. 모집단·표본과 통계적 추론 → [[모집단과표본]] · [[통계적추론]] · [[점추정과구간추정]]

**추론통계의 출발**: 모집단 전체는 조사하기 어려우니 **표본**으로 **모수**를 추정한다.

```
모집단 ──표집(Sampling)──▶ 표본 ──통계량 계산──▶ 추론(Inference) ──▶ 모수
(전체·미지)                (일부·조사)          (표본값)           (모집단 특성)
```

| 용어 | 정의 |
|:--|:--|
| 모수(Parameter) | 모집단에서 계산된 값(미지) |
| 통계량(Statistic) | 표본에서 계산된 값(모수를 추정) |

- **통계적 추론 = 모수추정 + 가설검정.** 표본으로 전체를 추론하므로 **항상 오류가 존재**(부정확도 명시 필수).
- **점추정:** 모수에 가까울 하나의 값(모평균 추정량 = 표본평균 X̄).
- **구간추정:** 모수를 포함하리라 예상되는 (하한, 상한) 구간.
  - [[신뢰구간]]: `X̄ ± z_(α/2)·σ/√n`. [[신뢰구간|신뢰수준]]: 그 구간이 모수를 포함할 확률(95% 등).
  - 예) N(100,10²)에서 n=15, x̄=105 → 95% 신뢰구간 `105 ± 1.96·10/√15 = (99.94, 110.06)`.

→ [[모집단과표본]] · [[통계적추론]] · [[점추정과구간추정]] · [[신뢰구간]] 참조

## 06. 가설검정 이론 → [[가설검정]] · [[귀무가설과대립가설]] · [[1종오류와2종오류]] · [[유의수준]] · [[p-value]]

**가설검정**: 모수에 대한 주장의 옳고 그름을 표본으로 판단.

- **[[귀무가설과대립가설|귀무가설 H₀]]**(기본·차이 없음) vs **대립가설 H₁**(입증하려는 연구가설). 예) 공정한 동전? `H₀: p=1/2`, `H₁: p≠1/2`.
- **양측**(≠) / **단측**(>, <).
- **표현 규칙:** 귀무가설 기준으로 말한다 — 대립 채택 = "H₀을 **기각한다**", 귀무 채택 = "H₀을 **기각할 수 없다**". "귀무가설 채택"은 부정확한 표현.

**오류의 종류(반비례 — 동시 최소화 불가):**

| | H₀ 참 | H₀ 거짓 |
|:--|:--|:--|
| H₀ 기각 | **[[1종오류와2종오류\|1종 오류 α]]** (무죄를 유죄) | 옳은 판단 |
| H₀ 채택 | 옳은 판단 | **2종 오류 β** (유죄를 무죄) |

- 전통 통계학은 **1종 오류를 먼저 최소화**한다. **[[유의수준]] α** = 1종 오류 최대 허용확률(0.01~0.10). 신뢰수준 = 1-α, **검정력 = 1-β**.
- **검정 절차:** 가설 설정 → 표본 관측 → 검정통계량 선택 → 관측값 계산 → 기각역/p-value 계산 → 판정.
- **[[검정통계량과기각역|기각역]]:** H₀을 기각하는 구간(`R: X̄ ≤ c`).
- **[[p-value|유의확률(p-value)]]:** 표본이 대립가설을 지지하는 정도(0~1). **`α > p → H₀ 기각`, `α < p → 기각 못함`**. `p<0.05`(*)/`<0.01`(**)/`<0.001`(***).

**이항검정·z검정:**
```python
scipy.stats.binom_test(x, n, p, alternative='two-sided')  # 모수 p 검정
# ※ 최신 scipy는 binomtest 권장(binom_test deprecated)
# 모평균 z검정: Z = (X̄-μ₀)/(σ/√n) ~ N(0,1)
```
- ⚠ **[원문 확인]** p87 우측 단측 기각역 `R: Z ≥ -z_α`는 부호 오기 추정(통상 `Z ≥ z_α`).

## 07. 검정 기법 선택 지도 → [[t검정]] · [[카이제곱검정]] · [[분산분석]]

**핵심은 "어떤 상황에 어떤 검정을 쓰는가"**다. 데이터 형태로 갈린다.

```

 2집단(독립) ──── 정규성O·등분산O ─▶ 독립표본 t검정  stats.ttest_ind(equal_var=True)
               ├ 등분산X ────────▶ Welch          ttest_ind(equal_var=False)
               └ 정규성X ────────▶ Mann-Whitney(비모수)
 2집단(쌍) ───── 정규성O ─────────▶ 대응표본 t검정  stats.ttest_rel
               └ 정규성X ────────▶ Wilcoxon(비모수)
 3집단 이상 ─────────────────────▶ 일원분산분석    stats.f_oneway → 기각 시 Tukey HSD

[범주형]
 관측 vs 이론분포 ───────────────▶ 카이제곱 적합도  stats.chisquare
 두 범주형 독립성 ───────────────▶ 카이제곱 독립성  stats.chi2_contingency

[관계·예측]
 두 연속형 선형관계 ─────────────▶ 피어슨 상관     stats.pearsonr
 연속형 Y 예측 ──────────────────▶ 다중선형회귀    smf.ols / sm.OLS
 이진 Y 분류 ────────────────────▶ 로지스틱 회귀   smf.logit / sm.Logit
```

**가정 진단 순서(t검정):** ① [[정규성검정]](Shapiro-Wilk, N≤30일 때. N≥30이면 [[중심극한정리|CLT]]로 가정) → ② [[등분산검정]](Levene) → ③ 본 검정. 위반 시 Welch/[[비모수검정]]으로 우회.

## 08. t검정 3종 (단일·독립·대응) → [[t검정]]

```python
from scipy import stats
# ① 단일표본: 모평균 = 기준값?  H₀: μ=μ₀
t, p = stats.ttest_1samp(df['Height'], popmean=75)
# ② 독립표본: 두 집단 평균 차?  (등분산 먼저)
lev_stat, lev_p = stats.levene(a, b)          # H₀: 분산 같음
t, p = stats.ttest_ind(a, b, equal_var=(lev_p>=0.05))   # False면 Welch
# ③ 대응표본: 전후 차이?  H₀: μ_D=0
t, p = stats.ttest_rel(post, pre, alternative='greater')  # 단측
```

- **실습(취업/HR):** 온라인 vs 오프라인 월매출 독립 t → t=4.786, p=0.0 **기각**. 캠페인 전후 전환율 대응 t → t=13.235, p=0.0 **기각**(효과 있음).
- **대응표본**은 동일 대상을 쌍으로 묶어 차이 D=X-Y를 검정(쌍체비교). 실험 전/후에 사용.

## 09. 카이제곱·분산분석 → [[카이제곱검정]] · [[분산분석]]

```python
from scipy import stats
# 적합도: 관측이 이론분포를 따르나?
f, p = stats.chisquare(observed, f_exp=expected)
# 독립성: 두 범주형이 독립인가?  df=(r-1)(c-1), 기대도수≥5(미만 Fisher)
ct = pd.crosstab(df['hire_type'], df['final_pass'])
chi2, p, dof, expected = stats.chi2_contingency(ct)
# ANOVA: 3+ 집단 평균 차?  기각 시에만 사후검정
f, p = stats.f_oneway(g1, g2, g3)
from statsmodels.stats.multicomp import pairwise_tukeyhsd   # Tukey HSD
```

- **실습:** 채용 전형×합격 카이제곱 → chi2=46.137, p=0.0 **기각**(연관 있음). 직군별 토익 ANOVA → F=10.878, p=0.0 **기각**, Tukey 유의쌍(IT vs 기획/영업, 마케팅 vs 영업).
- **[[분산분석|ANOVA]] 아이디어:** 집단 내 분산보다 **집단 간 분산이 크면** 평균 차가 유의(F 검정통계량).

## 10. 회귀·로지스틱 (statsmodels) → [[회귀분석]] · [[로지스틱회귀]] · [[상관분석]]

```python
import statsmodels.formula.api as smf
# 다중선형회귀: 연속형 Y 예측  H₀: 기울기=0
model = smf.ols("monthly_sales ~ call_count + visit_count + work_years", data=df).fit()
model.rsquared        # R² (설명력), model.rsquared_adj (변수 수 페널티)
model.pvalues         # 변수별 유의성(<0.05 = 유의변수)
# 로지스틱: 이진 Y 확률 예측
model = smf.logit("doc_pass ~ toeic + gpa + intern", data=df).fit(disp=False)
prob = model.predict(df); y_pred = (prob >= 0.5).astype(int)
odds_ratio = np.exp(model.params["balance"])   # 오즈비(β>0이면 증가 시 확률↑)
```

- **실습:** 영업 월매출 다중회귀 R²=0.940. 서류합격 로지스틱 Accuracy=0.848(gpa 계수 1.41 최대). [[상관분석|피어슨]] `stats.pearsonr` → r, p.
- **[[회귀분석|회귀 진단 4가정]]:** 선형성·독립성(Durbin-Watson)·등분산성·정규성 — 모두 **잔차(Residual)**로 검증.
- **[[로지스틱회귀]] 지표:** 오즈비 `exp(β)` / 잔차이탈도 `-2·llf` / 정확도 / 오분류율 / AUC.
- **표준편차 vs 표준오차:** `s=√(Σ(xᵢ-x̄)²/(n-1))`(데이터 퍼짐) vs `S.E=s/√n`(표본평균의 표준편차, n↑이면 감소).

→ [[회귀분석]] · [[로지스틱회귀]] · [[상관분석]] · [[오즈비]] 참조

## 보충

📌 **오늘부터 추론통계다.** 6/19까지의 [[0619-통계자료요약|기술통계]]는 "가진 데이터 요약", 오늘부터는 "표본→모집단 추론"이다. 그래서 [[확률]]→[[확률분포]]→[[중심극한정리|CLT]]→[[가설검정]]의 다리가 필요하다. CLT(n≥30이면 표본평균 분포가 정규분포)가 z검정·t검정을 정당화하는 핵심 근거.

📌 **가설검정 표현은 항상 귀무가설 기준.** "대립가설을 채택"이 아니라 "**귀무가설을 기각한다/기각할 수 없다**"로 말한다. "귀무가설 채택"(X) → "귀무가설을 기각하지 못한다"(O). 데이터가 없음을 증명한 게 아니라 기각할 근거가 부족한 것뿐이기 때문.

📌 **p-value 판정 한 줄:** `p < α`면 기각(유의), `p ≥ α`면 기각 못함. α는 보통 0.05. 이 한 줄이 작업형 3유형 전체를 관통한다.

📌 **검정 선택은 "데이터 형태 + 가정 확인"이 먼저.** 평균 비교인지·범주형인지·예측인지 → 집단 수·독립/대응 → 정규성(Shapiro)·등분산(Levene) 확인 → 위반 시 Welch/비모수. §07 지도를 몸에 익히면 회차가 바뀌어도 대응된다.

📌 **1종 오류를 왜 먼저 줄이나.** 1종·2종은 반비례라 동시 최소화가 불가능하다. 보통 "참인데 뒤집는" 1종 오류(무죄를 유죄, 효과 없는 약을 있다고 판단)의 비용이 커서, α를 먼저 고정(0.05)하고 그 안에서 검정력(1-β)을 높인다.

📌 **표준편차 ≠ 표준오차.** 표준편차 s는 "개별 데이터가 평균에서 얼마나 퍼졌나", 표준오차 S.E=s/√n은 "표본평균이 모평균에서 얼마나 흔들리나". 표본이 커지면(n↑) 표준오차만 줄어든다(추정이 정밀해짐). 신뢰구간·검정통계량의 분모가 표준오차다.
