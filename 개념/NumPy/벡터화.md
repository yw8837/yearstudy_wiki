# 벡터화 (Vectorization)

**정의**: 파이썬 **for 루프 대신 배열 단위 연산**으로 처리하는 방식. NumPy가 반복을 **C 레벨**에서 돌려 훨씬 빠르다.

---

## 왜 필요한가

원소가 많을수록 파이썬 루프는 느리다. 벡터화하면 같은 계산을 **수십~수백 배** 빠르게 끝낼 수 있다 — 대규모 데이터 분석의 전제.

---

## 어떻게 작동하나

```python
import numpy as np
big = np.arange(10_000_000)

# 느림: 파이썬 루프 (원소마다 +5)  ≈ 5.3s
# result = [x + 5 for x in big]

# 빠름: 벡터화 (배열에 직접)        ≈ 33.5ms  → 약 160배
result = big + 5
```

```
루프:   원소 → +5 → 원소 → +5 ...   (파이썬 인터프리터, 느림)
벡터화: [전체 배열] + 5             (C 루프 일괄, 빠름)
```

---

## 실제 예시

- 표준화 `(X - mu) / sig`, 마스킹 `a[a>0]` 모두 루프 없는 벡터화 연산.

---

## 자주 헷갈리는 것

**"한 줄로 짧다"가 핵심이 아니라 "C 레벨 처리"가 핵심.** 루프를 안 쓰는 것 자체가 속도를 만든다([[브로드캐스팅]]·[[ufunc]]이 이를 뒷받침).
