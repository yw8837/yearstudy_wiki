# 네트워크 (Network)

**정의**: 두 개 이상의 기기가 연결되어 데이터를 주고받는 구조 전체.

---

## 왜 필요한가

인터넷, Wi-Fi, 블루투스, 회사 내부망 — 전부 네트워크다. 기기들이 서로 데이터를 주고받으려면 공통된 규칙(프로토콜)이 필요하다. 이 규칙들을 계층으로 나눠 정리한 것이 OSI 7계층이다.

---

## 어떻게 작동하나

### OSI 7계층

네트워크 통신을 7단계로 나눈 국제 표준. 각 계층이 독립적으로 역할을 수행한다.

```
7. 응용(Application)    ← HTTP, DNS, FTP, SMTP
6. 표현(Presentation)   ← SSL/TLS, JPEG, ASCII
5. 세션(Session)        ← 연결 유지·관리
─────────────────────────────────────────────
4. 전송(Transport)      ← TCP, UDP
3. 네트워크(Network)    ← IP, 라우팅
2. 데이터링크(DataLink) ← Ethernet, Wi-Fi, MAC
1. 물리(Physical)       ← 케이블, 허브, 신호
```

실무에서는 OSI 7계층보다 **TCP/IP 4계층**이 더 자주 등장한다.

```
응용 계층       ← HTTP, DNS, FTP
전송 계층       ← TCP, UDP
인터넷 계층     ← IP
네트워크 접속  ← Ethernet, Wi-Fi
```

### 데이터 전송 흐름 — 보낼 때 포장, 받을 때 뜯기

데이터를 보낼 때 각 계층을 내려가면서 헤더가 붙는다. 받을 때는 역순으로 벗겨낸다.

```
[보내는 쪽]
데이터 → [TCP 헤더 추가] → [IP 헤더 추가] → [이더넷 헤더 추가] → 전송

[받는 쪽]
수신 → [이더넷 헤더 제거] → [IP 헤더 제거] → [TCP 헤더 제거] → 데이터
```

### 네트워크 규모

| 유형 | 범위 | 예시 |
|:---|:---|:---|
| PAN | 개인 기기 간 ~10m | 블루투스 이어폰, USB |
| LAN | 건물·캠퍼스 내 | 회사 Wi-Fi, 이더넷 |
| WAN | 국가·대륙 이상 | 인터넷, 전용선 |

### 통신 방식

- **유니캐스트**: 1:1 (카카오톡 DM)
- **멀티캐스트**: 1:그룹 (단체 카톡방)
- **브로드캐스트**: 1:전체 (DHCP IP 할당 시 전체에 뿌림)

## 실제 예시

브라우저에서 `https://www.google.com` 입력했을 때 일어나는 일:

```
1. DNS 조회 → google.com의 IP 주소 확인
2. TCP 3-way handshake → 서버와 연결
3. TLS handshake → 암호화 채널 설정 (HTTPS)
4. HTTP GET 요청 전송
5. 서버 HTTP 응답 수신
6. 브라우저가 HTML 파싱 → 화면 렌더링
```

이 모든 과정이 수백ms 안에 일어난다.

## 자주 헷갈리는 것

**"인터넷 = 네트워크"**: 인터넷은 전 세계를 연결한 거대한 WAN이지만, 네트워크는 더 넓은 개념이다. 집 안의 Wi-Fi도, 회사 내부망도 다 네트워크다.

**"OSI 7계층을 실무에서 많이 쓴다"**: 실제로는 TCP/IP 4계층을 더 많이 쓴다. OSI는 개념·교육용 표준이고 실제 인터넷은 TCP/IP 기반으로 설계됐다.

**"프로토콜 = HTTP"**: HTTP는 많은 프로토콜 중 하나. 프로토콜은 "통신의 규칙·약속"이라는 개념이고, HTTP, TCP, IP, DNS, FTP 등 수십 가지가 있다.

## 더 알면 좋은 것

📌 **토폴로지(Topology)**: 네트워크 기기들의 물리적 연결 형태
- Star: 중앙 허브에 모두 연결 (현재 가장 일반적)
- Bus: 하나의 선에 모두 연결
- Ring: 원형으로 연결
- Mesh: 일부 노드 상호 연결

📌 **라우터와 스위치**: 라우터는 서로 다른 네트워크를 연결(IP 기반), 스위치는 같은 네트워크 내 기기 연결(MAC 기반). 공유기 = 라우터 + 스위치 + 무선 AP 통합.
