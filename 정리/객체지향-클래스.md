# 객체지향(클래스) · 모듈 정리

클래스(OOP)와 모듈·패키지를 **섹션별로 한눈에**. 자세한 설명은 개념 페이지 링크에서.

## 1. 클래스 기본 → [[클래스]]

```python
class TeamMember:
    company = "이어드림"           # 클래스 변수 (공유)
    def __init__(self, name, salary):
        self.name = name           # 인스턴스 변수 (각자)
        self.salary = salary
    def introduce(self):           # 메서드 (self 필수)
        print(f"{self.name}입니다")

alice = TeamMember("Alice", 6000)  # 인스턴스 생성
alice.introduce()                  # self=alice 자동
```

- **클래스**=설계도, **인스턴스**=실제 객체
- `__init__`=생성 시 자동 실행, `self`=그 객체 자신

## 2. 메서드 종류

```python
def method(self): ...          # 인스턴스 메서드 (객체 데이터)
@classmethod
def m(cls): ...                # 클래스 메서드 (cls, 대체 생성자)
@staticmethod
def m(): ...                   # 정적 메서드 (독립 유틸)
def __str__(self): ...         # 매직 메서드 (print 시 호출)
```

## 3. 상속 · 다형성 → [[상속]]

```python
class DevTeam(Department):         # 부모 상속
    def __init__(self, budget):
        super().__init__("개발팀", budget)   # 부모 초기화
    def meeting(self):             # 오버라이딩 (재정의)
        print("스프린트 회의")

for t in [DevTeam(...), SalesTeam(...)]:
    t.meeting()                    # 다형성: 같은 호출, 다른 결과
```

📌 `isinstance(obj, 클래스)` / `issubclass(자식, 부모)` *(예습 — 수업 미진행)*

## 4. 모듈과 패키지 → [[모듈과패키지]]

```python
import math                  # 통째로 → math.sqrt()
import random as rd          # 별칭
from math import pi, sqrt    # 콕 집어
import sound.audio           # 패키지(폴더).모듈
```

- **모듈**=`.py` 파일 / **패키지**=모듈 담은 폴더
- 표준 라이브러리(math·random)는 설치 없이, 외부 패키지(numpy)는 uv/pip로

## 5. 지역/전역 보강 → [[함수]]

```python
s = "전역"
def f():
    s = "지역"        # Shadowing: 전역을 가림 (전역 안 바뀜)
def g():
    global s          # 전역을 수정하려면 global 선언
```
