# 데이터 시각화 원칙 정리

『Fundamentals of Data Visualization』 기반 6/18 2부(이론) 요약. **왜·무엇**(원칙)만, 코드 실습은 10~12일차.

> 강의 출처: [[0618-pandas와데이터시각화]] · 상세: [[RoseDiagram]] · [[미학요소]] · [[색상스케일]] · [[비례잉크원칙]]

---

## 1. 왜 시각화인가 → [[RoseDiagram]] · [[앤스컴콰르텟]]

- **나이팅게일 [[RoseDiagram|Rose Diagram]]:** 크림전쟁 사망 데이터를 polar area로 → Before/After 정책효과 비교. "데이터 자체 보고(X), **전달 방식의 차별화**(O)".
- **[[앤스컴콰르텟|앤스컴 콰르텟]]:** 동일 통계량(평균·분산·상관·회귀선 같음)인데 **분포는 4개 다 다름** → **수치만 보지 말고 반드시 시각화**.

---

## 2. 시각화 원리: 삭제 > 분리 > 강조 > 배열

> Gene Zelazny 『Say it with Charts』

| 원리 | 한 줄 |
|:--|:--|
| 삭제(Delete) | 의미 없는 차트 제거 |
| 분리(Divide) | 분리 후 별도 차트·논리 순서 |
| 강조(Highlight) | 필수 강조·부가 약하게(대조) |
| 배열(Arrange) | 영역 그룹핑·논리 순서 구조화 |

---

## 3. 3대 문제 & 목표

- **심미적**(매력) · **지각적**(명확/정보과다) · **수학적**(수치 왜곡).
- 목표: **명확(Clear)·정직(Honest)·간결(Concise)**.

---

## 4. 미학 요소 → [[미학요소]]

- 시각 속성: **위치·길이**(최정밀) > 색상·면적·형태·크기.
- 원칙: ① 중요 변수 → **위치·길이** 우선 매핑 ② **일대일(가역성)** 1:1 ③ **접근성([[CVD]])** 색+모양 병행 ④ **단순성** 미학 3개 이내.

---

## 5. 좌표계 → [[좌표계]]

| 좌표계 | 용도/주의 |
|:--|:--|
| 직교(Cartesian) | 표준 2D, 같은 단위면 1:1 |
| 로그(Log) | 곱셈·비율·넓은 범위, 0·음수 불가(기준 1) |
| 극좌표(Polar) | 주기 데이터(연 기온·24h), 파이=stacked bar 변형 |
| 지도 투영 | 3D→2D 필연 왜곡(정각 Mercator/정적 Goode/절충 Robinson) |

- 같은 물리단위면 1:1 종횡비, **막대는 0 시작**·산점/선은 0 불필요.

---

## 6. 색상 스케일 → [[색상스케일]] · [[CVD]]

| 용도 | 스케일 | 예 |
|:--|:--|:--|
| 구분 | Qualitative | Okabe-Ito |
| 값 표현 | Sequential/Diverging | Blues·PiYG(중립점) |
| 강조 | Accent | 회색 배경+강조색 |

- **[[CVD]]:** 적록색맹(남 ~8%) → 빨강-초록 회피·명도 병행.
- **무지개색(Rainbow/Jet) 함정:** 비단조 밝기·인위 경계 → **Viridis/Magma/Inferno**(지각적 균등).

---

## 7. 목적별 차트 유형

| 목적 | 대표 차트 | 핵심 |
|:--|:--|:--|
| 양 | Bar/Dot/Heatmap | 막대 0 시작·의미있는 정렬 |
| 분포 | Histogram/KDE/Boxplot/Violin/ECDF/Q-Q | bin·대역폭 민감, ECDF 손실없음 |
| 비율 | Pie/Stacked/Treemap | 부분-전체 |
| 관계 | Scatter/Line/Correlogram | 시계열=Line+Direct Labeling |
| 지리 | Choropleth/Cartogram | 비율(rate), 면적왜곡 주의 |
| 불확실성 | Error bar/CI band | SD/SE/CI 명시·빈도 프레이밍 |

---

## 8. 디자인 원칙 → [[비례잉크원칙]]

- **★[[비례잉크원칙|비례 잉크(Value ∝ Area)]]:** 면적∝수치, **막대 0 시작**(절단=왜곡, 작은 차이는 Dot Plot). 로그축 막대는 기준선 1.
- **중복코딩:** 색+모양/선종류(흑백·[[CVD]] 대비).
- **복합:** Small Multiples(축 공유)·Compound Figures(패널 라벨 a,b,c). 3D 효과 지양.
