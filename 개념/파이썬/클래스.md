# 클래스 (Class)

**정의**: 객체를 만들기 위한 **설계도**. 데이터(속성)와 행동(메서드)을 하나로 묶는 객체지향(OOP)의 기본 단위.

---

## 왜 필요한가

함수·변수가 흩어져 있으면 "팀원 한 명"을 표현하는 이름·연봉·자기소개가 따로 논다. 클래스는 **관련된 데이터와 기능을 한 덩어리**로 묶어, 현실의 사물(팀원·상품·계좌)을 코드로 자연스럽게 표현한다. 같은 종류 객체를 **찍어내듯** 여러 개 만들 수 있다.

---

## 어떻게 작동하나

### 클래스 = 설계도, 인스턴스 = 실제 물건

```python
class TeamMember:        # 설계도 (이름 첫 글자 대문자 관례)
    def __init__(self, name, salary):   # 생성자: 객체 만들 때 자동 실행
        self.name = name       # 인스턴스 속성
        self.salary = salary

alice = TeamMember("Alice", 6000)   # 인스턴스(객체) 생성
print(alice.name)                   # Alice  (객체.속성)
```

- **`__init__`**: 인스턴스가 생길 때 자동 실행 (초기 속성 설정)
- **`self`**: "이 객체 자신". 메서드 첫 매개변수로 자동 전달

### 메서드 — 객체의 행동

```python
class TeamMember:
    def __init__(self, name): self.name = name
    def introduce(self):                 # 인스턴스 메서드
        print(f"안녕하세요, {self.name}입니다.")

TeamMember("Alice").introduce()   # alice.introduce() → self=alice
```

### 클래스 변수 vs 인스턴스 변수

```python
class TeamMember:
    company = "이어드림"          # 클래스 변수 (모든 객체 공유)
    def __init__(self, name):
        self.name = name          # 인스턴스 변수 (객체마다 다름)
```

### 매직 메서드 · classmethod · staticmethod

```python
class TeamMember:
    count = 0
    def __init__(self, name): self.name = name; TeamMember.count += 1
    def __str__(self): return f"팀원 {self.name}"   # print() 시 호출

    @classmethod
    def get_count(cls): return cls.count            # cls = 클래스 자신
    @staticmethod
    def is_valid(salary): return salary >= 1000      # self·cls 없음
```

## 실제 예시

```python
# 은행 계좌를 객체로
class Account:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance
    def deposit(self, amount):
        self.balance += amount
    def __str__(self):
        return f"{self.owner}: {self.balance}원"

acc = Account("홍길동")
acc.deposit(5000)
print(acc)        # 홍길동: 5000원
```

---

## 자주 헷갈리는 것

**`self`를 빼먹음**: 메서드 첫 매개변수는 항상 `self`. 안 쓰면 `TypeError`.

**클래스 변수 수정 함정**: `self.company = "X"`는 그 객체만의 인스턴스 변수를 새로 만든다. 모두에 반영하려면 `클래스명.company = "X"`.

**`__init__`은 "초기화"지 "생성"이 아님**: 객체 생성은 파이썬이, `__init__`은 그 직후 속성 채우기 담당.

## 더 알면 좋은 것

📌 **매직(던더) 메서드**: `__init__` `__str__` `__repr__` `__len__` `__eq__` 등 `__이름__`. 파이썬이 특정 순간 자동 호출. → [데이터 모델](https://docs.python.org/ko/3/reference/datamodel.html)

📌 **데코레이터 `@`**: `@classmethod` `@staticmethod` `@property` — 메서드에 기능을 입히는 표시.

📌 **캡슐화**: `_name`(쓰지 마세요 관례), `__name`(이름 맹글링). 파이썬은 강제 private 없이 관례로.

📌 **isinstance/issubclass**: 객체의 타입·상속 관계 확인. → [[상속]]
