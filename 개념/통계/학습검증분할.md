# 학습/검증 분할 (Train/Test Split)

**정의**: 데이터를 **학습용(train)과 검증용(test)으로 나누는 것**. 모델은 학습셋으로만 배우고, 한 번도 안 본 검증셋으로 성능을 평가한다. titanic 실습은 80:20으로 분할.

---

## 왜 필요한가

학습에 쓴 데이터로 평가하면 "외운 답"을 보는 셈이라 [[머신러닝|과적합]]을 잡지 못한다. **본 적 없는 데이터에서의 성능(일반화 능력)**을 재려면 검증셋을 떼어놔야 한다.

---

## 어떻게 작동하나

```python
# titanic 실습: sklearn train_test_split 미사용, NumPy로 직접
np.random.seed(42)                 # 재현성
n = len(df_model)
indices = np.arange(n)
np.random.shuffle(indices)         # 인덱스 셔플
train_size = int(0.8 * n)          # 80% 학습
train_idx = indices[:train_size]
test_idx  = indices[train_size:]   # 20% 검증
train_df = df_model.iloc[train_idx].reset_index(drop=True)
test_df  = df_model.iloc[test_idx].reset_index(drop=True)
```

- **seed 고정**으로 매번 같은 분할 재현(협업·비교 가능).
- **셔플 후 슬라이싱**: 원본 순서 편향(예: 정렬된 데이터)을 제거.

---

## 자주 헷갈리는 것

**셔플을 빼먹으면 안 된다.** 데이터가 클래스 순으로 정렬돼 있으면 앞 80%에 한 클래스만 몰려 분할이 망가진다. 그래서 `np.random.shuffle`로 인덱스를 섞은 뒤 잘라야 한다. sklearn의 `train_test_split`은 이 과정을 한 줄로 해준다.

## 더 알면 좋은 것

📌 titanic 실습은 sklearn을 안 쓰고 NumPy 셔플+슬라이싱으로 분할 원리를 직접 구현한다. 더 엄밀하게는 클래스 비율을 유지하는 층화(stratified) 분할이나 교차검증(k-fold)을 쓰지만 본 실습 범위 밖. ⚠ `df_model`(전처리 완료 데이터프레임)을 만드는 코드는 노션 원문에 없음 → [원문 확인 필요].
