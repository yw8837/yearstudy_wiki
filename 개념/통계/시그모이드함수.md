# 시그모이드 함수 (Sigmoid)

**정의**: 임의의 실수 z를 **0~1 사이 값**으로 눌러주는 S자(로지스틱) 곡선. `σ(z) = 1 / (1 + e^(−z))`. [[로지스틱회귀]]가 선형결합을 "확률"로 바꿀 때 쓰는 핵심 함수.

---

## 왜 필요한가

선형결합 `z = β₀ + β₁x₁ + … + βₖxₖ`는 −∞~+∞ 범위라 그대로는 확률로 못 쓴다. 시그모이드에 통과시키면 항상 0~1이 되어 **"양성(1)일 확률"**로 해석할 수 있다.

---

## 어떻게 작동하나

```python
import numpy as np
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# z가 0이면 0.5, z가 크면 1에 수렴, 작으면 0에 수렴
sigmoid(0)     # 0.5  → 임계값
sigmoid(5)     # 0.993
sigmoid(-5)    # 0.007
```

- **z = 0 → σ = 0.5** 가 분류 임계값의 기준. 보통 σ ≥ 0.5(즉 z ≥ 0)면 1로 예측 → [[의사결정경계]].
- σ(z) = P(y=1 | x). 이 확률에 임계값을 적용해 [[혼동행렬|예측 라벨]]을 만든다.

---

## 자주 헷갈리는 것

**z(로짓)와 σ(확률)은 다르다.** z는 로그오즈(−∞~+∞), σ(z)는 확률(0~1). [[오즈비]]의 log를 취한 것이 z이고, z를 시그모이드로 되돌리면 확률이다. 계수 β는 z 스케일에서의 기울기다.

---

## 더 알면 좋은 것

📌 시그모이드는 z=0 근처에서 가장 가파르고 양끝에서 평평(포화)해진다. 그래서 확률 0.5 부근의 작은 z 변화가 예측을 크게 흔든다. titanic 실습에서 확률→예측 변환(≥0.5→1)이 바로 이 곡선 위의 임계 판정이다. ⚠ 본 실습 노션 원문엔 시그모이드 정의식·확률 변환 코드가 없음 → 표준 개념 보강.
