# 인덱싱·슬라이싱 (Indexing·Slicing)

**정의**: 순서가 있는 자료(문자열·리스트)에서 **위치 번호로 원소를 꺼내는 법**. 한 개 꺼내기 = 인덱싱, 범위로 잘라내기 = 슬라이싱.

---

## 왜 필요한가

"세 번째 글자", "뒤에서 두 개", "앞 5개"처럼 데이터의 일부만 꺼내 쓸 일이 매우 많다. 문자열·리스트 어디서나 똑같은 규칙으로 동작해서, 한 번 익히면 계속 쓴다.

---

## 어떻게 작동하나

```
word = "Python"
        P  y  t  h  o  n
인덱스: 0  1  2  3  4  5     ← 앞에서 (0부터!)
       -6 -5 -4 -3 -2 -1     ← 뒤에서 (음수)
```

### 인덱싱 — 한 개 꺼내기

```python
word = "Python"
word[0]     # 'P'   첫 번째
word[2]     # 't'
word[-1]    # 'n'   맨 마지막
word[-2]    # 'o'   뒤에서 두 번째
```

### 슬라이싱 — 범위 꺼내기 `[시작:끝]`

**끝 번호는 포함하지 않는다.**

```python
word[1:4]   # 'yth'    인덱스 1,2,3 (4는 제외)
word[:3]    # 'Pyt'    처음부터 (시작 생략)
word[3:]    # 'hon'    끝까지 (끝 생략)
word[:]     # 'Python' 전체 복사
```

### 간격(step) · 역순

```python
nums = [0, 1, 2, 3, 4, 5, 6]
nums[::2]    # [0, 2, 4, 6]   2칸씩 건너뜀
nums[::-1]   # [6, 5, 4, 3, 2, 1, 0]  역순 (거꾸로)
word[::-1]   # 'nohtyP'       문자열 뒤집기
```

### 리스트도 똑같이

```python
scores = [90, 85, 78, 92, 88]
scores[1:3]   # [85, 78]
scores[-1]    # 88
scores[:2]    # [90, 85]
```

---

## 실제 예시

```python
# 이메일에서 아이디만 꺼내기
email = "alice@example.com"
email[:email.index("@")]    # 'alice'  (@ 앞까지)

# 마지막 점수
scores[-1]                  # 88

# 최근 3개만
recent = scores[-3:]        # [78, 92, 88]
```

---

## 자주 헷갈리는 것

**끝 번호 미포함**: `word[1:4]`는 1,2,3까지. 4는 안 들어간다. (개수 = 끝 − 시작)

**인덱스 범위 초과**: `word[100]` → `IndexError`. 하지만 슬라이싱 `word[100:]`은 에러 없이 빈 값 반환.

**문자열은 불변**: `word[0] = "J"` → `TypeError`. 문자열은 인덱스로 값을 바꿀 수 없다(리스트는 가능).

**음수 인덱스 0 없음**: 맨 뒤는 `-1`부터 시작 (`-0`은 그냥 0).

---

## 더 알면 좋은 것

📌 **슬라이스로 부분 교체(리스트)**: `nums[1:3] = [99]` 처럼 범위를 통째로 바꿀 수 있다.

📌 **`[::-1]` 관용구**: 문자열·리스트를 거꾸로 뒤집는 가장 흔한 방법. 회문(palindrome) 판별에 자주 씀.

📌 **복사 용도 `[:]`**: `b = a[:]`는 리스트를 **새로 복사** (`b = a`는 같은 리스트를 가리킴).
