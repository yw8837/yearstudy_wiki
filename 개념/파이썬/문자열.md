# 문자열 (String, str)

**정의**: 따옴표로 감싼 텍스트 자료형. 한 번 만들면 내용을 바꿀 수 없는 **불변(immutable)** 자료형.

---

## 왜 필요한가

이름·주소·메시지·CSV 한 줄 등 세상의 데이터 상당수가 텍스트다. 입력받기(`input`)·출력(`print`)·파일·API 응답이 전부 문자열로 오가므로, 문자열 다루기는 거의 모든 프로그램의 기본이다.

---

## 어떻게 작동하나

### 생성

```python
a = "큰따옴표"
b = '작은따옴표'      # 둘 다 OK
c = """여러 줄
문자열"""             # 삼중 따옴표 = 여러 줄
d = "3.14"            # 따옴표 안에 있으면 숫자처럼 보여도 문자열!
```

### 연산 (이어붙이기·반복)

```python
"안녕" + "하세요"     # '안녕하세요'
"하" * 3              # '하하하'
"파" in "파이썬"       # True
len("Python")         # 6
```

### 인덱싱·슬라이싱 → [[인덱싱슬라이싱]]

```python
s = "Python"
s[0]      # 'P'
s[1:4]    # 'yth'
s[::-1]   # 'nohtyP'
```

### 자주 쓰는 메서드

```python
"  Hi Python  ".strip()        # 'Hi Python'   앞뒤 공백 제거
"hello".upper()                # 'HELLO'
"HELLO".lower()                # 'hello'
"a,b,c".split(",")             # ['a', 'b', 'c']   문자열 → 리스트
"-".join(["a", "b", "c"])      # 'a-b-c'           리스트 → 문자열
"banana".count("a")            # 3
"banana".replace("a", "o")     # 'bonono'
"file.txt".startswith("file")  # True
```

### f-string (문자열 포매팅)

```python
name, score = "홍길동", 87.5
f"{name}님 점수: {score}점"     # '홍길동님 점수: 87.5점'
f"{score:.1f}"                  # '87.5'  소수점 1자리
f"{name:>10}"                   # 오른쪽 정렬 10칸
```

## 실제 예시

```python
# CSV 한 줄 파싱
line = "홍길동,25,서울"
name, age, city = line.split(",")    # 쪼개서 각 변수에

# 단어 리스트를 문장으로
words = ["파이썬", "정말", "재밌다"]
" ".join(words)                       # '파이썬 정말 재밌다'

# 숫자를 문자열과 합치기
age = 25
"나이: " + str(age)                   # '나이: 25'
```

## 자주 헷갈리는 것

**불변(immutable)**: `s[0] = "J"` → `TypeError`. 문자열은 일부만 못 바꾼다. 바꾸려면 새로 만든다: `"J" + s[1:]`.

**`split` ↔ `join` 방향**: `split`은 문자열→리스트, `join`은 리스트→문자열. `join`은 `"구분자".join(리스트)` 순서.

**문자열 + 숫자 → `TypeError`**: `"나이" + 25` 불가. `str(25)`로 변환 필요.

**메서드는 원본을 안 바꾼다**: `s.upper()`는 새 문자열을 **반환**할 뿐, `s` 자체는 그대로. `s = s.upper()`로 다시 담아야 한다.

## 더 알면 좋은 것

📌 **`find` vs `index`**: 둘 다 위치 찾기. 없을 때 `find`는 `-1` 반환, `index`는 에러.

📌 **이스케이프 문자**: `\n`(줄바꿈), `\t`(탭), `\\`(역슬래시), `\"`(따옴표).

📌 **`in`으로 포함 검사**: `"@" in email` — 특정 문자가 있는지 빠르게 확인.

📌 **대소문자 무시 비교**: `a.lower() == b.lower()` 로 대소문자 구분 없이 비교.
