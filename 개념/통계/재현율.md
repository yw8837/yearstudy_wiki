# 재현율 (Recall)

**정의**: **실제 1(양성) 중 1로 맞춘 비율**. `TP / (TP + FN)`. "진짜 생존자 중 내가 찾아낸 비율." 민감도(Sensitivity)·TPR과 같은 값.

---

## 왜 필요한가

**거짓 음성(FN, 놓침)의 비용이 클 때** 중요하다. 암 진단에서 환자를 놓치면(FN) 치명적이므로 재현율을 높여야 한다. "실제 양성을 얼마나 빠짐없이 잡았나"를 잰다.

---

## 어떻게 작동하나

```python
# titanic 실습: 손계산
recall = TP / (TP + FN) if (TP + FN) > 0 else 0
print(f"Recall:    {recall:.2%}  (of actual survivors, how many did we find)")
```

- 분모가 **실제 양성(TP+FN)** — 모델 예측과 무관한 "진짜 1의 총수".
- FN(놓친 양성)이 많을수록 재현율이 떨어진다.

---

## 자주 헷갈리는 것

**정밀도와 분모가 다르다.** [[정밀도]]는 예측 양성(TP+FP) 기준, 재현율은 실제 양성(TP+FN) 기준. 임계값을 낮춰 많이 1로 예측하면 재현율↑·정밀도↓(더 많이 잡지만 오탐도 늘어남).

---

## 더 알면 좋은 것

📌 재현율 100%는 "전부 1로 예측"으로 쉽게 달성되지만 그러면 정밀도가 폭락한다. 그래서 [[F1점수]]로 균형을 본다. 재현율=민감도=TPR(True Positive Rate)로, ROC 곡선의 y축이기도 하다(본 실습 범위 밖). ⚠ 노션 원문엔 실제 재현율 수치 없음.
