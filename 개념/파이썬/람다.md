# 람다 · map · filter

**정의**: **람다(lambda)** = 이름 없는 한 줄짜리 함수. `map`/`filter`/`sorted`의 기준 함수로 자주 쓰인다.

---

## 왜 필요한가

`sorted`의 정렬 기준, `map`의 변환 함수처럼 **한 번만 쓸 짧은 함수**를 매번 `def`로 만들기 번거롭다. 람다는 그 자리에서 함수를 간단히 표현한다.

---

## 어떻게 작동하나

### lambda
```python
square = lambda x: x ** 2     # def square(x): return x**2 와 동일
square(5)                     # 25
# 형식: lambda 매개변수: 반환식
```

### map — 각 요소에 함수 적용
```python
nums = [1, 2, 3, 4]
list(map(lambda x: x*2, nums))     # [2, 4, 6, 8]
```

### filter — 조건 맞는 것만
```python
list(filter(lambda x: x % 2 == 0, nums))   # [2, 4]
```

### sorted key로 활용
```python
sorted(members, key=lambda m: m["salary"], reverse=True)
```

---

## 실제 예시

```python
# 연봉 원→만원 변환
won = [65000000, 52000000]
list(map(lambda w: w // 10000, won))    # [6500, 5200]

# 5000 이상만
list(filter(lambda m: m["salary"] >= 5000, members))
```

---

## 자주 헷갈리는 것

**결과는 list()로 감싸야 보임**: `map`/`filter`는 객체를 반환 → `list()` 필요.

**lambda 한계**: 한 줄·단일 식만. 조건이 복잡하면 일반 `def` 함수가 가독성·재사용성↑.

**map vs 컴프리헨션**: `[x*2 for x in nums]`가 `list(map(lambda x:x*2, nums))`보다 보통 더 읽기 쉬움. → [[컴프리헨션]]

---

## 더 알면 좋은 것

📌 **`sorted`/`max`/`min`의 key**: 전부 `key=lambda ...`로 기준 지정 가능. → [[정렬]]

📌 **`functools.reduce`**: 누적 계산. `reduce(lambda a,b: a+b, nums)`.
