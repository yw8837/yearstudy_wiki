# 실무 문법 패턴 정리

실무에서 자주 쓰는 파이썬 심화 문법 6가지를 한눈에. 상세는 개념 링크에서.

> 강의 출처: [[0604-실무문법]] · 상세: [[컴프리헨션]] · [[람다]] · [[정렬]]

---

## 6가지 심화 문법

```python
# ① f-string
f"{val:.2f}"  f"{n:,}"  f"{r:.1%}"  f"{s:>7}"

# ② 컴프리헨션 → [[컴프리헨션]]
[x**2 for x in seq]
[x for x in seq if 조건]            # 필터(뒤)
[A if 조건 else B for x in seq]      # 변환(앞)

# ③ sorted → [[정렬]]
sorted(data, key=lambda m: m["salary"], reverse=True)
sorted(data, key=lambda m: (m["team"], -m["salary"]))   # 다중

# ④ enumerate
for i, v in enumerate(seq, start=1): ...

# ⑤ lambda · map · filter → [[람다]]
list(map(lambda x: x*2, nums))
list(filter(lambda x: x%2==0, nums))

# ⑥ __name__
if __name__ == "__main__": ...       # 직접 실행 시만
```
