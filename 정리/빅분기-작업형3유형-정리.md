# 빅분기 작업형 제3유형 정리 (통계적 가설검정)

빅데이터분석기사 실기 작업형 3유형 = **통계적 가설검정**. scipy/statsmodels로 상황에 맞는 검정을 골라 코드로 구현하는 치트시트.

> 강의 출처: [[0622-확률과통계적추론]] · 이론: [[가설검정-정리]] · 상세: [[t검정]] · [[카이제곱검정]] · [[분산분석]] · [[회귀분석]] · [[로지스틱회귀]]

## 0. 검정 선택 지도

```
[평균]  1집단 vs 값 ─▶ ttest_1samp
        2집단 독립 ─── 정규O·등분산O ─▶ ttest_ind(equal_var=True)
                    ├ 등분산X ─────────▶ ttest_ind(equal_var=False)=Welch
                    └ 정규X ───────────▶ mannwhitneyu (비모수)
        2집단 대응 ── 정규O ─▶ ttest_rel  / 정규X ─▶ wilcoxon
        3집단+ ─────────────▶ f_oneway → 기각 시 pairwise_tukeyhsd
[범주]  관측vs이론 ─▶ chisquare  /  두 범주 독립 ─▶ chi2_contingency
[관계]  두 연속 상관 ─▶ pearsonr  /  Y예측 ─▶ ols  /  이진Y ─▶ logit
```

**가정 진단:** ① [[정규성검정|정규성]](Shapiro, N≤30) → ② [[등분산검정|등분산]](Levene) → ③ 본 검정. **`p<0.05`면 H₀ 기각.**

---

## 1. t검정 3종 → [[t검정]]

```python
from scipy import stats
t, p = stats.ttest_1samp(df['x'], popmean=75)                  # 단일: μ=μ₀
lev_s, lev_p = stats.levene(a, b)                              # 등분산 먼저
t, p = stats.ttest_ind(a, b, equal_var=(lev_p >= 0.05))       # 독립(False=Welch)
t, p = stats.ttest_rel(post, pre, alternative='greater')      # 대응: μ_D=0
```

- **단일** = 한 집단 평균이 기준값과 같은가. **독립** = 다른 두 집단 평균 차. **대응** = 같은 대상 전후 차(쌍체).
- `alternative`: `'two-sided'`(양측)·`'greater'`·`'less'`(단측).

---

## 2. 정규성·등분산·비모수 → [[정규성검정]] · [[등분산검정]] · [[비모수검정]]

```python
stats.shapiro(x)                     # 정규성 H₀:정규분포 (소표본)
from statsmodels.stats.diagnostic import normal_ad
normal_ad(x)                         # Anderson-Darling (꼬리 민감, 극단값 탐지)
stats.levene(a, b)                   # 등분산 H₀:분산 같음
stats.mannwhitneyu(a, b)             # 독립·비정규 대체
stats.wilcoxon(after, before, alternative='greater')  # 대응·비정규 대체
```

- 정규성 위반 → Mann-Whitney(독립)/Wilcoxon(대응). 등분산 위반 → Welch.
- N≥30이면 [[중심극한정리|CLT]]로 정규성 가정 만족으로 봄.

## 3. 카이제곱·분산분석 → [[카이제곱검정]] · [[분산분석]]

```python
f, p = stats.chisquare(observed, f_exp=expected)      # 적합도
ct = pd.crosstab(df['A'], df['B'])
chi2, p, dof, exp = stats.chi2_contingency(ct)        # 독립성, df=(r-1)(c-1)
f, p = stats.f_oneway(g1, g2, g3)                     # ANOVA (3+ 집단)
from statsmodels.stats.multicomp import pairwise_tukeyhsd
tukey = pairwise_tukeyhsd(endog=df['y'], groups=df['grp'], alpha=0.05)  # 기각 시
```

- 카이제곱 독립성: **기대도수 ≥ 5** 조건(미만이면 Fisher Exact).
- ANOVA: 집단 간 분산 > 집단 내 분산이면 유의. 기각 시에만 Tukey HSD 사후검정.

## 4. 상관·회귀·로지스틱 → [[상관분석]] · [[회귀분석]] · [[로지스틱회귀]]

```python
import statsmodels.formula.api as smf
r, p = stats.pearsonr(df['x'], df['y'])               # 피어슨 상관
model = smf.ols("y ~ x1 + x2 + C(cat)", data=df).fit()   # 다중회귀
model.rsquared; model.rsquared_adj; model.pvalues      # R²·조정R²·유의성
model = smf.logit("y ~ x1 + x2", data=df).fit(disp=False)  # 로지스틱
prob = model.predict(df); y_pred = (prob >= 0.5).astype(int)
odds = np.exp(model.params["x1"])                      # 오즈비 exp(β)
```

- **[[회귀분석|회귀 진단 4가정]]:** 선형성·독립성(Durbin-Watson)·등분산성·정규성 — 잔차로 검증.
- **[[로지스틱회귀]] 지표:** [[오즈비]] `exp(β)` / 잔차이탈도 `-2·llf` / 정확도 / 오분류율 / AUC(`roc_auc_score`).
- **표준편차 vs 표준오차:** `s`(데이터 퍼짐) vs `S.E=s/√n`(표본평균 흔들림, n↑이면 감소).

## 6. 메서드 요약표
