# 의사결정 경계 (Decision Boundary)

**정의**: 분류 모델이 클래스를 **0과 1로 가르는 경계**. [[로지스틱회귀]]에서는 예측 확률 = 0.5(즉 [[시그모이드함수|시그모이드]] 입력 z = 0)가 되는 지점.

---

## 왜 필요한가

로지스틱 회귀는 확률(0~1)을 내놓지만, 최종 예측은 0/1 라벨이어야 한다. **어느 확률 이상을 1로 볼지**의 기준선이 필요하고 그게 의사결정 경계다. 기본값은 0.5.

---

## 어떻게 작동하나

```python
# 확률 → 라벨 변환 (임계값 0.5)
y_pred = (prob >= 0.5).astype(int)   # σ(z) >= 0.5  ⇔  z >= 0
```

- `z = β₀ + Σβᵢxᵢ = 0` 을 만족하는 특성 공간의 초평면이 경계.
- 임계값을 0.5에서 올리면(예 0.7) 1로 판정하는 조건이 엄격 → [[정밀도]]↑·[[재현율]]↓.

---

## 자주 헷갈리는 것

**경계는 확률 0.5지, 계수 0이 아니다.** 계수 β는 경계의 "기울기·방향"을 정하고, 경계 자체는 z=0(확률 0.5) 위치다. 임계값을 바꾸면 같은 모델이라도 경계가 이동해 [[혼동행렬]]이 달라진다.

---

## 더 알면 좋은 것

📌 임계값 0.5는 관례일 뿐 절대 기준이 아니다. 놓치면 안 되는 문제(재현율 중시)면 임계값을 낮추고, 오탐이 비싼 문제(정밀도 중시)면 높인다. ⚠ titanic 노션 원문엔 확률→예측(`y_pred`) 변환 코드 자체가 없어 임계값 적용은 표준 관례로 보강한 것 → [원문 확인 필요].
