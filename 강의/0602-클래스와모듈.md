# 06/02 · 클래스(OOP) · 모듈과 패키지

객체지향(클래스)으로 "IT 회사 팀원·부서"를 만들고, 코드를 모듈·패키지로 나눠 `import`하는 법.
한 줄 요약: **데이터+행동을 클래스로 묶고(캡슐화) → 물려받고(상속) → 같은 명령에 다르게 반응(다형성), 그리고 코드를 파일·폴더로 나눠 가져다 쓰기(모듈·패키지).**

## 수업 포인트

- **클래스 vs 인스턴스** = 설계도 vs 실제 물건. `TeamMember()`로 객체 생성
- **`self`** = 그 객체 자신. `alice.introduce()` → `self=alice` 자동 전달
- **클래스 변수**(공유) vs **인스턴스 변수**(각자) — `company_name` 바꾸면 전원 반영
- **`@classmethod`**(cls, 대체 생성자 `from_string`) vs **`@staticmethod`**(독립 유틸)
- **상속**: 공통은 부모(`Department`), 차이는 자식(`DevTeam`…). `super().__init__()`로 부모 초기화
- **다형성**: 여러 팀을 리스트에 담아 같은 `team_meeting()` 호출 → 팀마다 다른 결과
- **모듈/패키지**: 모듈=`.py` 파일, 패키지=모듈 담은 폴더. `import`·`from~import`·`as`·점(`.`) 경로
- 이전 ipynb 복습(지역/전역)에서 **Shadowing**·**`global`** 추가 확인 → [[함수]]에 보강

## 실무 문법 패턴 (심화 6가지)

실무에서 자주 쓰는 심화 문법. 상세는 [[컴프리헨션]] · [[람다]] · [[정렬]].

```python
# ① f-string:  f"{val:.2f}" f"{n:,}" f"{r:.1%}" f"{s:>7}"
# ② 컴프리헨션: [x for x in seq if 조건]  /  [A if 조건 else B for x in seq]
# ③ sorted:     sorted(data, key=lambda m: m["salary"], reverse=True)
# ④ enumerate:  for i, v in enumerate(seq, start=1): ...
# ⑤ lambda·map·filter:  list(map(lambda x: x*2, nums)) / filter(...)
# ⑥ __name__:   if __name__ == "__main__": ...   (직접 실행 시만)
```

> 정렬 다중 기준: `key=lambda m: (m["team"], -m["salary"])` / map·filter는 `list()`로 감싸기.

## 보충

📌 **isinstance() / issubclass()** *(예습 — 수업 미진행, 배운 뒤 보강)*: 객체의 타입·상속 관계 확인. `isinstance(dev, Department)`, `issubclass(DevTeam, Department)`.

📌 **매직 메서드**: `__init__`·`__str__`·`__repr__`·`__len__`·`__eq__` 등 파이썬이 자동 호출하는 `__이름__`.

📌 **`if __name__ == "__main__":`**: 모듈을 직접 실행할 때만 동작, import 시엔 안 돌아감.

📌 **심화 문법**(실무 추가 문법 패턴)은 이날 시간상 미진행 → 추후 정리 예정.
