# uv

**정의**: Rust로 만든 **빠른 파이썬 패키지·프로젝트 매니저**. 기존의 `pip`(패키지 설치) + `venv`(가상환경) + 버전관리를 하나로 합친 도구.

> 설치·세팅 전체 순서는 → [[개발환경-설정]]

---

## 왜 필요한가

프로젝트마다 필요한 라이브러리·버전이 다르다. 직접 `pip`+`venv`로 관리하면 번거롭고 느리다. uv는 **가상환경 생성·의존성 설치를 자동으로, 매우 빠르게** 처리한다. 또 `uv.lock`으로 **누구나 똑같은 환경**을 재현할 수 있다.

---

## 어떻게 작동하나

```bash
uv --version          # 설치 확인
uv sync               # pyproject.toml·uv.lock 기준으로 패키지 설치 (.venv 생성)
uv run python a.py    # 가상환경 안에서 실행 (활성화 불필요)
uv run jupyter lab    # 주피터랩 실행
uv add pandas         # 패키지 추가
```

- **`.venv`**: uv가 만드는 프로젝트 전용 가상환경 폴더
- **`pyproject.toml`**: 필요한 패키지 목록 / **`uv.lock`**: 정확한 버전 고정

---

## 실제 예시

```bash
# 강의 프로젝트 세팅
uv sync                       # 패키지 설치
uv run python check_env.py    # 환경 확인
uv run jupyter lab            # 실습 시작
```

---

## 자주 헷갈리는 것

**`uv run`을 쓰면 가상환경을 안 켜도 된다**: `source .venv/bin/activate` 없이 `uv run`이 알아서 가상환경에서 실행.

**Windows 보안 차단(`os error 4551`)**: `uv run`이 막히면 Windows 보안 "앱 및 브라우저 컨트롤"을 잠시 해제. → [[개발환경-설정]]

---

## 더 알면 좋은 것

📌 **왜 빠른가**: Rust로 작성 + 병렬 다운로드 + 캐시 활용으로 pip보다 수십 배 빠를 때도 있다.

📌 **`uv add` vs `uv sync`**: `add`는 새 패키지를 추가하며 lock 갱신, `sync`는 lock대로 설치(재현).
