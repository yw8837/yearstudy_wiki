# 데이터 리터러시 기초 정리

데이터를 **읽고·해석하고·비판적으로 다루는 능력**. 6/17 4주차 첫 회차(데이터 분석 커리큘럼 전환)의 전반부를 섹션별로 한눈에.

## 1. 데이터의 유형 → [[정형데이터]] · [[비정형데이터]] · [[반정형데이터]]

| 유형 | 구조 | 예 |
|:---|:---|:---|
| [[정형데이터]] | 행·열(엑셀/DB) | 매출표·센서값 → 통계·ML 주 적용 |
| [[비정형데이터]] | 구조 없음 | 텍스트·이미지·오디오·영상 |
| [[반정형데이터]] | 일부 구조 | JSON·딕셔너리 |

- 통계·ML 기법은 주로 **정형 데이터**에 적용. 비정형은 별도 기법이 필요하고 업계 수요가 커지는 중.

## 2. 변수의 척도 → [[척도]]

🔑 **변수의 척도에 따라 통계 분석 방법이 달라진다.**

| 척도 | 특징 | 절대영점 | 예 |
|:---|:---|:---:|:---|
| [[명목척도]] | 분류·이름표(순서 없음) | — | 성별·혈액형 |
| [[서열척도]] | 순서 있음, 간격 불균등 | — | 만족도·학점 |
| [[등간척도]] | 간격 동일 | ❌ | 온도(℃)·연도 |
| [[비율척도]] | 간격 동일 + 비율 계산 | ✅ | 키·몸무게·나이 |

- 등간↔비율 갈림은 **절대영점**(0이 "없음"인가). 0℃는 온도 없음이 아니므로 "2배" 진술 불가.
- 라이브 "명목/서열/등간/비율" = ADsP "명목/순서/구간/비율"(동일 개념, 동의어).

## 3. 양질의 데이터 → [[양질의데이터]]

```python
# 비유: 저품질 → 활용 데이터 → 고품질 으로 갈수록 비용 급증 (다이아몬드 가공)
```

- 고품질 데이터는 **희소·고비용**. 검증 안 된 자료는 분석 신뢰도·ML 정확도를 떨어뜨린다.
- **[[딥러닝]]("양이 깡패") vs [[머신러닝]](양보다 양질/정제)** — 무작정 많은 데이터는 효용이 낮을 수 있다.
- 데이터 엔지니어 = 수집→처리→양질 데이터(자동화 파이프라인).

---

## 4. 신뢰할 수 있는 데이터 → [[편향과대표성]] · [[결측치]]

- **3대 리스크:** 데이터 자체 오류 / 분석가 임의 보정 / **표본 [[편향과대표성|편향]]**(대표성 부족).
- **[[결측치]] 처리:** 정답 없음 → **비교 실험으로 선택**. 표준 분류 = 삭제 / 단순대치(평균·중앙값·최빈값) / 회귀대치 / 다중대치(MICE) / KNN.
- 설문은 회피·거짓·무성의 응답 가능 → 100% 진실 전제 금지.

---

## 5. 데이터 리터러시 핵심 → [[상관관계와인과관계]] · [[DIKW]] · [[데이터마이닝]]

- **[[상관관계와인과관계|상관 vs 인과]]:** 함께 변함(상관) ≠ 원인-결과(인과). 아이스크림↔모기 판매는 둘 다 "여름"이 원인.
- **[[DIKW]]:** Data → Information → Knowledge → Wisdom. "패턴 발견"이 핵심.
- **[[데이터마이닝]]:** 데이터에서 의미 있는 인사이트(패턴) 추출.
- **[[데이터커뮤니케이션]]:** 영점·축·표본을 체크리스트로 검증, 대상별 맞춤 리포트.
- **[[RAW데이터]]:** 분석엔 집계 데이터보다 가공 전 원자료(RAW)가 유리.

---

## 6. 정규화(DBA) vs 분석용 비정규화

- DB [[정규화]]는 DBA 역할. 분석가는 운영 DB를 **조인·가공해 분석용 비정규화 테이블**을 만든다.
- 분석의 "가공"(1·2·3차)은 DB 정규화와 별개 — 분석 목적 데이터셋 생성(조인·결측 처리)에 가깝다.
