# 반정형 데이터 (Semi-structured Data)

**정의**: 행·열 표는 아니지만 **일부 구조(키-값·태그)를 가진** 데이터. JSON·XML·딕셔너리 형태.

---

## 왜 필요한가

API 응답·로그·설정 파일은 대부분 JSON 같은 반정형이다. 완전한 표는 아니지만 **키로 값을 찾을 수 있어** 파싱해서 [[정형데이터]]로 펴낼 수 있다.

---

## 어떻게 작동하나

```json
{ "user": "A", "age": 25, "tags": ["vip", "active"] }
```

- 스키마가 느슨하지만 **키-값 구조**가 있어 추출·평탄화(flatten) 가능.
- 파이썬 [[딕셔너리]]가 대표적 — JSON ↔ dict 변환이 자연스럽다.

---

## 실제 예시

- REST API JSON 응답, NoSQL([[NoSQL]]) 문서, 웹 로그.

---

## 자주 헷갈리는 것

**반정형은 정형과 비정형의 중간.** 표는 아니지만 구조가 있어, 텍스트·이미지 같은 순수 [[비정형데이터]]보다 가공이 쉽다.
