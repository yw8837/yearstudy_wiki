# 연관 서브쿼리 / 비연관 서브쿼리

**정의**: [[서브쿼리]]를 **동작 방식**으로 나눈 분류. **연관(Correlated)** = 서브쿼리가 메인쿼리의 컬럼을 참조 → 메인쿼리 **행마다 재실행**. **비연관(Un-correlated)** = 메인쿼리와 무관 → **한 번만** 실행해 값을 제공.

---

## 왜 필요한가

"비교 기준이 행마다 다른가, 하나로 고정인가"를 구분하는 개념. **본인 부서 평균보다 높은 직원**은 부서마다 평균이 달라지니 연관, **회사 전체 평균보다 높은 직원**은 평균이 하나로 고정이니 비연관.

---

## 어떻게 작동하나

```sql
-- 연관 : 서브쿼리가 메인쿼리 A를 참조 → 행마다 평균 재계산
SELECT NAME, SALARY FROM EMPLOYEE A
WHERE SALARY > (SELECT AVG(SALARY) FROM EMPLOYEE B
                WHERE B.DEPARTMENT_ID = A.DEPARTMENT_ID);

-- 비연관 : 서브쿼리가 독립 → 한 번만 실행
SELECT NAME, SALARY FROM EMPLOYEE
WHERE SALARY > (SELECT AVG(SALARY) FROM EMPLOYEE);
```

| 구분 | 메인 컬럼 참조 | 실행 | 단독 실행 |
|:---|:---:|:---|:---:|
| 연관 | O | 행마다 재실행 | **불가**(메인 컬럼 필요) |
| 비연관 | X | 1회 | 가능 |

---

## 실제 예시

- 연관(chinook): 앨범 평균 재생시간 초과 트랙 — `WHERE t2.AlbumId = t.AlbumId`로 메인 행 참조.
- 비연관(chinook): 전체 평균 단가 초과 트랙 — `WHERE UnitPrice > (SELECT AVG(UnitPrice) FROM tracks)`.

---

## 자주 헷갈리는 것

**연관 서브쿼리는 단독 실행 불가**: 메인쿼리의 컬럼(`A.DEPARTMENT_ID`)을 참조하므로 떼어내 실행하면 "그 컬럼 없음" 오류. 비연관은 따로 실행해 결과 확인 가능 → "분할·실행·합치기" 학습법은 비연관에서 특히 유효.

**[[EXISTS]]·[[스칼라서브쿼리]]는 보통 연관**, [[IN연산자\|IN]]은 보통 비연관. 단 같은 결과를 내는 경우가 많다.

---

## 더 알면 좋은 것

📌 연관 서브쿼리는 행마다 재실행되어 대량 데이터에서 느릴 수 있다. 종종 JOIN으로 바꿔 최적화한다(결과는 같게).
