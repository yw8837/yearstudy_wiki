# 이항분포 (Binomial Distribution)

**정의**: 성공확률 p가 동일한 베르누이 시행을 **독립적으로 n번** 반복했을 때 성공 횟수 X의 분포. `X ~ B(n,p)`, `P(X=x)=ₙCₓ pˣ(1-p)^(n-x)`, x=0…n.

---

## 왜 필요한가

"n번 중 k번 성공" 유형(불량품 수, 합격 인원, 앞면 횟수)을 모형화한다. [[이항검정]]의 기반 분포.

---

## 어떻게 작동하나

```python
from scipy import stats
import numpy as np
stat = stats.binom(n, p)
stat.pmf(x); stat.cdf(x)
np.random.binomial(n, p, size)
```

- 베르누이(1회 성공/실패)를 n번 독립 반복 → 합이 이항.

---

## 자주 헷갈리는 것

**복원 vs 비복원.** 이항은 각 시행이 독립(복원추출 상황). **비복원**(모집단 유한, 뽑을수록 확률 변함)이면 [[초기하분포]]를 쓴다.

---

## 더 알면 좋은 것

📌 n이 크고 p가 작으면 λ=np인 [[포아송분포]]로 근사. n이 크면 [[정규분포]]로도 근사([[중심극한정리|CLT]]).
