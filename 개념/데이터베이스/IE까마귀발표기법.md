# IE / 까마귀발 표기법 (Crow's Foot)

**정의**: [[ERD]]를 그리는 실무 표준 표기법. 개체를 **박스(안에 컬럼 목록)** 로, 관계를 **선 끝 기호**로 나타낸다. 선 끝이 까마귀 발처럼 갈라져 "Crow's Foot".

---

## 왜 필요한가

속성을 박스 안에 넣어 도식이 간결하고, 관계선 끝 기호 하나로 "몇 대 몇 + 필수/선택"을 동시에 읽을 수 있어 실무 ERD에서 널리 쓰인다.

---

## 어떻게 작동하나

박스 안에 PK 구분선을 두고, 관계선 끝 기호로 카디널리티를 읽는다. **바깥=최대 수, 안쪽=최소 수.**

| 기호 | 의미 |
|:---|:---|
| `┼` (`|`) | 하나(one) |
| `○` | 영(0, 선택) |
| `<` (까마귀발) | 다수(many, N) |

조합: `0..1`, `1..N`, `0..N` 등.

```
SSN ─○┤ Has ├─ Student      학생은 SSN 0 또는 1개(선택), SSN은 학생 하나에 귀속
Student >──< Attends ──< Class   학생-수업 다대다(N:M)
```

---

## 실제 예시

- 선생님(PK 직원번호, 이름 NOT NULL) ↔ 학생(PK 학번, 이름 NOT NULL)을 IE 박스로 표기.
- 노션: 한쪽 `|` + 반대쪽 `<` = 일대다(1:N).

---

## 자주 헷갈리는 것

**기호 두 자리를 함께 읽어야 한다.** 안쪽(최소: `┤`필수 or `○`선택) + 바깥(최대: `|`하나 or `<`다수). `O<` = 0 또는 다수 → **1:N에서 가장 흔함**.

**IE vs [[PeterChen표기법]].** IE는 속성을 박스 안에 넣고, Chen은 타원으로 따로 그린다.
