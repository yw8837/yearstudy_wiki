## 01. 자료형 (Data Type)

컴퓨터는 숫자 `3`과 문자 `"3"`을 완전히 다르게 처리한다. 자료형이 이 차이를 결정한다.

| 자료형 | 표기 | 예시 | 특징 |
|:---|:---:|:---|:---|
| 정수 | `int` | `25`, `-100` | 소수점 없는 숫자 |
| 실수 | `float` | `3.14`, `175.5` | 소수점 있는 숫자 |
| 문자열 | `str` | `"안녕"`, `'Python'` | 따옴표로 감쌈 |
| 리스트 | `list` | `[1, 2, 3]` | 여러 값 순서대로 |
| 불리언 | `bool` | `True`, `False` | 참/거짓만 |

```python
print(type(42))        # <class 'int'>
print(type("안녕"))    # <class 'str'>
print(type([1,2,3]))   # <class 'list'>
```

**형 변환 (Type Casting)**:

```python
int("42")           # 42     — 문자 → 정수
float("3.14")       # 3.14   — 문자 → 실수
str(100)            # "100"  — 정수 → 문자
int(float("3.14"))  # 3      — 소수 문자는 float 먼저, 그 다음 int

# ⚠️ input()은 항상 str 반환
age = input("나이: ")       # "25" (문자열!)
birth = 2026 - int(age)    # int 변환 후 계산
```

## 02. 변수와 연산자

`=`는 "오른쪽 값을 왼쪽 이름에 저장". 수학의 "같다"가 아님.

```python
name = "홍길동"
age = 25
age += 1          # age = age + 1 의 축약 (= 26)
```

**변수 이름 규칙**: 영문·숫자·_ 만 가능, 숫자 시작 불가, 예약어(`if`, `for`) 사용 불가.
파이썬 관례: **스네이크 표기법** (`student_name`, `total_score`)

> ⚠️ **덮어쓰기 주의**: 같은 변수명에 다시 대입하면 기존 값이 사라진다. `a`, `b`, `c`처럼 모호한 이름을 쓰면 의미를 잃고, 코드가 커질수록 추적이 어렵다. 예를 들어 `기준금리` 같은 중요한 값이 실수로 덮어써지면 그걸 쓰는 모든 계산이 틀어진다 → **의미가 드러나는 변수명**이 그래서 중요하다.

**기본 연산자**:

```python
10 + 3    # 13
10 - 3    # 7
10 * 3    # 30
10 / 3    # 3.3333...  (나눗셈은 항상 float)
10 // 3   # 3   (몫 — 소수점 버림)
10 % 3    # 1   (나머지)
2 ** 8    # 256 (거듭제곱)
```

**`%`(나머지) 활용 — 홀짝 판별**:
```python
num = 7
print(num % 2)   # 1 → 홀수 (0이면 짝수)
```

**문자열 연산**:
```python
"안녕" + "하세요"    # "안녕하세요" (이어 붙이기)
"파이썬! " * 3       # "파이썬! 파이썬! 파이썬! " (반복)

# ⚠️ 숫자 + 문자열은 에러!
age = 25
print(str(age) + "살")    # "25살" ✅
print(f"나이: {age}살")   # f-string 방식 (더 깔끔)
```

## 03. 인덱싱과 슬라이싱

파이썬은 순서를 **0부터** 센다.

```
"Python"
  P  y  t  h  o  n
  0  1  2  3  4  5   ← 앞에서
 -6 -5 -4 -3 -2 -1   ← 뒤에서
```

```python
word = "Python"
print(word[0])     # P   (첫 번째)
print(word[-1])    # n   (마지막)
print(word[-2])    # o   (뒤에서 두 번째)

# 슬라이싱 [시작:끝] — 끝 번호는 포함 안 됨
beta = "abcdefg"
print(beta[2:5])   # cde  (인덱스 2, 3, 4)
print(beta[:3])    # abc  (처음~인덱스2)
print(beta[4:])    # efg  (인덱스4~끝)
print(beta[::-1])  # gfedcba (역순)
```

리스트도 동일하게 적용:
```python
scores = [90, 85, 78, 92, 88]
print(scores[0])    # 90
print(scores[-1])   # 88
print(scores[1:4])  # [85, 78, 92]
```

**중첩 리스트**: 리스트 안에 리스트가 있으면 `[i][j]`로 단계적으로 접근.
```python
people = [["홍길동", 25, "AI"], ["김철수", 30, "DB"]]
print(people[0][0])   # 홍길동
print(people[1][2])   # DB
```

## 04. 조건문

```python
if 조건:          # True면 실행
    코드
elif 다른조건:    # 앞이 False이고 이게 True면
    코드
else:             # 모두 False면
    코드
```

> 💡 **학습 팁**: 문법보다 *"언제 조건문이 필요한지 판단"*하는 게 먼저다. 조건은 **한글로 먼저 설계**하고("점수가 90 이상이면 A"), 그다음 논리연산자로 옮기면 헷갈리지 않는다.

**비교 연산자**: `==`(같다), `!=`(다르다), `>`, `<`, `>=`, `<=`
> ⚠️ `=`(대입) ≠ `==`(비교). 조건문에서 `=` 쓰면 오류.

**논리 연산자**: `and`(둘 다 True), `or`(하나라도 True), `not`(반전)

**실습 예시**:

```python
# BMI 계산기
weight = float(input("몸무게(kg): "))
height = float(input("키(m): "))
bmi = weight / (height ** 2)
print(f"BMI: {bmi:.1f}")

if bmi < 18.5:
    print("저체중")
elif bmi < 23:
    print("정상")
elif bmi < 25:
    print("과체중")
else:
    print("비만")

# 계절 판별 (in 연산자 활용)
month = int(input("월: "))
if month in [3, 4, 5]:
    print("봄")
elif month in [6, 7, 8]:
    print("여름")
elif month in [9, 10, 11]:
    print("가을")
else:
    print("겨울")
```

## 05. 리스트

```python
fruits = ["사과", "바나나", "체리"]

# 추가·수정·삭제
fruits.append("딸기")         # 끝에 하나 추가
fruits.extend(["수박", "감"]) # 여러 개를 펼쳐서 추가 (반복문에서 자주 씀)
fruits.insert(0, "포도")      # 0번 위치에 삽입
fruits.remove("바나나")       # 값으로 삭제 (없으면 ValueError, 중복이면 첫 번째만)
last = fruits.pop()           # 마지막 삭제 후 반환

# 정렬
numbers = [5, 2, 8, 1, 9]
numbers.sort()                # 오름차순 (원본 변경, 반환값 None!)
numbers.sort(reverse=True)    # 내림차순
sorted_nums = sorted(numbers) # 새 리스트 반환 (원본 유지)

# 검색
print(len(fruits))            # 길이
print("사과" in fruits)       # True/False
print(fruits.index("체리"))   # 인덱스 반환
print(fruits.count("사과"))   # 등장 횟수
```

> ⚠️ **`append` vs `extend`**: `append([1,2])`는 리스트 자체를 통째로 한 칸에 넣고, `extend([1,2])`는 각 항목을 풀어서 이어 붙인다.

> ⚠️ **`sort()` 함정**: 반환값이 None. `result = my_list.sort()`하면 result가 None이 됨.

**리스트 복사 주의**:
```python
a = [1, 2, 3]
b = a             # 복사 아님! 같은 리스트를 가리킴
b.append(4)
print(a)          # [1, 2, 3, 4] ← a도 변경됨!

b = a.copy()      # 진짜 복사
```

## 06. 실습 — 수업에서 만든 것들

**홀짝 판별기**:
```python
num = int(input("정수: "))
print("짝수" if num % 2 == 0 else "홀수")
```

**성적 등급 계산기**:
```python
score = int(input("점수: "))
if score >= 90: grade = "A"
elif score >= 80: grade = "B"
elif score >= 70: grade = "C"
elif score >= 60: grade = "D"
else: grade = "F"
print(f"학점: {grade}")
```

**장바구니 관리**:
```python
cart = ["라면", "계란", "우유"]
cart.append("빵")
cart.insert(0, "쌀")
cart.remove("계란")
cart.sort()
print(f"장바구니: {cart}")
print(f"총 {len(cart)}개")
```

**숫자 맞히기 게임** (while·random 미리보기):
```python
import random
answer = random.randint(1, 100)
while True:
    guess = int(input("숫자: "))
    if guess < answer: print("UP!")
    elif guess > answer: print("DOWN!")
    else:
        print("정답!")
        break
```

## 보충

📌 **f-string**: `f"나이는 {age}살"` — 문자열 안에 변수 삽입. Python 3.6+ 표준. `"나이는 " + str(age) + "살"` 보다 훨씬 깔끔.

📌 **`in` 연산자**: 리스트·문자열 포함 여부. `"파" in "파이썬"` → True. 조건문과 궁합 최고.

📌 **`enumerate()`**: for문에서 인덱스 + 값 동시에 꺼내기. `for i, item in enumerate(list):`

📌 **`AttributeError`**: "그 자료형엔 그 메서드가 없다"는 뜻. 예: `"abc".append("d")` → 문자열엔 `append`가 없어 AttributeError. 메서드 이름 대소문자를 틀려도(`Append` ≠ `append`) 같은 에러. → 그 객체의 자료형이 무엇인지, 그 자료형에 그 메서드가 있는지 공식 문서에서 확인하면 풀린다.

## 🧭 학습 태도 — 강사 강조 (이날의 핵심)

문법 암기보다 **"어떻게 막히고, 어떻게 푸는지"**가 더 중요하다고 반복 강조한 날.

- **에러는 정상 과정.** 막히는 건 당연하고, 핵심은 **에러 메시지를 읽고 해석하는 능력**. 메시지를 기록·정리해두면 다음에 같은 에러가 빨라진다.
- **AI에 에러 물어볼 땐 양식이 있다.** 막연히 "안 돼요"가 아니라 **작성한 코드 + 에러 메시지 + 상황 설명**을 같이 준다. 받은 답은 그대로 붙여넣지 말고 **핵심만 불릿으로 다시 정리**해 노트에 남긴다.
- **자동완성에 의존하지 않기.** 수업 기간엔 코드 자동 생성/자동완성은 끄고, **직접 타이핑**하며 흐름을 이해한다. AI는 에러 원인 파악이 막힐 때 보조로만.
- **공식 문서로 교차검증.** AI 답은 틀릴 수 있으니 공식 문서로 확인하는 습관. (예: `sort(reverse=True)` 같은 매개변수는 문서에서 직접 확인)
- **반복은 자동화 신호.** 구구단을 손으로 다 치다 보면 "왜 반복하지?"라는 질문이 나온다 — 이 감각이 다음 시간 **반복문([[반복문]])**으로 이어진다.
