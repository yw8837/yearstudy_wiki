# 06/04 · 실무 문법 패턴

기초 문법 위에, 실무에서 코드를 **짧고 깔끔하게** 쓰는 6가지 패턴. 한 줄 요약: **f-string으로 출력하고, 컴프리헨션으로 반복을 한 줄로 줄이고, sorted·enumerate·lambda로 데이터를 자유롭게 다룬다.**

---

## 01. f-string 포매팅

문자열 앞 `f` + `{ }` 안에 변수·식. (Python 3.6+)

```python
name, salary = "Alice", 6500
print(f"{name}님 연봉: {salary}만원")   # Alice님 연봉: 6500만원
print(f"{15 + 4}")                      # 식도 가능 → 19
```

**숫자 포맷** (표·로그 출력에 유용):

| 형식 | 의미 | 예 |
|:---|:---|:---|
| `:.2f` | 소수점 2자리 | `3.14` |
| `:,` | 천 단위 콤마 | `1,234,567` |
| `:.1%` | 퍼센트 | `12.3%` |
| `:>7` | 오른쪽 정렬 7칸 | `   INFO` |

## 02. 리스트 컴프리헨션

`for` 반복을 **한 줄로** 압축.

```python
[i**2 for i in range(1, 6)]            # [1,4,9,16,25]  기본
[i for i in range(10) if i % 2 == 0]   # [0,2,4,6,8]    필터(if 뒤)
["합격" if s>=60 else "불합격" for s in [80,50]]  # if-else(앞)
```

> ⚠️ **필터 if는 뒤**(`for ... if 조건`), **if-else는 앞**(`A if 조건 else B for ...`). 위치 다름!

```python
raw = [' Python ', 'SQL', ' ', '']
[s.strip() for s in raw if s.strip()]  # ['Python','SQL']  전처리 실무 예
```

## 03. sorted — 정렬

| | 원본 | 반환 |
|:---|:---|:---|
| `list.sort()` | 변경됨 | None |
| `sorted(list)` | 유지 | 정렬된 새 리스트 |

```python
sorted([85,92,78], reverse=True)              # [92,85,78]  내림차순
sorted(words, key=len)                         # 글자 수 순
sorted(members, key=lambda m: m["salary"])     # 연봉 순 (key=기준)
sorted(members, key=lambda m: (m["team"], -m["salary"]))  # 다중 기준
```

> `key=lambda ...` = "무엇을 기준으로 정렬할지". 튜플 `(기준1, 기준2)`로 다중 정렬.

## 04. enumerate — 인덱스 + 값

```python
for i, x in enumerate(["봄","여름"]):       # 0 봄 / 1 여름
    print(i, x)
for rank, t in enumerate(teams, start=1):   # 1번부터 (순위)
    print(rank, t)
```

> `range(len(...))` 대신 `enumerate`가 훨씬 깔끔. `start=1`로 시작 번호 지정.

## 05. lambda · map · filter

**lambda** = 이름 없는 한 줄 함수.

```python
square = lambda x: x**2          # def square(x): return x**2 와 동일
list(map(lambda x: x*2, nums))   # 각 요소에 적용 → [2,4,6,...]
list(filter(lambda x: x%2==0, nums))  # 조건 맞는 것만 → 짝수
```

> `map`/`filter` 결과는 `list()`로 감싸야 보임. 복잡하면 lambda 말고 `def`가 가독성↑.

## 06. `if __name__ == "__main__":`

파일을 **직접 실행할 때만** 동작, `import`되면 안 돌아감. 정의 코드와 실행 코드를 분리.

```python
def add(a, b): return a + b

if __name__ == "__main__":   # 직접 실행 시에만
    print(add(3, 4))
```

## 보충

📌 **딕셔너리 컴프리헨션**: `{m["name"]: m["salary"] for m in members}` — 리스트뿐 아니라 딕셔너리도 한 줄로.

📌 **map vs 컴프리헨션**: 같은 일을 둘 다 가능. 보통 **컴프리헨션이 더 읽기 쉬워** 선호. `[x*2 for x in nums]` ⟵ `list(map(lambda x:x*2, nums))`.

📌 **`sys.exit()`**: 프로그램 종료(0=정상). 주피터에선 커널이 죽으니 `.py`에서만.
