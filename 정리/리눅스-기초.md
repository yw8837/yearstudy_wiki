# 리눅스 기초 정리

리눅스 터미널 기본 명령어를 **섹션별로 한눈에** 보는 요약본. 자세한 설명은 개념 페이지에서.

> 강의 출처: [[0527-운영체제와리눅스]] · 상세: [[리눅스]]
> 핵심 비유: 윈도우에서 **마우스로 클릭하던 일**을 **키보드로 타자 쳐서** 하는 것.

---

## 0. 경로(Path) 기호

| 기호 | 뜻 |
|:---:|:---|
| `/` | 최상위 폴더(뿌리) |
| `~` | 내 홈 폴더 |
| `.` | 현재 폴더 |
| `..` | 상위 폴더 |

- **절대 경로**: `/home/user/Desktop` (뿌리부터) / **상대 경로**: `../Desktop` (현재 기준)

---

## 1. 위치 확인·이동

```bash
pwd              # 현재 위치(절대 경로) 출력
ls               # 파일·폴더 목록
ls -al           # 숨김파일(-a) + 상세정보(-l)
cd ~/Desktop     # 폴더 이동
cd ..            # 상위 폴더로
cd ~             # 홈으로
```

---

## 2. 폴더 만들기

```bash
mkdir myfolder        # 폴더 생성
mkdir -p a/b/c        # 중첩 폴더 한 번에
```

---

## 3. 파일 만들기·내용 보기

```bash
touch hello.txt              # 빈 파일 생성
echo "hi" > hello.txt        # 내용 덮어쓰기 (기존 삭제!)
echo "hi" >> hello.txt       # 내용 이어쓰기 (안전)
cat hello.txt                # 전체 내용 출력
head -n 5 hello.txt          # 앞 5줄
tail hello.txt               # 마지막 10줄
tail -f app.log              # 실시간 모니터링 (로그)
```

> ⚠️ `>`(덮어쓰기) vs `>>`(이어쓰기) — 가급적 `>>` 사용

**vi 편집기** (터미널 속 메모장): `i` 삽입 / `ESC` 일반모드 / `:wq` 저장후종료 / `:q!` 강제종료

---

## 4. 복사·이동·삭제

```bash
cp a.txt b.txt          # 파일 복사
cp -r src/ src_bak      # 폴더 복사 (-r 필수)
mv a.txt archive/       # 이동
mv a.txt b.txt          # 이름 변경 (같은 위치)
rm hello.txt            # 파일 삭제 (휴지통 없음!)
rm -r archive           # 폴더 삭제
rm -rf 폴더             # 강제 삭제 ← 매우 주의 (rm -rf / 절대 금지)
```

---

## 5. 권한 (Permission)

```bash
ls -al
# -rw-r--r--   →  파일(-), 소유자 rw-, 그룹 r--, 기타 r--
# drwxr-xr-x   →  폴더(d), ...
chmod 755 script.sh     # rwxr-xr-x
chmod 644 index.html    # rw-r--r--
```

- 권한 문자: `r`(읽기=4) `w`(쓰기=2) `x`(실행=1) → 7=rwx, 6=rw-, 5=r-x
- 맨 앞 `d`=폴더, `-`=파일 / 세 칸씩 소유자·그룹·기타

---

## 6. 검색 — `grep`

```bash
grep "linux" a.txt      # 단어 포함 줄 찾기 (문서 내 Ctrl+F)
grep -i "linux" a.txt   # 대소문자 무시
grep -n "error" a.txt   # 줄 번호 포함
grep -r "linux" .       # 현재 폴더 전체 재귀 검색
```

---

## 7. 파이프 `|` — 명령어 연결

```bash
ls | grep "txt"             # ls 결과 중 txt만
ps -aux | grep python       # 프로세스 중 python만
history | grep "cd"         # 명령 이력 중 cd만
```

> 앞 명령의 **출력**을 뒤 명령의 **입력**으로 (레고처럼 이어붙임)

---

## 8. 프로세스

```bash
ps -aux          # 전체 프로세스 목록
top              # 실시간 모니터링
kill -9 1234     # PID 1234 강제 종료
```

→ 상세: [[프로세스]]

---

## 9. 도움말 & 관리자 권한

```bash
ls --help        # 빠른 사용법
man ls           # 공식 설명서 (q로 종료)
sudo apt install 패키지   # 관리자(root) 권한 실행
```

> `Permission denied` 뜨면 앞에 `sudo`. 단, 강력하니 꼭 필요할 때만.

## 10. 🎁 터미널 꿀팁

| 키 | 동작 |
|:---:|:---|
| `Tab` | 파일·폴더명 자동완성 |
| `↑` `↓` | 이전 명령어 불러오기 |
| `history` | 입력한 명령 전체 이력 |
| `Ctrl + L` | 화면 청소 (= `clear`) |

## 더 알면 좋은 것

📌 **패키지 관리자**: Ubuntu `apt`, CentOS `yum`/`dnf`, macOS `brew`
📌 **cron**: `crontab -e` 로 예약 작업 (`0 9 * * 1` = 매주 월 9시)
📌 **SSH**: `ssh user@서버IP` 원격 접속
📌 [explainshell.com](https://explainshell.com/) — 명령어 붙여넣으면 옵션 설명
📌 **VS Code PATH 등록**: 터미널에서 `code .`가 `command not found`로 안 되면, VS Code를 PATH 환경변수에 등록해야 한다(명령 팔레트 → "Shell Command: Install 'code' command in PATH"). Windows/macOS 절차가 다름. → [[VSCode]]
