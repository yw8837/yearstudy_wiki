# 마크다운 (Markdown)

**정의**: 간단한 기호(`#`, `*`, `-` 등)만으로 서식 있는 문서를 작성하는 **경량 마크업 언어**. 확장자는 `.md`.

---

## 왜 필요한가

글에 제목·굵게·목록·링크 같은 서식을 넣으려면 원래 HTML 태그(`<h1>`, `<strong>`…)를 써야 한다. 마크다운은 이걸 **기호 몇 개로 대체**해 빠르고 읽기 쉽게 쓰게 해준다.

게다가 개발 생태계에서 **사실상 표준 문서 형식**이다 — 블로그(Hugo), 위키(Obsidian), GitHub README, 주피터 노트북, 노션, 디스코드, 슬랙이 전부 마크다운을 쓴다. 한 번 익히면 어디서나 쓴다.

---

## 어떻게 작동하나

평문에 기호를 붙이면, 뷰어가 그걸 서식으로 바꿔 보여준다.

### 제목 (Heading)
```markdown
# 제목1
## 제목2
### 제목3
```
`#` 개수가 제목 단계. (1~6단계)

### 강조
```markdown
**굵게**      → 굵게
*기울임*      → 기울임
~~취소선~~    → 취소선
`인라인 코드`  → 인라인 코드
```

### 목록
```markdown
- 순서 없는 항목
- 다음 항목
  - 들여쓰면 하위 항목

1. 순서 있는 항목
2. 두 번째
```

### 링크 · 이미지
```markdown
[표시할 글자](https://example.com)      ← 링크
![대체 텍스트](image.png)               ← 이미지 (앞에 ! 붙음)
```

### 코드 블록 (Fenced Code)
````markdown
```python
print("Hello")
```
````
백틱 3개로 감싸고, 시작에 언어명(`python`)을 적으면 **문법 색칠**이 된다.

### 인용 · 구분선 · 표
```markdown
> 인용문

---                          ← 구분선 (가로줄)

| 이름 | 나이 |               ← 표
|:---|:---:|
| 홍길동 | 20 |
```

### 체크박스 (할 일 목록)
```markdown
- [ ] 아직 안 함
- [x] 완료함
```

## 실제 예시

- **이 블로그·위키 글이 전부 마크다운**으로 작성됨
- Hugo 블로그 글 맨 위 `--- ... ---` = **프론트매터(YAML)** — 제목·날짜·태그 등 메타데이터
- Obsidian 위키의 `[[문서이름]]` = **위키링크** — 노트끼리 연결 (마크다운 확장 문법)
- GitHub 저장소의 `README.md` = 프로젝트 첫 화면

## 자주 헷갈리는 것

**줄바꿈이 안 먹힘**: 그냥 Enter 한 번은 줄바꿈이 안 된다. **빈 줄**을 넣거나, 줄 끝에 **공백 2칸**을 넣어야 줄이 바뀐다.

**`*` 와 `_`**: `*굵게*`/`_굵게_` 둘 다 되지만, 한글 단어 중간에 `_`는 인식이 안 될 때가 있어 `*`를 권장.

**코드블록 언어 빼먹기**: 백틱 3개 뒤에 `python`을 안 적으면 색칠이 안 된다.

**`#` 뒤 공백**: `#제목`(X) → `# 제목`(O). 기호 뒤에 **한 칸 띄어야** 인식된다.

## 더 알면 좋은 것

📌 **GFM (GitHub Flavored Markdown)**: GitHub이 확장한 마크다운. 체크박스·표·취소선·자동 링크 등이 여기서 옴.

📌 **프론트매터(Front Matter)**: 글 맨 위 `---`로 감싼 영역. YAML 형식으로 제목·날짜·태그 등 설정. (Hugo·Obsidian)

📌 **Obsidian 확장**: `[[위키링크]]`, `![[파일 임베드]]`, `> [!note]` 콜아웃 등 자체 문법 추가.

📌 **Mermaid 다이어그램**: 코드블록에 ```mermaid 로 순서도·플로우차트를 글자로 그릴 수 있음. (GitHub·Obsidian 지원)

📌 **편집 도구**: VS Code, Obsidian에서 미리보기 지원. 터미널에선 `vi`로도 `.md` 편집 가능. → [[리눅스]]
