# 함수 (Function)

**정의**: 특정 작업을 하는 코드 묶음에 **이름을 붙여 두고**, 필요할 때마다 그 이름으로 불러 쓰는 것. `def`로 정의한다.

---

## 왜 필요한가

같은 코드를 여러 곳에서 반복해서 쓰면, 고칠 때 모든 곳을 다 찾아 고쳐야 한다. 함수는 코드를 한 번 만들어 두고 **이름만 부르면 재사용**하게 해 준다.

또한 복잡한 프로그램을 "회원가입 함수", "결제 함수"처럼 **작은 기능 단위로 쪼개** 이해하기 쉽게 만든다. "한 번 쓰고 마는 코드"와 "이름 붙여 두고 계속 쓸 코드"를 나누는 것이 좋은 프로그램의 시작이다.

---

## 어떻게 작동하나

### 내장 함수 — 파이썬이 미리 만들어 둔 것

```python
len([1, 2, 3])        # 3    (길이)
sum([1, 2, 3, 4, 5])  # 15   (합)
max([1, 2, 3])        # 3    (최댓값)
min([1, 2, 3])        # 1    (최솟값)
print("안녕")          # 출력
```

> ⚠️ **내장 함수 이름을 변수명으로 쓰지 말 것**: `sum`, `list`, `str`, `max` 같은 이름에 값을 대입하면 그 함수가 가려진다(덮어쓰기). 초보가 자주 하는 실수다.
> ```python
> sum = 10          # sum이라는 내장함수를 숫자 10으로 덮어씀
> sum([1, 2, 3])    # TypeError! 'int' object is not callable
> ```

### 사용자 정의 함수 — 내가 직접 만들기

```python
def plus_double(a, b):     # def 이름(매개변수):
    c = a + b              #   들여쓰기로 본문 작성
    return 2 * c           #   return으로 결과 돌려주기

print(plus_double(3, 4))   # 14  ( (3+4) × 2 )
```

구조 정리:
- `def` : "함수를 정의한다"는 키워드
- `plus_double` : 함수 이름 (변수처럼 스네이크 표기법)
- `(a, b)` : **매개변수(parameter)** — 함수가 받는 입력
- `return` : 결과를 함수 밖으로 돌려줌

### 호출과 인자

```python
def greet(name):
    print(f"안녕하세요, {name}님!")

greet("홍길동")    # 안녕하세요, 홍길동님!
#     └─ 인자(argument): 호출할 때 넣는 실제 값
```

> 💡 **매개변수 vs 인자**: 정의할 때 받는 자리(`name`)가 매개변수, 부를 때 넣는 실제 값(`"홍길동"`)이 인자다.

### return 이 있고 없고의 차이

```python
def add(a, b):
    return a + b           # 결과를 돌려줌

def show(a, b):
    print(a + b)           # 화면에 보여주기만 함 (돌려주지 않음)

x = add(2, 3)              # x = 5
y = show(2, 3)             # 화면엔 5가 찍히지만 y = None
```

> ⚠️ `return`이 없는 함수의 결과값은 **`None`**. 함수 결과를 변수에 담아 쓰려면 반드시 `return`이 필요하다. 즉 **함수의 목적**(화면 확인용 = print만 / 값 재사용용 = return)에 따라 return 사용 여부가 갈린다.

### 매개변수 에러 메시지 읽기

일부러 에러를 내보며 메시지의 의미를 익히면 디버깅이 쉬워진다.

```python
def add(a, b):
    return a + b

add(1)          # TypeError: add() missing 1 required positional argument: 'b'
add(1, 2, 3)    # TypeError: add() takes 2 positional arguments but 3 were given
```

- `missing required positional argument` → 필수 매개변수를 **덜** 넣음
- `takes N positional arguments but M were given` → 인자를 **더** 넣음 (N = 정의된 개수, M = 실제 넣은 개수)

### 기본값(default) 매개변수와 설계

```python
def greet(name, greeting="안녕"):   # greeting 기본값 지정
    print(f"{greeting}, {name}!")

greet("철수")              # 안녕, 철수!       (기본값 사용)
greet("철수", "반가워")     # 반가워, 철수!     (직접 지정)
```

> 💬 **"고수 vs 하수" 매개변수 설계**: 외부/다수 사용자가 쓰는 함수일수록 **필수 입력은 최소화(보통 1개)** 하고, 나머지는 **기본값으로 제공해 옵션으로** 설계한다.
> 예: `pandas.read_csv()`는 매개변수가 수십 개지만 **필수는 경로(path) 1개 중심**, 나머지는 전부 기본값으로 동작한다. → 배포·사용자 관점에서 **사용자 편의성을 최우선**으로 두는 설계.
> ⚠️ 단, 기본값 없는 매개변수가 기본값 있는 매개변수보다 **앞**에 와야 한다(`def f(a, b="x")` O / `def f(a="x", b)` ❌ SyntaxError).

## 실제 예시

```python
# 합격 여부 판단 함수
def is_pass(score):
    return score >= 60

print(is_pass(75))    # True
print(is_pass(40))    # False

# 여러 값 반환 (튜플로 묶임)
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([3, 1, 9, 5])   # 1, 9 로 나눠 받음

# 함수 + 반복문 조합
def total_price(prices):
    total = 0
    for p in prices:
        total += p
    return total

print(total_price([1000, 2000, 3000]))   # 6000
```

## 자주 헷갈리는 것

**전역 변수 vs 지역 변수**: 함수 **안에서 만든 변수**는 함수 밖에서 쓸 수 없다. *(라이브에서는 이 파트를 6/2 클래스 수업으로 이월해 다뤘다. → [[0602-클래스와모듈]])*
```python
x = "전역"             # 어디서든 접근 가능

def my_func():
    y = "지역"         # 이 함수 안에서만 존재
    print(x)           # 전역변수 읽기 OK
    print(y)           # OK

my_func()
print(x)               # OK
print(y)               # NameError! — 함수 밖에는 y가 없음
```

**Shadowing(가림)**: 함수 안에 전역과 **같은 이름**의 변수를 만들면, 그 함수 안에서는 지역이 전역을 "가린다". 전역은 그대로 유지된다.
```python
s = "전역값"
def f():
    s = "지역값"        # 전역 s를 가리는 새 지역 s
    print(s)            # 지역값
f()
print(s)                # 전역값 (안 바뀜!)
```

**`global` — 함수 안에서 전역을 수정하려면**: 그냥 대입하면 지역이 새로 생긴다. 전역을 진짜 바꾸려면 `global` 선언이 필요하다.
```python
count = 0
def increase():
    global count        # "이 count는 전역이다" 선언
    count += 1
increase(); increase()
print(count)            # 2
```
> ⚠️ `global` 남용은 코드 추적을 어렵게 한다. 가능하면 값을 `return`으로 주고받는 게 좋다.

**함수 vs 메서드**: 둘 다 기능 묶음이지만 호출 방식이 다르다.
- **함수**: `len(my_list)` — 독립적으로 존재, 괄호 안에 대상을 넣음
- **메서드**: `my_list.append(4)` — 특정 자료형에 **딸린** 함수, 점(`.`)으로 호출

**`return`과 `print`의 혼동**: `print`는 사람 보라고 화면에 찍는 것이고, `return`은 컴퓨터(다른 코드)가 쓰라고 값을 넘기는 것이다. 계산 결과를 이어서 활용하려면 `return`을 써야 한다.

**정의만 하고 호출 안 함**: `def`로 만들기만 하면 아무 일도 안 일어난다. `함수이름()`으로 **불러야** 실행된다.

## 더 알면 좋은 것

📌 **타입 힌트(Type Hint)**: 매개변수·반환값의 자료형을 명시한다. 강제는 아니지만(어겨도 에러 안 남) 가독성과 협업 효율을 높인다.
```python
def add(a: int, b: int) -> int:     # int 둘을 받아 int 반환
    return a + b
def log(msg: str) -> None:          # 반환값 없으면 -> None
    print(msg)
```

📌 **독스트링(docstring)**: 함수 첫 줄에 `"""설명"""`을 적으면 그 함수가 무슨 일을 하는지 문서가 된다. `help(함수이름)`으로 볼 수 있고, 라이브러리 공식 문서도 대부분 여기서 자동 생성된다.
```python
def add(a, b):
    """두 수를 더해 반환한다."""
    return a + b
```

📌 **`*args` / `**kwargs`**: 개수가 정해지지 않은 인자를 받을 때 쓴다. `def func(*args):`는 여러 값을 튜플로 모아 받는다. (수업 미커버)

📌 **람다(lambda)**: 이름 없는 한 줄짜리 함수. `square = lambda x: x**2`. `sort`의 정렬 기준 등에 자주 쓴다. (수업 미커버)

📌 **함수도 값이다**: 파이썬에서 함수는 변수에 담거나 다른 함수의 인자로 넘길 수 있다. 이 성질이 나중에 데이터 처리·AI 코드에서 강력하게 쓰인다.
