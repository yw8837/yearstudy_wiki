# 사분위수 (Quartile)

**정의**: 자료를 정렬해 **4등분하는 세 위치값**. Q1(제25백분위), Q2(제50=중앙값), Q3(제75백분위). [[백분위수]]의 특수 경우.

---

## 왜 필요한가

분포를 4등분해 **가운데 50%가 어디에 있는지**, 위/아래로 어떻게 퍼졌는지 본다. [[상자그림]]과 [[IQR]]의 토대.

---

## 어떻게 작동하나

```python
import numpy as np
Q1 = np.percentile(x, 25)   # 13.35 (tips)
Q2 = np.percentile(x, 50)   # 17.80  = 중앙값
Q3 = np.percentile(x, 75)   # 24.13
IQR = Q3 - Q1               # 10.78
```

---

## 자주 헷갈리는 것

**Q2 = [[중앙값]]이다** — 따로가 아니다. 또 "사분위수"는 4개 구간을 만드는 **3개의 경계값**(Q1·Q2·Q3)을 가리킨다.

---

## 더 알면 좋은 것

📌 Q1~Q3 사이가 [[IQR]](가운데 50%)이고, [[상자그림]]의 상자가 바로 이 구간이다. 정렬 기반이라 극단값에 강건하다.
