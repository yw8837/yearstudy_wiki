# 정밀도 (Precision)

**정의**: **1(양성)로 예측한 것 중 실제로 1인 비율**. `TP / (TP + FP)`. "내가 생존이라 한 사람 중 진짜 생존자 비율."

---

## 왜 필요한가

**거짓 양성(FP)의 비용이 클 때** 중요하다. 스팸 필터가 정상 메일을 스팸으로 오분류(FP)하면 곤란하듯, "양성이라 외친 게 얼마나 믿을 만한가"를 잰다.

---

## 어떻게 작동하나

```python
# titanic 실습: 손계산
precision = TP / (TP + FP) if (TP + FP) > 0 else 0
print(f"Precision: {precision:.2%}  (of predicted survivors, how many actually survived)")
```

- 분모가 **예측 양성(TP+FP)** — 실제와 무관하게 "1이라고 찍은 전부".
- 분모 0(양성 예측이 하나도 없음) 방어 코드가 들어 있다.

---

## 자주 헷갈리는 것

**정밀도 ↔ 재현율 혼동.** 정밀도 분모는 *예측* 양성(TP+FP), [[재현율]] 분모는 *실제* 양성(TP+FN). "찍은 것 기준이 정밀도, 실제 정답 기준이 재현율." 둘은 보통 **트레이드오프** — 임계값을 올리면 정밀도↑·재현율↓.

---

## 더 알면 좋은 것

📌 정밀도만 높이려면 확실한 것만 1로 예측하면 되지만 그러면 놓치는 게 많아져 재현율이 떨어진다. 그래서 둘을 함께 요약한 [[F1점수]]를 본다. ⚠ 노션 원문엔 실제 정밀도 수치 없음.
