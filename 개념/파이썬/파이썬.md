# 파이썬 (Python)

**정의**: 읽기 쉬운 문법을 가진 고수준 프로그래밍 언어. 데이터 분석·AI·자동화·웹 개발 전반에 쓰인다.

---

## 왜 필요한가

파이썬이 AI·데이터 분야의 사실상 표준이 된 이유는 세 가지다.
1. 문법이 간결해서 아이디어를 코드로 빠르게 옮길 수 있다
2. 데이터 분석(pandas, numpy), 머신러닝(scikit-learn), 딥러닝(PyTorch, TensorFlow) 라이브러리 생태계가 압도적이다
3. 커뮤니티가 크다 = 문제 생기면 답이 인터넷에 있다

---

## 어떻게 작동하나

### 한 줄씩 바로 실행하는 방식

```
C (컴파일):   소스코드 → (컴파일) → 실행파일 → 실행
Python: 소스코드 → (한 줄씩 읽으면서) → 즉시 실행
```

한 줄씩 실행하는 방식의 장점: 결과를 바로 볼 수 있다. Jupyter Notebook에서 셀 하나 실행하면 바로 결과 보임.

### 파이썬의 특징

```python
# 들여쓰기로 코드 블록 구분 (C, Java는 중괄호 {})
if score >= 90:
    grade = "A"       # 들여쓰기가 구조를 결정
    print(grade)      # 이 두 줄이 if 블록

# 동적 타이핑 - 자료형 선언 불필요
x = 42          # int
x = "hello"     # str로 변경 가능 (다른 언어에서는 불가능한 경우 많음)
x = [1, 2, 3]   # list로 변경 가능
```

### 파이썬 생태계

| 분야 | 라이브러리 | 역할 |
|:---|:---|:---|
| 데이터 처리 | pandas | 표 형태 데이터 처리 |
| 수치 계산 | numpy | 행렬·배열 연산 |
| 시각화 | matplotlib, seaborn | 그래프·차트 |
| 머신러닝 | scikit-learn | 전통적 ML 알고리즘 |
| 딥러닝 | PyTorch, TensorFlow | 신경망 학습 |
| 웹 백엔드 | FastAPI, Django, Flask | 웹 서버 |
| 크롤링 | requests, BeautifulSoup | 웹 데이터 수집 |

## 실제 예시

```python
# pip으로 라이브러리 설치
pip install pandas numpy matplotlib

import pandas as pd

df.head()              # 처음 5행 보기

```

## 자주 헷갈리는 것

**"파이썬은 느리다"**: 맞다, 순수 파이썬은 C보다 느리다. 하지만 numpy·pandas는 내부적으로 C로 구현되어 있어 속도가 빠르다. 데이터 분석에서 속도 문제를 체감하는 경우는 드물다.

**"Python 2 vs Python 3"**: 2020년 Python 2 공식 지원 종료. 새로 배운다면 무조건 Python 3. `print "hello"` (Python 2) vs `print("hello")` (Python 3).

**"들여쓰기는 스페이스 4칸이어야 한다"**: PEP 8 권장사항이지 강제는 아니다. 단, 한 파일 안에서 혼용하면 IndentationError가 난다.

## 더 알면 좋은 것

📌 **가상환경(Virtual Environment)**: 프로젝트마다 독립된 패키지 환경 유지. `python -m venv myenv` → `source myenv/bin/activate`. 다른 프로젝트 라이브러리와 충돌 방지.

📌 **pip vs conda**: pip는 파이썬 패키지 관리자, conda는 패키지+환경 관리자 (Anaconda의 기반). 데이터 과학에서는 conda를 많이 씀.

📌 **PEP 8**: 파이썬 코딩 스타일 가이드. 변수명 snake_case, 클래스명 CamelCase, 줄 최대 79자 등. VS Code의 autopep8·black이 자동 적용.
