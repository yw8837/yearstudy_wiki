# AI 산업 활용 사례

**정의**: 생성형 AI·AI Agent가 제조·금융·IT 등 실제 산업에서 쓰이는 사례 모음.

> ⚠️ 효과 수치는 슬라이드에서 정상 추출됐으나, **각 수치의 정확한 의미 라벨은 PDF 한글 깨짐으로 `[원문 확인 필요]`**. 아래 수치를 특정 의미로 단정하지 말 것.

---

## 산업별 사례

### 제조 — LG

- "현황 / 기능 적용 / 효과" 3단 구성
- 효과 지표 수치: `17%`, `30%`, `70%` (의미 라벨 미확정)
- "생성형 AI + 공정 적용" 조합 도식

### 금융 — AI Assistant

- `Assistant` 활용, `Advisor adoption`(어드바이저 도입)
- 수치: `20%`, `98%+ → 80%` (도입 전후 효과로 추정, 라벨 미확정)

### IT·개발 — 코딩 에이전트 / CI 자동화

- [[AIAgent]]로 코드 작성·리뷰·PR 처리
- `CI` 파이프라인 연동, `worktree`로 Agent 병렬 실행
- 키워드: `OAuth`, `MCP`, `PR`
- 수치: `560`, `97`, `80%` (라벨 미확정)

| 산업 | 핵심 | 추출 수치(의미 미확정) |
|:---|:---|:---|
| 제조(LG) | 생성형 AI + 공정 | 17% / 30% / 70% |
| 금융 | AI Assistant·어드바이저 | 20% / 98%+ → 80% |
| IT·개발 | 코딩 에이전트·CI 자동화 | 560 / 97 / 80% |
