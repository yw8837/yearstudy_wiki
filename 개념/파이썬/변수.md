# 변수 (Variable)

**정의**: 데이터를 담는 이름 붙은 메모리 공간. `=`으로 값을 저장한다.

---

## 왜 필요한가

프로그램은 데이터를 계속 사용한다. 같은 값을 여러 곳에서 쓰거나, 연산 결과를 나중에 쓰려면 이름을 붙여 저장해야 한다. 그게 변수다.

---

## 어떻게 작동하나

### 기본 사용

```python
# 대입 연산자 =
# "오른쪽 값을 왼쪽 이름에 저장"
name = "홍길동"       # 문자열 저장
age = 25             # 정수 저장
pi = 3.14159         # 실수 저장

# 값 읽기
print(name)          # 홍길동

# 값 변경
age = 26             # 덮어쓰기
age = age + 1        # 현재값 기반 업데이트 (= 27)
age += 1             # 동일 (= 28, 축약 표현)
```

### 변수 이름 규칙

```python
# 가능
user_name = "홍길동"    # 스네이크 케이스 (Python 표준)
score1 = 95
_private = "내부용"     # 언더스코어 시작 가능

# 불가능
1score = 95            # SyntaxError: 숫자로 시작 불가
my-name = "홍"         # SyntaxError: 하이픈 불가
my name = "홍"         # SyntaxError: 공백 불가
for = 10              # SyntaxError: 예약어 사용 불가
```

### 네이밍 관례

```python
# snake_case: 파이썬 변수·함수 표준 (PEP 8)
student_name = "홍길동"
total_score = 100
is_logged_in = True

# CamelCase: 클래스 이름에 사용
class StudentInfo:
    pass

# UPPER_CASE: 상수 (변하지 않는 값)
MAX_SIZE = 100
PI = 3.14159
```

### 다중 대입

```python
# 여러 변수 동시 할당
a, b, c = 1, 2, 3
x, y = y, x          # 값 교환 (파이썬만의 간결한 방식)

# 같은 값으로 초기화
a = b = c = 0
```

## 실제 예시

```python
# 가독성 좋은 변수명 vs 나쁜 변수명
# 나쁨
x = 1200
y = 1.1

# 좋음
base_salary = 1200
tax_rate = 1.1
total = base_salary * tax_rate

# 의미 없는 단일 문자는 반복문 카운터에만
for i in range(10):
    print(i)
```

## 자주 헷갈리는 것

**`=` vs `==`**: `=`는 대입(저장), `==`는 비교(같은지 확인). `if x = 5`는 SyntaxError. 조건에서는 `==`.

**"변수는 데이터 자체"**: 정확하지 않다. 변수는 데이터가 저장된 메모리 위치를 가리키는 이름표다. 같은 데이터를 여러 변수가 가리킬 수 있다.

```python
a = [1, 2, 3]
b = a          # b도 같은 리스트를 가리킴
b.append(4)
print(a)       # [1, 2, 3, 4] ← a도 바뀜! (같은 메모리를 가리키기 때문)

# 독립적인 복사가 필요하면
b = a.copy()   # 또는 b = a[:]
```

**"변수명은 한글도 된다"**: 기술적으로는 가능하지만 절대 쓰지 않는다. 영어로 짓는 게 관례이고, 한글 변수명은 호환성·가독성 문제를 일으킨다.

## 더 알면 좋은 것

📌 **스코프(Scope)**: 변수가 유효한 범위. 함수 밖에서 선언하면 전역 변수, 함수 안에서 선언하면 지역 변수. 함수 안에서 전역 변수를 수정하려면 `global` 선언 필요.

📌 **메모리 관리**: 파이썬은 가비지 컬렉터(GC)가 더 이상 참조되지 않는 변수를 자동 해제. 개발자가 직접 메모리 관리 안 해도 되는 이유.
