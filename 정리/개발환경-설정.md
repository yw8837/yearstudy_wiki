# 개발 환경 설정 (uv)

이어드림 과정 파이썬 환경을 **uv**로 세팅하는 순서 정리. (설치 → 동기화 → 실행 → 문제해결)

> 출처: 강의 환경설정 안내 · uv 공식 문서 [docs.astral.sh/uv](https://docs.astral.sh/uv/)
> ⚠️ 아래 경로의 `<사용자명>`은 **본인 PC마다 다름** — 예시를 그대로 쓰지 말고 화면에 출력된 본인 값을 사용.

---

## 0. uv란?

📌 Rust로 만든 **빠른 파이썬 패키지·프로젝트 매니저**. `pip` + `venv` + 버전관리를 하나로 대체한다. 가상환경 생성·의존성 설치가 매우 빠름.

---

## 1. uv 설치

### Windows
1. **PowerShell을 관리자로 실행**
2. 아래 입력 후 Enter:
   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
3. 설치되면 `uv.exe`, `uvx.exe`, `uvw.exe` 가 깔리고, **PATH 추가 안내**가 출력됨.
   화면에 나온 아래 형태의 줄을 복사해 실행:
   ```powershell
   $env:Path = "C:\Users\<사용자명>\.local\bin;$env:Path"
   ```
   > ⚠️ 이 경로는 사용자마다 다름 → **출력된 본인 것 복사** (예시 복사 금지).
   > PowerShell에서 복사 `Ctrl + Insert` / 붙여넣기 `Shift + Insert`.

### macOS
- 터미널에서:
  ```bash
  curl -LsSf https://astral.sh/uv/install.sh | sh
  ```
- (공식 문서 Installation 페이지에서 OS 탭 선택 시 정확한 명령 확인 가능)

---

## 2. 설치 확인

```powershell
uv --version
# 예: uv 0.11.16 (... x86_64-pc-windows-msvc)
```
버전이 나오면 설치 성공.

---

## 3. 프로젝트 설정 파일 준비

- 강의에서 제공한 **`uv_project_settings.zip`** 압축 해제
- 안에 `pyproject.toml`, `uv.lock`, `check_env.py`, `env.example`, `.gitignore` 등 포함
  (`pyproject.toml`·`uv.lock` = 설치할 패키지 목록·버전 고정)

---

## 4. 의존성 설치 — `uv sync`

1. **VS Code를 관리자로 실행** → 터미널 열기 (Windows: PowerShell / macOS: bash)
2. 프로젝트 폴더에서:
   ```bash
   uv sync
   ```
- `.venv` 가상환경이 생기고 패키지가 설치됨
- `Installed N packages` 가 **에러 없이** 나오면 성공 (numpy·pandas·matplotlib·jupyter 등)

---

## 5. 환경 확인 — `check_env.py`

```bash
uv run python check_env.py
```
정상이면 라이브러리 버전이 출력됨 (예시):

| 라이브러리 | 버전 |
|:---|:---|
| Python | 3.13.2 |
| numpy | 2.4.6 |
| pandas | 3.0.3 |
| matplotlib | 3.10.9 |
| seaborn | 0.13.2 |
| plotly | 6.7.0 |
| scipy | 1.17.1 |
| sklearn | 1.8.0 |
| statsmodels | 0.14.6 |
| pyarrow | 24.0.0 |
| openpyxl | 3.1.5 |

> `uv run <명령>` = uv가 만든 가상환경 안에서 그 명령을 실행 (가상환경 수동 활성화 불필요).

---

## 6. JupyterLab 실행

```bash
uv run jupyter lab
```
브라우저에서 JupyterLab이 열림.

---

## 7. 문제 해결 — Windows 보안 차단

`uv run` 실행 시 아래 에러가 나면:
```
error: Failed to spawn: `python`
  Caused by: 애플리케이션 제어 정책에서 이 파일을 차단했습니다. (os error 4551)
```

**해결**: Windows 보안 → **앱 및 브라우저 컨트롤** → 차단 설정을 잠시 **해제** 후 재시도.
> ⚠️ 보안 기능이므로 설치·확인이 끝나면 **다시 켜두는 것**을 권장.

## 자주 쓰는 uv 명령 (보충)

| 명령 | 역할 |
|:---|:---|
| `uv --version` | 버전 확인 |
| `uv sync` | pyproject·lock 기준 의존성 설치 |
| `uv run <명령>` | 가상환경에서 명령 실행 (`uv run python x.py`) |
| `uv add <패키지>` | 패키지 추가 |
