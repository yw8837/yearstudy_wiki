# 06/04 · 파이썬 라이브러리 활용

남이 만든 강력한 도구를 **가져다 쓰고**, 내 코드를 **전 세계에 공유**하는 법. 한 줄 요약: **`pip install`로 도구를 빌려 쓰고, PyPI에 올려 내 코드도 내놓는다.**

---

## 01. 라이브러리란

**라이브러리 = 누군가 미리 만들어 둔 코드 묶음.** 바퀴를 다시 발명하지 않는 게 핵심.

| 구분 | 설명 | 예시 |
|:---|:---|:---|
| **표준 라이브러리** | 파이썬 기본 내장 (설치 불필요) | `math`·`random`·`datetime`·`os`·`json` |
| **외부 라이브러리** | 따로 설치해서 사용 | `numpy`·`pandas`·`requests`·`matplotlib` |

대표 외부: **numpy**(배열계산)·**pandas**(표 데이터)·**matplotlib/seaborn**(시각화)·**requests**(웹요청)·**scikit-learn**(머신러닝)·**BeautifulSoup**(크롤링).

> 전 세계 라이브러리는 **PyPI**(Python Package Index) 창고에 모여 있고, `pip`로 내려받음. → [[크롤링]]

→ [[파이썬라이브러리]] 참조

---

## 02. 설치 — `pip`

```bash
pip install pandas            # 설치
pip install pandas==2.2.0     # 특정 버전
pip install --upgrade pandas  # 업그레이드
pip list                      # 설치 목록
```

**팀 협업 기본** — 의존성 파일:

```bash
pip freeze > requirements.txt     # 현재 목록을 파일로
pip install -r requirements.txt   # 그대로 한 번에 설치
```

> 우리 과정은 **uv**로 관리: `uv add pandas`·`uv sync`. → [[uv]]

---

## 03. 사용 — `import`

```python
import pandas as pd          # 관례 별칭(as)
import numpy as np

df = pd.DataFrame({"이름": ["A","B"], "점수": [95, 82]})
print(df["점수"].mean())      # 88.5
print(np.array([1,2,3]).mean())   # 2.0
```

> `pandas→pd`, `numpy→np`는 관례 별칭(공식 문서도 사용). 막히면 **공식 문서** 보는 습관이 중요.

## 04. PyPI 배포 — 내 코드 공유

내가 만든 코드도 패키지로 만들어 올리면 누구나 `pip install` 가능.

```
1. 패키지 구조(폴더+코드+pyproject.toml)
2. python -m build   → dist/ 에 .whl·.tar.gz 생성
3. twine upload      → PyPI 업로드
4. 누구나 pip install
```

```bash
pip install build twine
python -m build
twine upload dist/*
```

```toml
# pyproject.toml — 패키지 이름·버전·의존성
[project]
name = "my-package"
version = "0.1.0"
dependencies = ["requests"]
```

> 처음엔 **TestPyPI**(test.pypi.org)에 먼저 올려 연습 권장.

## 보충

📌 **모듈 vs 패키지 vs 라이브러리**: 모듈=`.py` 파일 / 패키지=모듈 담은 폴더 / 라이브러리=패키지(들)을 묶어 배포한 것. → [[모듈과패키지]]

📌 **가상환경**: 프로젝트별 독립 패키지 공간(버전 충돌 방지). uv가 `.venv`로 자동 관리. → [[개발환경-설정]]

📌 **시맨틱 버저닝**: `major.minor.patch` (예 `2.2.0`). 큰 변화=major, 기능추가=minor, 버그수정=patch.

📌 **`pip install` 안 될 때**: 가상환경 활성화 확인 / 오타·대소문자 / `pip` 대신 `python -m pip`.
