# AI (Artificial Intelligence, 인공지능)

**정의**: 인간의 학습·추론·문제해결 능력을 컴퓨터로 구현하는 기술 분야 전체.

---

## 왜 필요한가

AI, 머신러닝, 딥러닝은 중첩된 개념이다. 혼용해서 쓰이지만 엄밀히는 다르다.

```
AI (인공지능)
└── 머신러닝 (Machine Learning)
     └── 딥러닝 (Deep Learning)
          └── LLM (Large Language Model)
```

큰 범주가 AI, 그 안에 머신러닝이 있고, 딥러닝은 머신러닝의 한 방법, LLM은 딥러닝 기반의 언어 모델이다.

---

## 어떻게 작동하나

### AI의 분류

| 분류 | 설명 | 예시 |
|:---|:---|:---|
| **좁은 AI (Narrow AI)** | 특정 작업 하나만 잘함 | 알파고, 스팸 필터, 얼굴 인식 |
| **범용 AI (AGI)** | 인간처럼 모든 작업 | 아직 없음 |
| **초인공지능 (ASI)** | 인간을 초월 | 이론상 개념 |

현재 존재하는 AI는 전부 좁은 AI다. ChatGPT도 언어 처리에 특화된 좁은 AI.

### 머신러닝의 학습 방식

| 방식 | 설명 | 예시 |
|:---|:---|:---|
| **지도학습** | 정답 있는 데이터로 학습 | 스팸 분류, 집값 예측 |
| **비지도학습** | 정답 없이 패턴 발견 | 고객 군집화, 이상 탐지 |
| **강화학습** | 보상·벌로 행동 최적화 | 알파고, 게임 AI, 로봇 제어 |

### 딥러닝의 핵심 — 신경망

인간 뇌의 뉴런 연결을 수학적으로 모방.

```
입력층 (데이터)
    ↓
은닉층 1 (특징 추출)
    ↓
은닉층 2 (패턴 인식)
    ↓
...
    ↓
출력층 (결과)
```

층이 깊어질수록 더 복잡한 패턴을 학습. "딥(Deep)" = 층이 깊다는 뜻.

### 생성형 AI (Generative AI)

기존 AI가 분류·예측에 집중했다면, 생성형 AI는 새로운 콘텐츠를 만든다.

| 종류 | 예시 |
|:---|:---|
| 텍스트 생성 | ChatGPT, Claude |
| 이미지 생성 | Midjourney, DALL-E, Stable Diffusion |
| 코드 생성 | GitHub Copilot, Cursor |
| 음악 생성 | Suno, Udio |
| 영상 생성 | Sora, Runway |

## 실제 예시

이미 AI를 매일 쓰고 있다:
- 유튜브·넷플릭스 추천 = 협업 필터링 (머신러닝)
- 스마트폰 얼굴 인식 = 딥러닝 (CNN)
- 네이버 지도 도착 예정 시간 = 머신러닝
- 카카오톡 스마트 답장 제안 = 자연어 처리
- 신용카드 이상거래 탐지 = 이상 탐지 (머신러닝)
- ChatGPT, Claude = LLM (딥러닝)

## 자주 헷갈리는 것

**"AI = 로봇"**: AI는 소프트웨어(알고리즘). 로봇은 AI가 탑재될 수도 있는 하드웨어. 별개의 개념.

**"AI는 모든 것을 안다"**: 아니다. LLM은 학습 데이터 기반으로 "그럴듯한 답"을 생성한다. 잘못된 정보를 자신 있게 말하는 할루시네이션이 발생한다.

**"딥러닝이 항상 머신러닝보다 낫다"**: 데이터가 적거나 문제가 단순하면 오히려 기본 머신러닝이 낫다. 딥러닝은 대용량 데이터가 필요하고 해석이 어렵다.

## 더 알면 좋은 것

📌 **Transformer**: 2017년 Google이 발표한 "Attention is All You Need" 논문에서 나온 아키텍처. 현대 LLM의 기반. GPT·BERT·Claude 모두 Transformer 기반.

📌 **파라미터(Parameter)**: 모델의 크기를 나타내는 지표. GPT-3는 1750억 개 파라미터. 파라미터가 많을수록 더 복잡한 패턴 학습 가능 (≠ 더 똑똑하다는 보장은 없음).

📌 **파인튜닝(Fine-tuning)**: 사전 학습된 모델에 특정 도메인 데이터로 추가 학습. 의료 AI, 법률 AI 등에 활용.
