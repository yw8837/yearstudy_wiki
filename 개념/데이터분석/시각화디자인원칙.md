# 시각화 디자인 원칙 (Wilke)

**정의**: Claus O. Wilke 『Fundamentals of Data Visualization』의 실무 디자인 원칙. 색은 데이터를 인코딩할 때만, 동일 범주는 동일 색, 색각친화, 강조 절제, Data-ink 최소화. 6/19 노트북에서 코드로 구현된다.

---

## 왜 필요한가

같은 데이터도 색·강조를 잘못 쓰면 오해를 부른다. 일관된 원칙을 따르면 정직하고 명확한 차트가 되고, 차트 간 비교도 쉬워진다. 6/18 [[데이터시각화-원칙]] 이론의 코드화.

---

## 어떻게 작동하나

- **6원칙:** ① 색은 **데이터 인코딩 전용**(장식 무지개 금지) ② **동일 범주=동일 색**(노트북 전체 일관) ③ **색각친화**([[OkabeIto]]·[[CVD]]) ④ **강조 절제**(강조만 vermillion #D55E00) ⑤ 연속/분포는 단일 색조의 농도·투명도 ⑥ **Data-ink**(상·우 spine 제거, 격자는 필요 축만).

```python
def stable_cat_colors(values, palette=PALETTE_OI):   # 범주→색 고정(차트 간 공유)
    cats = sorted(pd.Series(values).dropna().unique())
    return {c: palette[i % len(palette)] for i, c in enumerate(cats)}
```

---

## 자주 헷갈리는 것

**"색을 많이 쓰면 화려해서 좋다"가 아니다.** 색은 정보를 인코딩할 때만, 강조는 한 그래프에 하나만. 무지개색(Rainbow/Jet)은 순서를 왜곡하므로 Viridis 계열을 쓴다([[색상스케일]]).

---

## 더 알면 좋은 것

📌 핵심은 **색-일관성**: 같은 범주가 차트가 바뀌어도 같은 색이면(`COLOR_BY_ISSUE` 키 공유) 독자가 차트들을 쉽게 연결한다(`viz_advanced_01`의 메시지).
