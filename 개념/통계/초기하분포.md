# 초기하분포 (Hypergeometric Distribution)

**정의**: 유한 모집단에서 **비복원추출**할 때 성공(관심 범주) 횟수의 분포. `X ~ Hyper(M,n,N)`. 불량률·품질검사 계산에 사용.

---

## 왜 필요한가

모집단이 유한하고 한 번 뽑으면 다시 넣지 않는 경우(제품 검사, 카드 뽑기), 매 시행 확률이 변하므로 [[이항분포]]가 아니라 초기하분포를 써야 한다.

---

## 어떻게 작동하나

```python
from scipy import stats
import numpy as np
stat = stats.hypergeom(M, n, N)   # M=전체, n=성공 원소 수, N=표본 크기
stat.pmf(x); stat.cdf(x)
np.random.hypergeometric(ngood, nbad, nsample, size)
```

- 예) 흰공6·검은공4에서 5개 뽑아 흰공3일 확률 = `C(6,3)·C(4,2)/C(10,5)=10/21`.

---

## 자주 헷갈리는 것

**이항 vs 초기하 = 복원 vs 비복원.** 모집단이 매우 크면 비복원이어도 확률 변화가 미미해 이항분포로 근사할 수 있다.
